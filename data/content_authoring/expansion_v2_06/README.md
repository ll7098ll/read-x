## 내용·표현 보완

모든 자료는 자체 창작한 **가상 기관·가상 행사·가상 조사**이다. 실제 웹 검색 결과·기관의 운영 공지·뉴스나 조사 결과를 수집한 것처럼 소개하지 않는다. 초5는 검색 화면을 읽는 모형이며 실제 검색 도구의 사용 수행을 완료했다고 집계하지 않는다.

최근에 게시했다는 이유만으로 옛 원문을 최신 수정본으로 읽지 않게 했다. 운영 주체가 자기 행사의 변경을 확인한 설정은 제공하되 공식 명칭만으로 모든 정보가 참이라는 규칙은 만들지 않았다. 지난해 자료가 올해의 독립 근거는 아니지만 올해 내용이 반드시 거짓이라는 반대 단정도 허용하지 않는다.

초4에서 응답하지 않은 학생을 반대자로 분류하지 않으며, 씨앗의 현재 상태만 보고 미래 전시 계획을 확정하지 않는다. 초6에서도 큰 글씨가 모든 독자에게 같은 반응을 일으켰다는 실제 관찰 기록을 만들지 않는다. 독자의 실제 이해는 추가 확인 대상으로 남겼다.

첫 이미지 검토에서 낱말이 갈라지거나 느낌표가 홀로 다음 줄에 떨어지는 문제를 고쳤다. 띄어쓰기 경계를 우선해 줄바꿈하고 3개 미리보기에서26장 전체를 다시 살폈다. 초6 비교 포스터의 제목에 ‘무료 입장 강조’·‘비용 범위 함께 제시’라는 해석을 붙여 놓은 문제도 발견해 **자료v2**에서 ‘포스터 가·나’만 남겼다. 실제 배치를 읽어 설명하게 하고, 수정 전 [원고](revision_history/2026-11-18-before-caption-review.json)와 [이미지 제작 원장](revision_history/2026-11-18-before-word-wrap-assets.json)을 보존했다.

## 접근성과 검증

그림마다 같은 정보의 문자 대체를 제공한다. 그림의 모양·표의 행 정보·큰 글씨와 작은 글씨도 구별해 적었다. 대체 설명은 정답 해설을 포함하지 않는다. 이미지·문자 대체·대독 중 사용한 형태를 기록하고, 시각적 배치 자체에 대한 수행을 같은 방식으로 측정했다고 단정하지 않는다.

문항은 이미지의 특정 요소 ID와 실제 문구에 연결한다. **시각 자료 근거103개**를 대조하고 원고·이미지 자료·PNG 파일·내장 이미지·대체 설명의 일치와 해시를 검사했다. 구조·일부 사례 관계 확인36건, 원문 버전·교육과정 범위·정답·준거·HTML·JavaScript 문법 검사를 통과했다. 자동 경고·정답 길이 검토 후보·설정한 유사 본문 후보는0이다. 자동 검사가 정답 유일성·실제 학년 난도를 증명하는 것은 아니다.

`python -X utf8 -m unittest discover -s tests -p test_media_v2_delivery.py`의3개 테스트는 잘못된 이미지 근거 문구, 내장 PNG 변조, 이미지 대체 설명 변경이 각각 차단됨을 확인한다. 공통 문제집 검사기를 바꾼 뒤 기존6배치의 산출물도 재대조해 통과했다.
