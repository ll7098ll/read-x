## 생성과 검토

본문과 문항은 학년별 저작 스크립트의 실제 집필문에서 만든다. 이름과 숫자만 바꾸어 수량을 늘리는 반복 생성은 사용하지 않았다. 수치 자료와 실험 기록, 마을과 기관은 자체 창작한 가상 학습 상황이다. 교육과정 성취기준을 임의로 연결하거나 실제 조사 결과로 표시하지 않았다.

자동 검사는 ID·문장별 근거·문자 위치·글자 수·해시·목표 ID·선지 수·해설·쓰기 과정·확인 자료의 도움 차단·수치 계산·동일 및 유사 본문 후보를 확인한다. 계산 문제 12개 검사를 별도로 두었으며 주요 평균·비율·사용량은 생성된 원자료 표에서 다시 계산한다.

내용 재검토에서는 네 번 치는 놀이를 세 번으로 오해할 수 있던 제목을 ‘차례로 이어가는 합주’로 바꿨다. 수치 설명에 표를 보강하고, 도전 확장을 새 전이 자료로 세지 않도록 계열을 유지했다. 서술형은 예시 문구 일치만으로 채점하지 않으며, 실제 응답을 받지 않은 상태에서 성적이나 능력 진단을 만들지 않는다.

브라우저 실행 검사는 로컬 file 주소의 접근 정책으로 수행하지 못했다. JavaScript 문법과 산출물 데이터 검사는 수행했다. 학년 적합성·정답의 유일성·수업 시간·서술 답의 수용 범위는 실제 교사·학생 검토로 이어져야 한다.
