## 검토와 보완

직접 뜻풀이가 있어 해석 없이 풀리던 의미 풀기 원고4개를 수정했다. 선택형7개는 정답 선지만 길어 답이 드러나는 단서를 줄였다. 전시관이 정상 운영한다는 사실만으로 학교의 오전 견학이 진행된다고 추정할 수 있는 문제에는 오전 집합 안내를 추가했다. 모든 변경 뒤 원고와 문제집을 다시 생성하고 근거 인용을 재검사했다.

문항624개에는 선택144, 설명119, 쓰기88, 짝짓기51, 분류38, 근거 찾기30, 고쳐쓰기60, 표 정리36, 순서8, 질문 만들기14, 직접 말하기24, 소리 내어 읽기12가 있다. 서술·쓰기에는 부적절한 답·부분 수행·충족 예를 구체적으로 적었다. 표현이 다른 타당한 답은 수용하도록 명시했다.

두 번째 확장에서 초1 인물 마음과 초3 비교 읽기의24묶음·104문항을 추가했다. 웃음이나 멈춘 행동만으로 감정·성격을 단정하지 않게 했으며, 목적이 달라지면 비교 기준도 달라지는 상황을 넣었다. 상자 수납 문제에는 안쪽 치수임을 명시하고, 새 선택형4개의 길이 단서를 보완했다. 모든 선택형48개에 정답을 지지하는 이유를 문장으로 집필했다.

초3의 수치 자료6개는 실제 표로 함께 제공한다. 주요 표와 본문 값의 대응, 용량·무게 차이, 안쪽 길이와 막대의 수납 조건, 수량·예산 충족을8개 계산·대조 검사로 확인한다. 검증 보고서는 검사한 콘텐츠 파일의 해시도 기록하므로 이전 산출물의 성공을 새 원고의 성공으로 오인하지 않게 한다.

세 번째 확장에서 초5 주장 쓰기와 초6 상충 자료 읽기의24묶음·104문항을 추가했다. 초5 쓰기10과제에는3개씩 분석적 준거를 두어 주장 범위·관찰 근거·실제 반론·실행 조건을 나누어 보게 했다. 학생용에도 준거 이름과 계획 안내를 제공하며, 교사용은 각 준거의 부적절한 답·부분 수행·충족 예를 별도로 보여 준다. 타당한 근거와 대응을 갖춘 다른 제안도 수용한다.

초6의 같은40명 중28명과20명이 응답한 사례는 정확한 겹침이 미확인이더라도 최소8명은 겹쳐야 한다. 처음 원고의 단순한 미확인 설명을 이 제약까지 반영하도록 고쳤다. 모둠 총시간을 개인별 평균 시간으로 오해할 수 있던 부분 답 설명도 수정했다. 수치 표8개를 더해 현재 본문 표는14개이며, 표·원문·주요 계산·수치 정답의 대응을25개 검사로 확인한다.

새 초5·6 자료24개에는 교육과정 연결 후보도 기록했다. 주장 쓰기·독자 고려·고쳐쓰기·자료 타당성·매체 신뢰성에 관한5~6학년군 원문을 로컬 별책5 추출본의 실제 행과 대조하고 출처 파일 해시를 저장했다. 이는2022-33 원문 확인과 단원 수준 연결 후보이며 특정 학년 배치·개별 문항의 측정 범위·최신 고시 대조·교사 승인을 모두 완료했다는 뜻은 아니다.

네 번째 확장에서 초2 정보 보충과 초4 그래프의24묶음·104문항을 추가했다. 초2는 필요한 정보·모르는 정보·기본 안내·예외를 구별하고 쓰기10과제에 상황별 준거2개씩을 작성했다. 발문도 ‘정해진 것’, ‘그곳에서 받는 것’처럼 다듬었다. 높은 단계의 본문에서 판단을 먼저 알려 주던 부분은 인물 행동과 상충하는 초안으로 바꾸었다. 정답만 길었던 선택형2개도 수정했다.

초4에는 실제 그래프15개를 SVG와 PNG로 제작하고 범례·줄·축 요소85건을 문항 근거에 연결했다. 빈 범례와 눈금은 학생용 이미지와 대체 설명에 답을 미리 넣지 않는다. 잘못된 명 단위와6에서 시작하는 축은 학생이 검토할 의도된 초안이다. 전이 자료는 연습의6·10 대신8·14를 사용한다. 그래프15개는 로컬 PNG 모음에서 시각 검토했다.

현재 원문 표14개와 그래프15개의 주요 수치·단위·분모·중복·정답 대응을40개 계산·대조 검사로 확인한다. SVG의 실제 기호 개수와 막대 요소, 문제집의 전체 문항·답안 칸·그림 포함 여부와 학생·교사 해설 분리도 검사한다. 초5·6 외 자료의 개별 성취기준 연결은 추가 검토 대기다. 수학의 그래프 기준을 국어의 직접 성취기준으로 바꾸어 기록하지 않는다.

다섯 번째 확장에서 초5 화자의 태도와 정서를12묶음·52문항 추가했다. 창작시14편·68행을 집필해 전후 마음 변화·복합 정서·서로 다른 해석·표현 효과·두 시의 비교·답시를 다룬다. 실제 작가의 이력과 화자의 말은 구별한다. 쓰기10과제에는 상황별 분석 준거를 두고 답시는 새 화자·원시 응답·시적 구성의3준거로 본다. 예시와 다른 감정도 근거와 연결되면 수용한다. 시 제목과 행을 별도 구조로 저장해 두 문제집에14편68행을 보존하는지 검사했다. 새12자료의 작품 의견 나누기 및 해당 비유 효과 기준은 로컬 원문과 대조한 연결 후보이며 교사 승인은 아니다.

음성 제작 경로 점검에는 설치된Microsoft Heami ko-KR를 사용해18초 WAV를 만들었다.16kHz·16bit·mono 구조·무음 여부·클리핑을 검사했다. 최초 샌드박스의PowerShell 권한 검사 실패 뒤 정책 변경 없이 승인된 실행 환경에서 생성했다. 발음·쉼·속도는 청취 검토 대기이며 이 점검 파일은 학습 자료 수에 포함하지 않는다.

여섯 번째 확장에서 초3 모르는 내용 질문을12묶음·52문항 추가했다. 수량·기한·조건의 빈칸, 대답과 질문의 어긋남, 지시 대상, 미확인 전제, 두 자료와 새 역할 상황을 다룬다. 실제 한국어 합성 음성12개196.85초와 교사용 응답자 카드12개를 제작했다. 직접 말하기12과제는 상대에게 질문하고 답을 듣는 수행이며, 메모를 입력했다고 말하기를 완료한 것으로 보지 않는다. 대상과 조건을 드러내는 다른 적절한 표현도 수용한다.

학생용에는 듣기 음성을 내장하고 전체 대본·응답자 답을 넣지 않는다. 교사용에는 대본·응답자 카드·관찰 기록란을 각각12개씩 둔다. S4~S6는 선택형보다 실제 질문을 먼저 표시한다. 이는 교사·짝과 진행하는 학습 순서이며 학생이 다른 문제를 볼 수 없도록 막는 보안 시험 기능은 아니다. 재생 횟수·받은 도움·실제 첫 질문·상대 답·확인 발화를 관찰자가 기록한다. 기록란은 인쇄용이며 자동 학생 수행 데이터가 아니다.

합성 시 요청·입력 대본·WAV 해시를 기록해 최신 원고와 대조한다. 해시를 바꾼 세 보고서를 거부하는 검사도 통과했다.12개 음성은16kHz16bitmono·무음 아님·클리핑0을 확인했지만 발음·쉼·속도 청취 검토는 남아 있다. 음성 파일을 자료 묶음 수에 중복 합산하지 않는다.

일곱 번째 확장에서 초6 반론을 듣고 설명 수정을12묶음·52문항 추가했다. 예외·집단·기간·인과·필수 조건·불분명한 반론·오해한 전제·근거의 범위·사실 정정·복수 조건을 구별한다. 반론을 받았다고 원안을 전부 취소하지 않으며, 틀린 사실은 바로잡고 타당한 장점은 유지한다. 마지막 복합 상황 하나는 기존 전시 소재와의 겹침을 줄이기 위해 파일 이름과 기존 연결을 함께 보존하는 상황으로 바꿨다.

새 음성12개는280.805초이며 전체 듣기 음성은24개477.655초다. 각 상황에 실제 수정 설명과 후속 확인을 관찰하는3준거·기록란을 두었다. 모호한 반론은 구체적인 답을 먼저 들은 뒤 수정하고, 다른 상황의 확인 질문은 첫 설명 뒤에 제공해 첫 수행과 후속 수정을 구분한다. 질문하기와 설명 수정에 서로 다른 진행 안내가 실제로 출력되는지도 검사한다. 발음·쉼·속도 청취 및 실제 교사·학생 확인은 남아 있다.

초6 수치 원고의 한글 수량과 집단·관찰·시범·시간 조건을9개 검사로 추가 대조했다. 전체 수치 검사는49개다. 마지막 시간 조정 과제는 예시의6명씩4분만 정답으로 고정하지 않고 전원 개인 기회·최소3분·매회 준비정리8분·각40분·두 모임 조건을 충족하는 다른 안도 수용한다. 실제 참석 가능일은 별도 확인한다.

여덟 번째 확장에서 초1 짧은 문장 정확히 읽기를12묶음·52문항 추가해 대표 초안 집필 수량을 채웠다. 보이는20문장을 직접 먼저 읽고, 원문 어절71개를 기준으로 첫 읽기·모델 전 자기 수정·지원 뒤 읽기를 구별한다. 모델12개48.91초는 첫 읽기 과제 뒤 닫힌 영역에 표시한다. 진행자가 첫 읽기 전에 목표 문장이나 정답 낱말을 읽어 주지 않게 지시를 다듬었다. 모델 영역을 여는 것만으로 실제 첫 읽기가 검증된 것은 아니며 관찰자가 노출·도움을 기록한다.

초1의 낭독 예시·원문 선택 정답·빠진 말·바뀐 말은24개 원문 대조 검사로 확인했다. 두 문제집 모두20문장을 보존하고 교사용에는 관찰표12개·원문 어절71개를 별도 출력한다. 자연스러운 발음·음운 변동·방언을 철자 불일치만으로 오류 처리하지 않고, 문장부호 이름·목소리 연기·속도를 강요하지 않는다. 원문 그대로 읽는 목표에는 S4 정답이 본문과 같다는 이유만으로 해석 단계 오류 탐지를 적용하지 않는다. 이는 공인 해독 발달 등급이 아닌 기능별 지도 역할이다.

현재 실제 음성 파일은36개526.565초이며 듣기24개와 첫 읽기 뒤 모델12개를 구별한다. 이 숫자를144자료에 추가 합산하지 않는다. 모든 음성은 기술 검사만 통과했고 발음·쉼·속도 청취 검토는 남아 있다. 교사용 기록란은 모두 빈 양식이며 실제 학생 수행·승인·난도 자료를 생성한 것이 아니다.

아홉 번째 검토에서는 원문 연결 후보가 비어 있던72자료를 분류했다.27자료는 국어 성취요소 일부의 후보이고45자료는 학습 보조·타교과 연계로 두어 직접 국어 측정 주장을 보류한다. 기존72자료의 연결 후보와 합치면 국어 기준 연결 후보99, 보조·타교과 연계45다. 모든144자료에 원문 연결 또는 검토 판단이 있지만 이것이 개별 문항의 타당성·학년 배치·성취기준 전체 승인이라는 뜻은 아니다. 초4 그래프는 수학 해석 요소와 국어 발표 자료 제작을 구별한다.

교사용에는72개 범위 패널과312문항별 측정 범위 메모를 추가했다. 학생용에는 이 메타데이터가 나오지 않는다. 초2 낱말 도입과 초3 비교 읽기S5 두 자료를 실제로 수정했고3자료의v1 전체 원고·문항은 보존했다. 수정본v2는 문항과 근거 참조 버전도 함께 갱신했다. 비교 읽기에서는 판단 이유를 미리 알려 주던 본문을 상충 의견·검토 상황으로 바꾸고, 오답도 실제 비교 기준·목적의 혼동을 반영하게 다듬었다.

이번 원문 대조는 로컬2022-33 원문과 해설에 대한 확인이다. 국립국어원의 동음이의어·다의어 처리 설명 및2026-1호 고시의 존재도 참고했지만 최신 통합 교육과정 전체를 전량 대조했다고 주장하지 않는다. 자세한 근거와 분류는 조사 기록 및 범위 원장에 둔다.

자동 검사는 문장 ID·근거 위치·해시·문항 수·선지·루브릭·단계별2자료·전이 자료 공개 정책과 중복 후보를 확인했다. 단계 적합성·정답 유일성·학년 수준·실제 난도는 교사와 학생 검토 대기다. 브라우저 실행 검수는 이번 작업에서 수행하지 않았다.
