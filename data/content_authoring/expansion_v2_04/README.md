이름만 달리한 난도 등급 대신 실제 읽을 행동을 정했다. 반복 말과 움직임을 잇기, 말 뒤의 뜻 짐작하기, 배경의 역할 풀기, 목소리의 주인 짐작하기, 인물 평가의 근거 따지기, 실제 과거와 아직 오지 않은 일을 구별하기다. 이번에 채운 것은12수행-단계 칸이며 각 수행의 여섯 단계 전체가 아니다.

8편의 이야기는 짧은 인물 장면에서 여러 장면의 고학년 서사까지 구성했다. 초5에서는 책을 함께 읽게 하고 싶은 마음과 고유한 기억을 지키는 마음, 새 길을 소개하고 싶은 기대와 확인하지 못한 조건 사이의 갈등을 다룬다. 인물을 무조건 착함·이기적임으로 판정하지 않는다. 초6에서는 회상에서 현재로 돌아오는 단서, 기억과 상상·편지·현재 답장의 다른 확실성을 연결한다. 길게 쓰려고 사건과 결론을 반복하지 않는다.

주 응답12개에는 **분석적 준거28개**를 두고 선택형보다 먼저 제시했다. 초1의 주 응답은 반복 표현을 찾거나 비교하는 활동이므로 실제 낭송을 했다고 계산하지 않는다. 다른 감정·해석은 구체적인 작품 단서와 연결하고 사건에 모순되지 않으면 수용한다. 실제 작가의 가족사나 학생의 성격·흥미를 작품의 나만으로 확정하지 않는다.

자체 편집에서 다음을 보완했다.

- 눈이 내리기 전날 잃은 장갑의 발자국을 새 눈에서 찾는 것처럼 읽힐 수 있어, 눈이 내린 뒤 조금 전 다녀온 일로 시간 관계를 맞췄다. 비슷한 발자국만으로 모두 자기 것이라 확정하지 않게 기억·빨간 실을 함께 읽는다.
- 점선 길의 메모를 계단이 이미 확인된 사실이 아니라 앞으로 계단이 있는지 확인할 질문으로 명료화했다. 확인 계획을 확인 완료로 올려 읽지 않는다.
- 인물의 의도를 단정하거나 작품에 없는 극단적 행동을 고르는 선지보다, 실제 나온 다른 행동·장소·시간을 대조하는 오답으로 바꿨다.
- 직접 대화와 편지에는 인용 부호를 넣어 말·서술을 구별했다. 시의 나와 실제 작가를 분리하고, 우체통 같은 화자는 이름 하나보다 여러 구절의 연결로 평가한다.
- 마지막 이야기의 가상 독자 의견을 작품 본문과 표시로 구별했다. 작품 목록의 이야기 글자 수에서는 외부 독자 의견을 빼고, 자료 전체 읽기 부담은 별도 문자 수로 남겼다.

S4의 직접 근거 찾기 보조 문항1개는 자동 단계 경고로 남아 있다. 원문 인용을 요구하는 활동이라 직접 인용 답을 허용한다고 자체 검토했다. 경고를 지우거나 이 보조 문항을 주 해석 수행으로 바꾸어 집계하지 않는다. 독립 교사 검토는 아직 없다.
