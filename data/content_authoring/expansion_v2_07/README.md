## 음성과 수행의 구별

새 **WAV12개·247.225초(약4분7초)**를 Windows 기본 한국어 음성 Microsoft Heami로 합성했다. 단일 음성이 역할 이름을 읽으며 이어지는 창작 대본이다. 실제 어린이 대화 녹음이나 여러 성우의 자연 대화를 재현한 것으로 소개하지 않는다. 16kHz·16bit PCM 파일의 구조·길이·무음 여부·입력 문구와 파일 해시를 확인했고 최대 클리핑 비율은0이었다. **발음·쉼·속도·학년 적합성의 청취 검토는12개 모두 대기**다.

학생용에는 음성 재생기와 과제만 두고 전체 대본·상대 응답 카드·채점 기준은 제외했다. 교사용에는 이를 제공한다. 인쇄본에서는 진행자가 대본을 읽을 수 있으며 대독·반복 재생·낱말 풀이·질문 틀·보완대체 의사소통 등의 지원을 기록한다. 실제 말하기를 관찰하지 않고 메모나 선택형 정답만으로 수행을 완료 처리하지 않는다.

모든 자료에서 **첫 듣기 → 학생 첫 발화 → 상대 실제 응답 → 학생 후속 발화**를 구별한다. HTML에 주 과제를 먼저 배치했지만 뒤 문항 노출을 기술적으로 봉인하지는 않으므로 노출 시점을 기록해야 한다. 아직 실제 학생 발화·점수·친구의 실제 반응은 없다.

## 검토하고 고친 점

상대가 말할 차례를 주고 답을 확인하는 행동을 보며 목소리 크기·말의 빠르기·시선·성격으로 채점하지 않는다. 초1에서 상대 답으로 새로 제공한 수량·보관 장소를 처음 음성에 이미 있던 정보와 구별했다.

초3에서 새 정보가 첫 제안을 뒷받침하면 유지 이유를 말해도 수용한다. 다른 친구에게 무조건 동의하거나 첫 의견을 반드시 바꾸는 것을 목표로 삼지 않는다. 게시판의 빈 공간 크기가 없는데 모든 사진이 들어간다고 단정하지 않는다.

초4의 엽서 절차는 실제 우편 발송 규정이 아닌 가상 놀이의 규칙이다. 메모9장을 제출자9명이라고 확정하지 않고 내용6장·3장과 사람별 기록 부재를 구별한다. 초5에서도 표지를 다시 본 행동을 이해 실패로 단정하거나 설문과 관찰 중 하나가 반드시 거짓이라고 결정하지 않는다.

초6의 배너 과제에서는 다른 변화뿐 아니라 비교 기간·집계 방법을 묻는 질문도 적절하다. 이 경우 진행자는 제공되지 않은 답을 지어내거나 아직 묻지 않은 온라인 창구 정보를 먼저 주지 않는다. **미확인이라는 답을 받아 그 확인을 이어 가는 응답도 완전 수행으로 수용**하도록 응답자 안내와 준거를 맞췄다.

보조 선택형2개는 정답만 길게 보이는 후보로 잡혀 뜻을 보존해 간추렸고 해당2자료와 연결 문항·근거를 **v2**로 맞췄다. 오답을 늘여 길이만 맞추지 않았다. 대본은 보존하면서 최종 원고·음성 의뢰·생성 보고서의 연결 해시를 갱신했다. [수정 전 원고](revision_history/2026-11-18-before-option-review-sets.json)와 [음성 의뢰서](revision_history/2026-11-18-before-option-review-listening_requests.json)를 보존했다.
