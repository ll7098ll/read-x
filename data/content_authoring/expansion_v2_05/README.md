## 집필·보완한 점

- 대상과 행동, 건넨 사람과 받은 사람, 문장의 말 차례와 역할을 구별했다. 이·가 또는 은·는만 보고 모든 문장의 행동 주체를 찾는 규칙은 만들지 않았다.
- 질문 형식과 전달 목적을 구별했다. 초2에서 문을 닫아 줄래에 담긴 부탁을 상황과 행동으로 읽되, 실제 억양을 듣고 판단했다고 주장하지 않는다.
- 문맥에서 자연스러운 생략과 처음 읽는 독자에게 필요한 정보의 누락을 구별했다. 목적에 맞게 보충하되 생략된 문장을 모두 비문으로 처리하지 않는다.
- 초4에서는 그다음을 그래서로 바꾸면서 더해지는 인과 판단을 비교하고, 동시에 바뀐 안내 표지 때문에 조명만의 효과를 단정할 수 없게 했다. 목적과 관계를 보존하는 다른 접속 표현도 수용한다.
- 초5의 무대 장면에서 예시 답에도 수식 범위의 모호함이 남아 **자료 v2**로 수정했다. 문장을 나누어 공연한 사람과 만난 사람을 각각 밝혔다. 수정 전 전체 초안은 [이력](revision_history/2026-11-18-before-scope-rewrite.json)에 보존했다. 본문을 바꾼 수정이 아니라 발문·예시 답·교사용 안내 수정이다.
- 초6에서는 예약과 시간 조건, 설문 완료와 선착순 제한, 일부 미참석과 전원 미참석, 도구 대여 금지와 설명회 참석 허용을 따로 다뤘다. 모두 오지 않았다는 말만으로 참석 인원을 확정하지 않는다.
- 초2·3의 선택형 3개도 장면과 동떨어진 오답을 줄여 장소·날짜와 시각, 상태·방법 질문과 행동 부탁, 문장 순서와 주체·대상의 실제 혼동을 비교하도록 보완했다. 해당 3자료도 v2이며 수식 범위를 수정한 자료와 합쳐 v2 자료는 4개다.
- 국립국어원 자료 3개를 개념 집필에 참고했다. 답변을 제공하지 않은 온라인가나다 질문 1개는 문법 해설의 근거에서 제외했다. [조사 원장](../../../research/language_v2_sources_2026-11-18.json)에 적용 범위와 한계를 기록했다.

## 검사 결과와 남은 일

`python -X utf8 scripts/build_language_v2.py`로 원고 생성, 기존 5개 V2 배치와 중복 후보 검사, 근거 위치·정답·준거·버전·교육과정 연결 검사, 학생용·교사용 HTML 생성 및 정적 대조를 수행했다. **구조 오류 0, 정답 길이 검토 후보 0, 설정된 임계치의 유사 본문 후보 0**, 구조·일부 의미 관계의 기계적 일관성 확인 63건이다. 이는 정답 유일성이나 실제 학년 난도의 증명이 아니다.
