글자 수는 문단 사이 공백을 포함한 `charCount`다. 학년별 규준이나 가독성 승인을 뜻하지 않는다. 저학년은 몸의 부분과 역할, 가까운 변화의 연결을 읽고, 고학년은 정의의 적용 범위·기록과 실제 전승·서로 다른 대상의 결과·조건이 다른 비교의 한계를 다룬다. 어려운 낱말과 분량만 늘려 단계를 구분하지 않는다.

이번에 새로 채운 것은 **6수행의 선택한 한 단계씩, 6수행-단계 칸**이다. 같은 수행의 여섯 단계 전체나 독립·전이·지연 확인 공급을 모두 완료한 것이 아니다. A·B는 서로 다른 글이지만 같은 원천이나 개념을 공유할 수 있으므로 사전 사실 노출을 확인해야 한다.

사실 원장은 [조사 기록](../../../research/nonfiction_v2_sources_2026-11-17.json)에 둔다. Smithsonian, NASA, NOAA, NPS, Kew, 유네스코한국위원회, EPA의 출처와 확인한 문단·사실을 구별했다. 지문에 연결한 **44개 근거 위치**를 원문 기반 사실과 편집상 적용으로 나누어 저장했다. 출처가 있다는 사실만으로 새 한국어 글의 정확성이나 모든 추론이 승인되었다는 뜻은 아니다.

씨앗 자료는 영어 Burdock을 우엉으로 표기하고 씨와 열매가 함께 이동하는 경우를 구별했다. 화석에서는 잎 자국과 동물 발자국을 같은 범주로 처리하지 않는다. 수분은 꽃 방문이나 수정과 같지 않으며, 관찰하지 못한 것을 발생하지 않았다고 단정하지 않는다. 안개 설명은 공기를 수증기 통처럼 보는 표현을 고치고 냉각·물방울·지면 가까운 위치를 연결했다.

무형문화유산 설명은 공동체·전승·재창조·기록과 배움의 역할을 다룬다. 지도에 실린 과거 등재 수를 현재 현황처럼 쓰지 않고, 가상 마을이나 공방이 실제 등재 유산이라고 주장하지 않는다. 생태계·온도 자료의 비판 과제는 본문이 오독의 정답을 미리 해설하던 부분을 서로 다른 주장과 원자료로 바꿔 학생이 직접 검토하게 했다.

[학생용 문제집](../../../output/expansion-v2-02/학생용_문제집.html)과 [교사용 해설집](../../../output/expansion-v2-02/교사용_해설집.html)을 분리했다. 학생용 HTML·원고에도 바탕 출처를 표시하고, 교사용에는 사실 위치와 교육과정 관계·채점 기준을 제공한다. 국어 성취요소 일부 후보는 초6의 2자료이며 나머지 10자료는 읽기 이해의 준비·보조 관계로 기록했다. 사실 출처 검토와 국어 교육과정 승인·교과 지식 평가를 혼동하지 않는다.
