# Read X — 브랜드 CI · UI/UX 테마 킷 v3

기준일: 2026-11-14 · 공식 표기: **Read X / 리드엑스**

이 문서는 ReadX-Ray Pro / Rx-5 및 v2 디자인 가이드를 대체하는 현재 브랜드 기준이다. 브랜드를 ‘읽는 방법을 배우는 문해력 코스웨어’로 재정의한다. 이전 문서는 프로젝트 이력으로만 사용한다.

## 1. 브랜드의 중심

**읽으라고 하기 전에, 읽는 방법부터.**

글자를 읽을 수 있어도 어디에 주목할지, 문장을 어떻게 연결할지, 무엇을 이해했다고 말할지 막막한 학생이 있다. Read X는 읽는 과정에서 할 수 있는 구체적인 행동을 시범과 안내로 보여 주고, 다른 글에서도 스스로 사용하도록 돕는 문해력 코스웨어다.

- 브랜드 약속: 읽는 방법을 알면, 읽는 힘이 자랍니다.
- 제품 설명: 읽는 방법을 배우는 문해력 코스웨어.
- 학생에게: 어디부터 읽을지, 함께 찾아볼까요?
- 교사에게: 학생이 어떻게 읽었는지 보고, 다음 도움을 정합니다.
- 보호자에게: 아이가 찾은 근거와 직접 쓴 문장에서 배움을 확인합니다.
- 핵심 성격: 명확한 안내 / 차분한 집중 / 작은 발견 / 점진적인 자립.

내부 설계에서는 학생의 어려움을 구체적으로 다루되, 학생에게 ‘못 읽는 아이’, ‘결손’, ‘긴급 처방’ 같은 정체성·의료 비유를 붙이지 않는다. 서비스의 가치는 독서량이나 시험 점수만으로 설명하지 않는다. 아직 측정하지 않은 학습 효과를 보장하지 않는다.

## 2. 이름과 CI

| 항목 | 규칙 |
|---|---|
| 영문 | **Read X**. Read와 X 사이 한 칸. 모든 화면·문서에서 동일하게 사용 |
| 국문 | **리드엑스** |
| 병기 | Read X 리드엑스 |
| 제품 설명과 결합 | Read X — 읽는 방법을 배우는 문해력 코스웨어 |
| 서비스 내 공간 | 나의 읽기 / 선생님 수업실 / 보호자 읽기 기록 / 학원 운영실 |
| 코드 식별자 | 기존 ReadXBrand, readx, rx 접두사는 호환성을 위해 유지 가능 |

X는 **글과 생각이 만나는 지점**이다. 잉크색 획은 글의 단서, 블루 획은 생각의 연결을 뜻한다. 두 획 사이의 간격은 작은 크기에서도 교차를 분명하게 보여 준다. 라임 바탕은 발견을 나타낸다.

심벌 원본: 64×64 viewBox, 모서리 16, 주획 8, 분리획 14. 주획은 (19,18)→(45,46), 연결획은 (45,18)→(19,46). 로고를 기울이거나 늘이지 않는다. 임의 그라데이션·그림자를 더하지 않는다.

- 심벌 기본 크기: 40px. 일반 UI 24px 이상, 파비콘 16px.
- 전체 로고 최소 너비: 112px. 그보다 작으면 심벌 사용.
- 보호 공간: 심벌 너비의 1/4. 최소 표시 크기에서도 바깥 여백 유지.
- 밝은 배경: 잉크 워드마크 + 블루 X + 컬러 심벌.
- 어두운 배경: 흰 워드마크 + 라임 X + 컬러 심벌.
- 인쇄: 한 색으로 출력하는 별도 단색 심벌 사용. 색으로 의미를 구분하지 않아도 형태 유지.
- 전체 워드마크 SVG는 Pretendard 글리프를 윤곽선으로 변환해 폰트 설치 없이 사용 가능.
- 정원·사진 등 기존 콘텐츠 이미지는 보조 소재이며 CI 심벌을 대신하지 않는다.

## 3. 테마와 디자인 토큰

시각 콘셉트: **읽기 안내가 놓인 조용한 책상**. 종이 면, 번호가 있는 읽기 순서, 선택한 문장, 짧은 생각 메모를 핵심 모티프로 사용한다. 학생의 읽기 화면에 장식용 차트·뱃지·움직임을 과도하게 넣지 않는다.

|---|---|---|
| ink | #202D40 | 기본 본문·제목·로고·관리 헤더 |
| action | #3157D5 | 주요 행동·현재 단계·포커스 |
| action-hover | #2445B5 | 주요 행동 hover |
| discovery | #DDF58A | 브랜드 포인트·오늘의 읽기 카드 |
| paper | #F7F8F2 | 앱·지문 바탕 |
| surface | #FFFFFF | 입력·도구·카드 |
| muted | #586579 | 보조 설명 |
| line | #D9DFE8 | 장식 구분선·카드 경계 |
| control-line | #7D899B | 입력·버튼 등 인지해야 하는 조작 경계 |
| connection | #EEEAFE | 사고 시범·연결 메모 |

배경 70%, 잉크·중립색 20%, 강조 10%를 구성 출발점으로 삼는다. 라임은 작은 본문 글자색으로 사용하지 않는다. 블루 버튼에는 흰 글자, 라임 카드에는 잉크 글자. 선택·성공·오류는 색과 함께 체크·라벨·테두리를 쓴다.

CSS 원본: `webapp/src/read-x-tokens.css`. JSON 배포본: `webapp/public/brand/read-x-tokens.json`. 생성 스크립트가 CSS에서 JSON을 추출하므로 수기로 다른 색을 입력하지 않는다. 기존 `--rx-*`와 `--ed-*`는 새 의미 토큰에 연결한다. 하위 기능의 기존 고정색은 개별 교체가 남을 수 있다.

## 4. 글자·아이콘·레이아웃

기본 서체는 프로젝트에 저장된 Pretendard Variable이다. UI와 지문에 같은 고딕 계열을 사용하며, 고급 학년의 명조 선택 기능은 기존 읽기 설정에서 유지 가능하다. 서체 변경만으로 학습 효과나 특정 장애에 대한 효능을 주장하지 않는다.

| 구분 | 시작 규격 |
|---|---|
| 브랜드 큰 제목 | 48–64px / 700, 모바일 35–38px |
| 화면 제목 | 28–36px / 700, 행간 1.35–1.5 |
| UI 본문 | 16px / 400–500, 행간 1.6–1.8 |
| 도움·보조 | 13–14px, 읽기 핵심 안내를 이보다 작게 넣지 않음 |
| 읽기 1–2학년 | 24px 기본, 짧은 문장과 한 번에 한 질문 |
| 읽기 3–4학년 | 22px 기본, 연결어와 문단 관계 안내 |
| 읽기 5–6학년 | 20px 기본, 문단 구조·주장·근거 연결 |

학년군 값은 설계 시작점이다. 개인 글자 크기 설정이 우선하며 실제 학습자 관찰로 조정한다. 지문 행간 1.9, 폭 최대 34em, 왼쪽 정렬, 한국어 어절 단위 줄바꿈. 한 문장을 가로 스크롤로 읽게 하지 않는다. 지문 확대 때문에 답안이 초기화되지 않게 한다.

- 간격: 4 / 8 / 12 / 16 / 24 / 32 / 48px.
- 모서리: 도구 8px / 카드 16px / 큰 면 24px.
- 아이콘: Lucide, 20–24px 기본, 선 두께 1.75–2. 아이콘 단독 버튼은 이름 제공.
- 콘텐츠 최대 폭: 서비스 1200–1280px, 읽기 스튜디오 1480px.
- 900px 이하: 2열 학습 화면을 본문/활동 전환형으로. 600px 이하: 카드 1열, 좌우 16–20px.
- 읽기 설정: 종이 / 세피아 / 야간 + 글자 크기. 마케팅·관리 화면 전체를 자동 야간 전환하지 않는다.
- 일반 버튼 48px 높이, 터치 영역 최소 44px. 포커스 3px + 간격 4px.
- 동작 160ms 기본. reduced-motion 설정에서는 장식·이동 애니메이션 제거.

## 5. 읽는 방법과 수업 단계를 구분한다

**읽기 전략**은 내용에서 학생이 하는 일이다: 살펴보기 → 단서 찾기 → 관계 연결하기 → 내 말로 정리하기. 모든 글에 네 가지를 기계적으로 요구하지 않고, 해당 수업의 한 가지 목표를 정한다.

**수업 단계**는 도움의 정도가 달라지는 과정이다:

| 단계 | 학생 화면 | 설계 규칙 |
|---|---|---|
| 1. 시범 보기 | ‘어디를 보고 왜 이렇게 생각할까?’ | 교사의 사고를 짧게 보여 줌. 결과만 공개하지 않음 |
| 2. 함께 읽기 | 질문과 위치 힌트를 따라 시도 | 처음부터 답을 밝히지 않고 필요한 도움 선택 |
| 3. 혼자 읽기 | 새로운 글에 같은 방법 적용 | 정답·근거 미리 강조하지 않음. 도움을 다시 요청할 수 있음 |
| 4. 돌아보기 | 내가 쓴 방법과 다음 행동 기록 | 점수와 별개로 선택한 근거·자기 설명·도움 사용을 보여 줌 |

학습 중 ‘근거 선택’은 선택했다는 기록이다. 이것만으로 이해·숙련·독립 수행을 판정하지 않는다. 보고서에는 무엇을 관찰했는지와 어느 도움을 썼는지 함께 표시한다. 전이는 새로운 글에서 같은 방법을 사용했을 때 검토한다.

읽기 중 막힘: 위치 힌트 → 관계 질문 → 짧은 시범. 언제든 시범으로 돌아갈 수 있다. 오답 때문에 전체 지문과 작성 내용을 지우거나 수업을 강제 종료하지 않는다.

## 6. 정보 구조

| 사용자 | 기본 화면 | 최우선 정보 | 주요 행동 |
|---|---|---|---|
| 학생 | 나의 읽기 | 오늘의 방법, 이어할 단계 | 이어 읽기 / 시범 보기 |
| 학생 | 읽기 스튜디오 | 지문, 한 가지 질문, 도움 | 근거 담기 / 이유 쓰기 |
| 학생 | 읽기 기록 | 내가 쓴 문장, 사용한 방법 | 다시 읽기 / 새 글에서 해 보기 |
| 교사 | 선생님 수업실 | 오늘의 목표, 학생별 관찰 | 수업 배정 / 근거와 응답 검토 |
| 교사 | 학생의 과정 | 근거·설명·도움·재시도 | 구체적인 다음 질문 제공 |
| 보호자 | 보호자 읽기 기록 | 배운 방법, 아이의 문장 | 집에서 나눌 질문 확인 |
| 운영자 | 학원 운영실 | 반·계정·수업 운영 | 운영 업무 수행 |

평가·모의고사는 학습과 별도 입구로 구분한다. 학생 첫 화면의 대표 CTA는 읽기 학습이다. 보호자에게 근거가 없는 백분위나 ‘문해력 완성’ 뱃지를 보여주지 않는다.

## 7. 말투와 상태

짧고 구체적인 문장, 한 번에 하나의 요청, 해요체. 실제 저장·제출·공개 상태와 일치하는 동사를 쓴다.

| 상황 | 권장 문구 |
|---|---|
| 시작 | 오늘은 까닭을 찾아볼까요? |
| 시범 | ‘그래서’ 앞 문장에 왜 그런 일이 생겼는지 나와 있어요. |
| 도움 | 앞 문장도 함께 살펴볼까요? |
| 선택 완료 | 근거를 담았어요. 왜 도움이 되는지 말해 볼까요? |
| 입력 없음 | 생각을 한 문장 써 주세요. ‘왜냐하면’으로 시작해도 좋아요. |
| 저장 실패 | 저장하지 못했어요. 작성한 내용은 그대로 있어요. |
| 빈 기록 | 첫 번째 읽기를 기다리고 있어요. |
| 기록 해석 | 시범을 본 뒤 까닭 문장을 선택했어요. |

## 8. 이번 적용 범위

완료한 기준과 인터페이스:

- 새 CI 심벌·워드마크·컬러/단색/반전 SVG, 파비콘 및 공통 React 로고.
- 디자인 토큰 CSS/JSON, 공통 테마 연결, 브랜드 명칭과 핵심 소개 문구.
- `#/brand` 인터랙티브 킷: 컬러 복사, 읽기 바탕·글자 크기·학년군, 선택/입력/도움 모달, 시범·근거 선택, 역할별 화면 예시, 파일 다운로드.
- 서비스 첫 화면: 읽는 방법을 중심으로 한 소개와 짧은 시범.
- 기존 디자인 가이드 모달과 문서 진입점 교체.

킷의 학생·교사·보호자 화면은 **설계 예시**다. 실제 데이터와 연결하지 않는다. 전체 기존 세부 활동을 새 컴포넌트로 교체하거나 모든 수업 엔진을 새 4단계로 재구현한 작업은 아니다. 다음 개발에서는 기존 수업 종류별 단계와 저장 상태를 이 규격에 맞춰 순차 적용한다. 현재 계정·평가·콘텐츠 로직은 기존 구현을 따른다.

## 9. 산출물과 유지

- 인터랙티브: 웹앱 `#/brand`.
- UI 명세: `READ_X_COMPONENT_SPEC_V3.md`.
- 제작 스크립트: `scripts/build_read_x_kit.py`.
- 배포 에셋: `webapp/public/brand/read-x-*`, `readx-symbol*.svg`.
- 일괄 다운로드: `read-x-kit.zip`.
