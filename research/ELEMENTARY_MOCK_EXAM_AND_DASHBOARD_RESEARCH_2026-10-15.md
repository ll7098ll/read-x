사용자가 확정한 대상은 **초등학생용 수능형 문해력 모의고사**다. 수능 국어에서 참고할 것은 글의 근거를 찾아 정보를 연결하고 판단하는 평가 방식이다. 초등학생에게 적용할 분량·시간·어휘·선택지·성취 수준은 별도로 설계한다. 제품은 학원·공부방의 정규 학습과 연결하고, 시험 결과가 다음 학습과 목표 달성 확인으로 이어지게 한다.

실행 범위·화면·데이터·개발 순서는 [개발 계획](../docs/ELEMENTARY_MOCK_EXAM_AND_DASHBOARD_PLAN_2026-10-15.md)에 정리했다.

ETS의 일반 측정 원리를 한국 초등 문해력에 적용하는 구체적 방법은 자체 검증이 필요하다.

## 초등 수능형 문항으로의 전환

아래는 공식 수능의 초등용 기준이 아닌 ReadX의 출제 설계안이다. 기존 [읽기 품질 개선 계획](../docs/READING_QUALITY_REVISION_PLAN_2026-10-14.md)의 직접 확인 → 정보 연결 → 추론 → 근거 판단 → 새 상황 적용 위계를 계승한다.

| 평가할 행동 | 초등 문항의 예 | 확인할 증거 |
| --- | --- | --- |
| 직접 확인 | 글에 설명한 대상의 특징 고르기 | 정답과 근거 구절 |
| 정보 연결 | 두 문단에서 같은 점과 다른 점 찾기 | 두 정보의 대응 관계 |
| 추론 | 조건이 바뀌면 결과가 어떻게 달라지는지 고르기 | 조건과 결과의 연결 |
| 근거 판단 | 주장에 맞는 자료와 부족한 근거 구별하기 | 판단 기준과 실제 자료 |
| 새 상황 적용 | 새 사례나 도표를 본문의 원리로 설명하기 | 기존 원리와 새 사례의 대응 |
| 문학 이해 | 인물의 말·행동으로 마음이나 변화를 해석하기 | 작품 속 표현과 해석의 관계 |
| 언어와 매체 이해 | 문맥 속 낱말, 안내문·광고·표의 정보 판단하기 | 문맥·목적·대상에 맞는 해석 |

초1~2는 3지선다, 초3~4는 4지선다, 초5~6은 5지선다를 기본으로 한다. 문항 수, 제한 시간, 글 길이와 난도는 별도 파일럿 변수다. 읽기 평가의 본문을 읽어 주는 기능은 수행 조건을 바꾸므로 지원 응시로 기록하고 일반 조건의 비교집단과 바로 합치지 않는다.

수능처럼 한 지문 묶음에 여러 문항을 두되 한 문항의 정답이 다음 문항을 직접 알려 주지 않게 한다. 시험 중에는 힌트·정답·해설을 제공하지 않고, 종료 후 같은 문항의 해설·사고 과정 복습을 연다. **종료 후 복습의 성공은 최초 응시 성적이나 새 지문 전이 성적으로 소급하지 않는다.**

공식 예시문항의 확보 경로는 [교육부 2028학년도 대입 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=103113&lev=0&m=020402&opType=N&page=1&s=moe&searchType=null&statusYN=W)의 첨부 자료다. 이번 조사에서는 안내 본문을 확인했으며, 첨부 PDF 전체 문항의 대조 분석은 완료하지 않았다. 실제 집필 착수 때 원본의 국어 예시문항을 문항별로 분석하고, 본문·선지·작품의 사용 조건을 확인한다. 첫 상품의 본문과 문제는 자체 집필·검수하는 방식을 기본으로 한다.

## 기존 설계에서 이어갈 것과 정리할 것

기존 [세부목표와 사고 과정 전략](../docs/GOAL_PROCESS_CONTENT_STRATEGY.md)의 핵심인 세부목표, 근거, 독립 수행, 새 지문 전이를 그대로 이어간다. 학생은 시험 점수뿐 아니라 어떤 글에서 어떤 조건으로 목표 수행을 보여 주었는지 확인할 수 있어야 한다.

과거 조사 문서의 D1~D6는 **제품 내부의 오답 편집 분류**로 사용한다. 평가원의 공식 오답 분류이거나 선택한 선지만으로 인지 결손을 확정할 수 있는 검사 체계로 표현하지 않는다. 현재 CBT의 `KICE CBT 수능 실전 모의평가` 문구도 정식 제품에서는 `ReadX 수능형 문해력 모의고사`로 바꾼다.

과거의 SmartScore 가산 방식이나 고정 백분위·성장 점수는 새로운 성취 판정의 근거로 사용하지 않는다. 시험 점수, 수행 수준, 학습 완료, 학습 습관을 서로 다른 값으로 저장하고 표시한다.

## 전국 비교와 성장 분석의 설계 조건

전국에서 참여 가능한 시험을 운영하는 것과 전국 초등학생을 대표하는 규준을 확보하는 것은 다른 작업이다. 초기에는 동일 회차·학년·시험지·응시 조건의 **ReadX 참여자 내 비교**를 제공한다. 참여자 수·기관 수·집계 시각·최초 응시 기준을 함께 표시한다. 표본이 커져도 지역·기관·학생 구성의 대표성이 자동으로 확보되지는 않는다.

월별 시험 난도가 달라지면 원점수 차이에 시험지 차이가 섞인다. 초기 화면은 회차별 점수와 평가 범위를 나란히 보여 주고, 서로 다른 시험의 점수 차이를 능력 성장치로 자동 변환하지 않는다. 장기 성장 척도는 공통 기준 문항을 통한 시험 연결과 표본 검증을 별도 개발한다. 이 판단은 [ETS의 비교 가능성 원리](https://www.ets.org/research/policy_research_reports/publications/periodical/2020/kgqh.html)를 참고한 제품 설계다.

대시보드의 성취 지표는 관찰 수가 적으면 비율 대신 `2문항 중 1문항 성공 · 추가 확인 필요`처럼 표시한다. 미평가·검토 대기·미응답·오답을 각각 유지한다. 작은 분모의 100%나 도움을 받은 정답을 완전한 숙달로 바꾸지 않는다.

## 도입 우선순위

1. **첫 단계:** 초5·6 학년별 미니 모의고사와 실제 개인 학습이력, 성적 분석, 목표 상태를 연결한다.
2. **다음 단계:** 독서·문학·언어와 매체를 포함한 학년별 시험지와 학원 연합 회차 운영을 완성한다.
3. **운영 확장:** 초3·4, 초1·2로 확대하고 충분한 유효 응시 자료가 있는 집단부터 참여자 비교를 제공한다.
4. **측정 고도화:** 전국 규준, 시험지 간 동등화, 종단 성장 척도는 별도의 측정 설계와 검증을 거친다.

다양한 차트는 이 단계들을 설명하는 수단이다. 첫 화면에는 최근 성적·현재 목표·오늘 할 일만 우선 제시하고, 상세 분석에서 학습 달력·회차 추이·영역 막대·목표 지도·과정 분석·오답 목록을 탐색하게 한다.
