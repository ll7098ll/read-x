## 조사 대상과 근거 수준

공개 자료를 읽는 범위에서 조사했으며 로그인 후 수업 수행·실제 PDF 출력·응답 지연·채점 품질은 비교하지 않았다. 서로 다른 제품의 기능 수를 합산해 우열 점수를 만들지 않았다.

## READ에서 확인한 경험

리드포스쿨은 진단 결과를 바탕으로 학습을 배정하고, 지문 읽기·어휘·문제 풀이·제목·요약·핵심 문장 활동을 안내한다. 리드AI는 진단 결과와 다음 독서·훈련을 연결하는 학원 상담 경험을 강조한다. [리드포스쿨 소개](https://www.readfor.school/ko), [리드AI 소개](https://readai.kr/)

공식 사용 설명서는 다음 화면 구조를 보여준다. PDF 쪽수는 1부터 센 파일 페이지이며 인쇄 쪽수와 다르다. 매뉴얼의 일부 예시 날짜는 과거 날짜이므로 업데이트일을 모든 화면의 제작일로 간주하지 않는다. [공식 사용 설명서](https://visualcamp.notion.site/pdf-1c82facb40e181f998cdf7181b0b925f)

| 화면 | 직접 확인한 구성 | ReadX에 적용할 판단 |
| --- | --- | --- |
| 학생 과제 | PDF 19쪽. 클래스와 과제 카드, 수업/마감 과제, 활동 칩, 진행률, 시작·결과 버튼 | 오늘 과제의 상태와 행동을 한곳에 배치 |
| 교사 참여 현황 | PDF 15쪽. 미시작·진행·제출 요약, 학생별 완료도와 현재 단계 | 전체 통계에서 개별 학생 확인으로 곧바로 이동 |
| 과제 결과 | PDF 16쪽. 학생·과제 선택, 단계별 결과, 정오표, 답안·정답·해설 | 점수에 대한 근거를 다른 메뉴에서 찾게 하지 않음 |
| 학습 추이 | PDF 38쪽. 과제별 추이와 선택, 비교 정보 | 차트의 각 점을 해당 과제 기록과 연결 |
| 평가 기록 | PDF 41·48쪽. 회차·평가일·소요시간·결과, 보고서 조회와 다운로드 | 상담 결과의 시점과 평가 조건을 명시 |
| 읽기 설정 | PDF 55쪽. 예문과 글씨 크기 설정 | 학생이 설정의 결과를 즉시 확인 |

시각적으로 밝은 배경과 민트 계열 행동 버튼, 상태 문구, 둥근 카드가 사용된다. 학생 화면은 과제의 시작과 이어하기에, 교사 화면은 목록과 상세 확인에 무게를 둔다. 이 역할 차이가 색상보다 중요한 벤치마크다. 위 표의 같은 공식 매뉴얼 화면에 근거한다.

RoCAT의 공개 결과 이미지는 레벨 비교, 네 영역 요약, 학습 전략을 한 화면에 배치한 설명용 이미지다. 시선추적이나 메타인지 진단의 측정 타당성을 이 이미지로 확인할 수는 없다. ReadX에는 결과에서 다음 활동으로 이어지는 설명 방식을 적용한다. [RoCAT 안내](https://readai.kr/rocat), [공식 설명 이미지](https://readai.kr/marketing/images/rocat-result.png)

## 러니에서 확인한 경험

러니는 자동으로 제공하는 오늘의 학습과 교사가 선택하는 클래스 학습을 구분한다. 교사는 콘텐츠를 탐색해 배정하고, 학생 응답과 학습 현황을 확인한다. 학생은 튜터의 질문과 피드백을 따라 학습한다. [러니 공식 소개](https://learney.school/), [클래스 관리](https://learney.school/solutions/class-management)

2026년 5월 공개된 리포트 기능은 기간별 클래스 요약, 클래스·학생 상세, 편집 가능한 교사 의견, 보관과 PDF 저장으로 이어진다. 주간·월간 자동 발행도 안내한다. [리포트 출시 안내](https://learney.school/news/35f0051b-d0a0-8013-a49b-c0eef177bdcf)

## 우선 적용할 다섯 가지

1. **학생은 오늘 할 일부터 본다.** 학습 시작·이어하기를 주 행동으로 두고, 분석과 보관 자료는 뒤에 배치한다.
2. **교사는 지도할 학생부터 본다.** 수업 상태와 검토 대기에서 실제 응답을 확인하고 다음 활동을 배정한다.
3. **학부모는 변화와 사례부터 읽는다.** 숫자 설명을 앞세우지 않고 교사 해석, 아이의 응답, 다음 지도 순서로 전달한다.
4. **리포트는 같은 원본 기록을 사용한다.** 웹·인쇄·학생·교사·부모 화면의 기간과 계산을 일치시킨다.
5. **요약에서 근거와 행동으로 이어진다.** 지표를 눌러 원래 응답을 보고, 취약 목표에서 보충학습과 새 글 확인으로 이동한다.

대표 사용 장면은 다음과 같다. 학생이 비교 문제에서 틀린 답을 제출하면 교사는 최초 답과 선택한 근거를 확인한다. 같은 기준으로 비교하도록 돕는 수업을 배정하고, 이후 새로운 글에서 혼자 수행한 기록을 확인한다. 학부모 리포트에는 처음의 어려움, 실제 지도, 새 글에서 확인한 결과와 다음 목표가 함께 남는다.

## 후속 사용성 확인

공개 자료만으로 판단하기 어려운 항목은 실제 테스트 계정을 확보했을 때 확인한다. READ·러니 공통으로 과제 배정부터 학생 제출까지의 이동 횟수, 제출 후 피드백, 긴 답안 처리, 태블릿 읽기, 빈 기록 상태, 재접속 복구, PDF의 실제 줄바꿈과 쪽 나눔을 같은 과제로 비교한다.

이 확인은 다음 설계의 정교화를 위한 추가 조사다. 지금은 확인된 화면·기능을 바탕으로 기준 화면과 공통 기록 연결을 먼저 설계할 수 있다.
