1. 공통 진단

신청 규칙의 적용

1. 프로그램은 목요일까지 신청하고 금요일에는 기존 명단의 정보만 고칠 수 있다. 정원 초과자는 접수 순서대로 대기한다. 대기자는 결원이 생겨 연락을 받은 뒤에만 참가가 확정된다.

2. 명단에 이름이 있다는 사실과 참가 확정은 다르다. 주최자는 두 상태를 구분해 공지한다.

“확정”의 문맥 의미는?

  1. □ 신청을 받기 전의 추측
  2. □ 이름만 적힌 모든 상태
  3. □ 조건을 확인해 결정된 상태로 정함
  4. □ 앞으로 절대 확인할 수 없음

대기자의 참가가 확정되는 조건은?

  1. □ 접수 순서를 지웠을 때
  2. □ 명단에 이름만 있을 때
  3. □ 금요일에 새로 신청할 때
  4. □ 결원이 생겨 연락을 받은 뒤

금요일에 대기자 이름의 오타를 고치면?

  1. □ 정보 수정일 뿐 참가가 자동 확정되지는 않는다
  2. □ 새 신청과 참가 확정이 동시에 된다
  3. □ 접수 순서가 반드시 맨 앞으로 간다
  4. □ 정원 제한이 사라진다

주최자가 상태를 구분하는 이유는?

  1. □ 마감을 무조건 늦추려고
  2. □ 명단 등재를 참가 확정으로 오해하지 않게 하려고
  3. □ 대기자가 존재하지 않는다고 하려고
  4. □ 모든 사람의 순서를 같게 하려고

같아 보이는 지표

1. 도서실 기록에서 방문 횟수는 월요일 24회, 화요일 30회다. 동일 인물의 재방문이 포함된다. 대출 권수와 서로 다른 방문자 수는 조사하지 않았다.

2. 보고서는 방문 증가를 근거로 학생 수, 대출량, 읽기 흥미가 모두 늘었다고 주장했다. 두 날의 운영 시간도 달랐지만 보정하지 않았다.

“보정”의 뜻으로 알맞은 것은?

  1. □ 조사하지 않은 값을 사실로 적음
  2. □ 원하는 결론만 남김
  3. □ 비교에 영향을 주는 차이를 고려해 값을 조정함
  4. □ 자료를 무조건 크게 만듦

직접 기록된 지표는?

  1. □ 대출 권수
  2. □ 읽기 흥미 점수
  3. □ 서로 다른 학생 수
  4. □ 방문 횟수

주장의 주된 한계는?

  1. □ 서로 다른 지표로 확대하고 운영 시간 차이도 고려하지 않았다
  2. □ 보정하지 않으면 모든 자료는 거짓이다
  3. □ 방문 횟수의 증가 자체도 수치가 없다
  4. □ 재방문이 있으므로 방문은 없었다

두 문단을 반영한 결론은?

  1. □ 운영 시간이 달라도 비교 조건은 항상 같다
  2. □ 기록된 방문 횟수는 늘었지만 다른 지표와 조건은 추가 확인해야 한다
  3. □ 학생 수와 흥미가 각각 25% 증가했다
  4. □ 대출량이 정확히 6권 늘었다

서로 다른 반응

1. 발표 뒤 한 친구는 설명이 명료했다고 썼고, 다른 친구는 질문할 기회가 부족했다고 썼다. 발표자는 두 반응이 모순이라고 생각했다.

2. 다시 읽은 뒤 그는 설명의 명료함과 질문 기회는 다른 측면임을 정리했다. 다음 모임에는 질문 시간을 확보하고 모르는 답은 확인한 뒤 안내하기로 했다.

수정 계획과 두 반응의 관계는?

  1. □ 명료한 설명이면 질문은 필요 없다
  2. □ 질문이 있으면 설명은 모두 틀렸다
  3. □ 설명의 장점은 유지하면서 질문 기회를 보완한다
  4. □ 둘 중 하나만 사실로 남긴다

발표자의 이해가 바뀐 점은?

  1. □ 모든 평가가 무의미하다고 정했다
  2. □ 질문한 친구가 발표를 듣지 않았다고 확정했다
  3. □ 친구들이 같은 문장을 썼다고 보았다
  4. □ 다른 평가 측면의 반응은 함께 성립할 수 있다고 보았다

모르는 답을 즉시 아는 것처럼 설명하지 않은 판단은?

  1. □ 확인한 내용과 아직 모르는 내용을 구분하려는 판단이다
  2. □ 확인 없이도 어떤 답이든 같다는 판단이다
  3. □ 답이 없으므로 모든 질문을 지우는 판단이다
  4. □ 친구의 말이 반드시 틀렸다는 판단이다

반응과 계획을 종합한 설명은?

  1. □ 모르는 답도 즉시 확정한다
  2. □ 명료함을 유지하고 질문 시간을 늘리며 불확실한 답은 확인한다
  3. □ 설명을 없애고 질문도 모두 막는다
  4. □ 한 친구의 의견을 지우고 다른 의견만 복사한다

2. 추가 진단

중첩된 조건

1. 프로그램은 10명 이상 신청하고 담당 강사가 참석해야 열린다. 원래 강사의 불참은 대체 강사로 보완할 수 있다. 다만 안전 점검이 미완료면 다른 조건과 무관하게 연기한다.

2. 신청 12명, 대체 강사 참석, 안전 점검은 미완료이다.

“다만” 뒤 조건의 역할은?

  1. □ 강사 이름만 설명한다
  2. □ 앞의 모든 내용을 같은 말로 반복한다
  3. □ 앞의 진행 가능 조건을 제한하는 예외를 제시한다
  4. □ 신청 인원을 없앤다

아직 끝나지 않은 것은?

  1. □ 신청 인원 계산
  2. □ 신청 접수
  3. □ 대체 강사 확인
  4. □ 안전 점검

모든 조건을 적용한 결과는?

  1. □ 안전 점검 미완료로 연기한다
  2. □ 신청과 강사 조건만으로 진행한다
  3. □ 신청자가 적어 취소한다
  4. □ 강사는 반드시 원래 사람이어야 하므로 영구 취소한다

안전 조건을 별도로 강조한 의도는?

  1. □ 점검이 결과와 무관하다고 하려 함
  2. □ 다른 진행 요건이 맞아도 안전 확인을 생략하지 못하게 하려 함
  3. □ 참가자 수만 늘리려 함
  4. □ 대체 강사를 모두 금지하려 함

1. 안내문의 글씨 크기와 정보 위치를 함께 바꾼 뒤 준비물을 잊은 비율이 낮아졌다. 이전 모임과 참가자 구성이 달랐고 각 모임의 인원도 달랐다.

2. 두 변경을 따로 적용한 비교는 없다. 보고서는 글씨 확대의 단독 효과라고 결론내렸지만 표에는 모임별 전체 인원과 잊은 사람 수가 함께 남아 있다.

“단독 효과”의 뜻은?

  1. □ 여러 변화의 총합을 아무 구분 없이 말함
  2. □ 관찰이 전혀 없다는 뜻
  3. □ 다른 요인을 구분한 특정 요인만의 영향
  4. □ 전체 인원 자체

표에서 비율을 확인할 때 함께 볼 수 있는 정보는?

  1. □ 글씨의 정확한 색 이름만
  2. □ 참가자의 모든 배경지식
  3. □ 다른 학교의 결과
  4. □ 각 모임의 전체 인원과 잊은 사람 수

단독 효과라는 결론의 한계는?

  1. □ 동시 변경과 참가자 차이를 분리해 확인하지 않았다
  2. □ 비율을 계산할 기초 수치가 전혀 없다
  3. □ 표가 있으므로 모든 원인이 확인됐다
  4. □ 비율이 낮으면 원인 검토가 불필요하다

두 문단을 종합한 보고 문장은?

  1. □ 원인이 글씨 크기 하나로 확정됐다
  2. □ 모임별 비율 변화는 기록됐지만 글씨 확대만의 효과는 추가 비교가 필요하다
  3. □ 모임 인원 차이는 비율 확인에도 전혀 필요 없다
  4. □ 이전과 이후 참가자는 완전히 같았다
