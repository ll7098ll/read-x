  3. □ 접수 순서를 지우려고

  1. □ 54명

  2. □ 모든 학생의 흥미가 높아졌다
  3. □ 방문 횟수도 기록하지 않았다
  4. □ 이용 학생이 반드시 6명 늘었다

2. 은호는 다음 모임에 질문 시간을 따로 넣고, 답을 모르는 질문은 적어 두었다가 확인하기로 했다.

  3. □ 친구가 설명을 듣지 않았다고 확정해서

  4. □ 틀린 답도 즉시 정답으로 만들려는 태도

  1. □ 쪽지만으로 모든 관계가 확인됐다

  1. □ 질문 기회를 마련하고 모르는 답은 확인하려고 계획했다

  2. □ 2명

  3. □ 정원 기준을 없애려 함

2. 예전 모임과 새 모임의 참가자는 일부 달랐다. 안내문 변경 중 어떤 부분이 영향을 주었는지는 따로 비교하지 않았다.

  1. □ 글씨의 가로 길이
  2. □ 전체에서 일부가 차지하는 정도
  3. □ 모임의 시작 시각
  4. □ 일부의 수만 언제나 같은 값

안내문에서 함께 바꾼 것은?

  1. □ 모임 장소와 날짜
  2. □ 준비물의 종류만
  3. □ 준비물 위치와 글씨 크기
  4. □ 참가자 이름과 가격

원인을 판단할 때 고려할 것은?

  1. □ 글씨 크기만의 효과가 입증됐다
  2. □ 참가자 차이는 어떤 경우에도 상관없다
  3. □ 비율이 줄면 다른 확인은 필요 없다
  4. □ 두 변경과 참가자 차이를 구별해 살펴야 한다

기록을 정리한 문장으로 알맞은 것은?

  1. □ 변경 뒤 비율은 줄었지만 특정 변경의 단독 효과는 확정하지 않는다
  2. □ 모든 참가자가 모든 준비물을 챙겼다
  3. □ 예전과 새 모임은 완전히 같은 조건이었다
  4. □ 글씨만 바꾸어 효과를 확인했다
