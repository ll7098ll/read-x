앱에서는 교사의 진단 응답 검토, 4주 계획 승인 전 확인 자료 미리보기, 성취 확인 답안 검토 화면에서 **정답·근거·해설과 채점 준거**를 펼친다. 학생은 확인 답안을 교사가 검토한 뒤 해당 문항의 정답과 해설을 볼 수 있다. 진행 중·검토 대기 중에는 해설을 전달하지 않는다.

종이 성취 확인 활동지는 한 코스의 8개 자료를 담고 있다. 교사가 필요한 페이지를 선택해 배부한다. 1~5번은 독립 확인, 6번은 새 상황 적용, 7번은 유지 확인, 8번은 대체 확인용이다. 모든 페이지를 미리 배부하지 않는다. 종이 응답은 앱에 자동 합산되지 않으며, 이미 공개한 글을 앱에서 미노출 독립 성취 근거로 다시 사용하지 않는다.

## 채점과 난도 적용

새 성취 확인 자료는 필요한 근거 집합을 포함했는지 확인한다. 관련 문단을 추가로 골랐다는 이유만으로 오답 처리하지 않는다. 필요한 문단을 빠뜨린 경우에는 근거 충족으로 보지 않는다. 모든 문단을 선택했다고 자동으로 성취가 인정되는 것은 아니다. 선택 답·근거 조건과 함께 교사가 학생의 실제 연결 설명을 확인해야 한다.

각 선지 해설은 선택지와 문항별 결정 근거를 함께 제시한다. ‘본문에서 확인되지 않음’과 ‘현실에서 불가능함’을 혼동하지 않도록 해설을 작성했다. 설명 과제는 제시된 참고 근거를 전부 골라야 하는 문제가 아니다. 학생이 실제로 사용한 충분한 단서와 판단의 연결을 검토한다. 저학년은 짧은 말·낱말·동등한 의미의 표현을 인정하고 문장 길이·맞춤법을 성취 조건으로 삼지 않는다. 구두 수행의 질문 도움·대독 이력은 기존대로 별도 보존한다.

편집 난도 ‘입문·기본·도전’은 해당 학년 안에서 분량·조건 수·근거 결합·추론 요구를 살피는 보조 표시이다. 학년 간 등가 척도나 정답률 구간이 아니며, 통과 점수·배치·이동 규칙을 자동 변경하지 않는다. 짧은 글이라도 조건과 판단 범위가 어려울 수 있다. 고학년 자료도 짧은 기능 확인용 과제가 많으므로 장문 읽기 지속성이나 학년 전체 성취를 이 점수만으로 단정하지 않는다. 실제 수업에서는 풀이 시간, 낯선 어휘, 선택지별 오답, 교사 도움 여부를 관찰해 부담을 조정한다.

기존 4/5 성공·여러 날짜·전이·유지 확인과 교사 승인 조건은 유지했다. 이 기준의 실증적 타당성이 이번 편집 검수로 확보된 것은 아니다.

## 버전과 기록 보존

새 진단은 `g16-placement-3`, 새 코스는 `g16-course-3`, 검수 내용은 `assessment-editorial-2026-11-17-v1`이다. 새로 시작하거나 승인하는 자료에 적용한다. 진행 중인 버전 2 진단은 추가 분기로 넘어가도 당시 본문·선지·정답을 유지한다. 기존 승인 코스·응시 문항은 저장된 자료와 근거 일치 기준을 유지한다. 이전 문항에 새 해설을 임의로 붙이지 않는다. 따라서 이 검수본의 정답 번호를 이전 버전의 종이 활동지나 응시 기록에 적용하면 안 된다.

## 재현과 검증

`webapp`에서 `npm run review:assessments`로 460개 원장과 인쇄용 자료를 다시 만든다. 이 명령은 근거 참조·정답 인덱스·선지 중복·해설 누락·정답 위치 분포·학생 공개 필드를 검사한다.

회귀 검사는 모든 과제의 자료 무결성, 발견한 모순의 재발, 새 근거 포함 규칙, 기존 버전의 근거 일치 유지, 공통·분기 일관성, 교사 검토 전 비공개와 검토 후 피드백 공개를 포함한다. 별도 브라우저 검사는 초1~6 진단→배치→확인→교사 해설→학생 피드백, 460개 교사용 항목의 필터·인쇄, 학생용 48종의 문항 수·정답 분리·모바일 화면을 확인한다. 실행 결과는 같은 출력 폴더의 로그와 검증 JSON에 저장한다.

## 검토 관점의 참고 근거

[PIRLS 2026 읽기 평가 틀](https://timssandpirls.bc.edu/pirls2026/frameworks/downloads/P26_Ch1_Reading-Assessment.pdf)의 정보 찾기·추론·통합·평가 구분을 검토 관점으로 참고했다. 이 프로젝트의 여섯 코스가 곧 표준화된 난도 위계라는 뜻은 아니다. [IES 초등 초기 읽기 지도 지침](https://ies.ed.gov/ncee/wwc/PracticeGuide/21)과 [4~9학년 읽기 중재 지침](https://ies.ed.gov/ncee/wwc/PracticeGuide/29)은 실제 읽기 수행, 어휘·이해 지도와 관찰을 분리해 살피는 데 참고했다. 영어권 연구의 지침이며, 한국어 초등학생의 학년별 규준이나 이 문항의 난도 검증 자료로 사용하지 않았다.
