## 체험판의 경계

역할 전환은 시연 메뉴이며 인증·권한 검사가 아니다. 입력은 각 방문자의 브라우저에 보관된다. 실제 기관·학생 간 공유, 서버 제출, 교사의 원격 피드백은 아직 연결되지 않았다. 교과 활동의 관찰 기록과 대표 수업의 리포트 저장소도 아직 하나의 학생별 서버 기록으로 합쳐지지 않았다. 교사용 해설은 접힌 형태로 제공되지만 접근 권한으로 차단한 시험이 아니다.

신규 교과 지문은 집필자 자체 검토·교사 검수 대기 상태다. 공개 체험 제공은 판매용 콘텐츠 승인이나 학습 효과 검증을 의미하지 않는다. 원장에 기록한 학기 배치 출처와 검토 상태를 그대로 유지한다.

## 버전 2: 학원 운영 체험

가상 학원 ‘리드엑스 생각숲 학원’의 초3~6학년 4개 반·24명을 구성했다. 실제 사람의 기록은 사용하지 않는다. 초기 집계는 출석 20명, 응답 제출 16명, 검토 대기 8명, 검토 완료 8명, 리포트 공개 4명이다. 모두 같은 예시 학생 상태에서 계산한다.

- **원장 `#/director`**: 반별 시간표, 출석·제출·검토 현황, 반·학생 검색, 피드백 상태 필터, 보호자 상담 3건과 메모 보관.
- **교사 `#/teacher`**: 반별 수업·학생 목록, 처음 응답과 수정 응답, 실제 교과 지문의 전체 본문·근거, 검토 메모와 다음 목표, 학부모 체험 리포트 반영.
- **학부모 `#/parent`**: 예시 자녀 전환, 4주 관찰 추이, 읽기 과정별 관찰, 교사 피드백, 아이의 생각 기록, 집에서 나눌 질문, 리포트 인쇄.

원장 화면에서 학생을 선택하면 교사 검토에 연결되고, 검토 저장 → 리포트 반영 → 해당 학생 학부모 화면으로 이어진다. 검토 전 응답은 공개할 수 없고, 아직 학습 중이거나 수업 전인 학생에게 오늘 제출한 답을 표시하지 않는다. 학부모의 지난주 기록과 오늘 수업 피드백을 구분한다.

운영 체험은 별도 `readx_academy_mock_v1` 저장소를 사용한다. 직접 체험한 수업의 기존 초안·응답·도움·점수를 변경하지 않는다. 교사와 학부모 화면에서 기존 연습 기록으로 진입할 수 있다. 실제 발송이나 기관 간 서버 공유는 발생하지 않는다.

검증: 예시 집계 일치, 미제출·미검토 공개 차단, 검토 후 집계 변경, 재수화 복원, 기존 학습 저장소 격리, 역할별 초기 렌더를 검사했다. 브라우저에서 학생 검색 → 검토 저장 → 학부모 반영, 상담 메모, 자녀 전환, 미검토 필터, 가정 대화 표시를 확인했다. 데스크톱 1440px·모바일 390px 점검에서 가로 넘침이나 콘솔 오류가 없었다. 같은 배포에는 현재 작업 공간의 수준별·단계별 읽기 개선도 함께 포함되어 있으며 관련 자동 검사도 통과했다.

## 버전 3: 수치와 근거가 연결된 학습 리포트

교사의 ‘학습 리포트’, 원장의 ‘학습 분석’, 학부모의 주간 리포트에 같은 집계기를 적용했다. 기존에 직접 넣었던 주간 막대·단계별 수치를 제거하고, 가상 학생 24명 × 4주 × 8개 활동의 기록 768건에서 계산한다. 체험 데이터이며 표준화 검사나 규준 점수는 아니다.

| 지표 | 분자 / 분모 | 조건 |
| --- | --- | --- |
| 활동 제출률 | 제출 활동 / 배정 활동 | 미제출도 배정 분모에 포함 |
| 첫 선택 정답률 | 첫 선택 정답 / 선택형 제출 문항 | 서술형만 있는 문항은 제외 |
| 첫 근거 일치율 | 기준 근거와 일치 / 근거 평가 응답 | 수정으로 첫 결과를 덮어쓰지 않음 |
| 도움 사용률 | 첫 제출 전에 도움을 사용한 활동 / 제출 활동 | 도움은 성공·실패 판단과 별도로 표시 |
| 독립 응답률 | 독립 조건이면서 도움 0회인 응답 / 제출 활동 | 정답률과 구분 |
| 새 글 적용 확인율 | 첫 수행을 교사가 확인한 응답 / 새 글·독립·도움 0회 중 검토 완료 | 미검토는 대기 건수로 따로 표시 |

설명은 단서 찾기·관계 연결·조건 확인·자기 설명을 각 0~2점으로 채점한다. 네 항목을 모두 채점한 최신 응답만 8점 만점 평균에 포함한다. 0점은 유효 채점이며, 미채점과 구분한다. 메모만 남겼다면 수치 채점으로 승격하지 않는다. 오늘 채점한 값은 리포트 공개 전까지 학부모 평균에서 제외한다.

최근 7일·직전 7일·최근 4주를 선택할 수 있다. 직전 같은 길이의 기간과 비율 차이(%p), 관찰 건수를 함께 보여준다. 반·학원 합산은 학생별 비율의 단순 평균이 아닌 응답 건수 합산이다. 서로 다른 문항의 변화이므로 난도 보정된 능력 변화로 해석하지 않는다. 분모가 0이면 ‘—’, 5건 미만이면 ‘관찰 수 적음’을 표시한다.

산출 기준·채점표, 활동별 집계 원장, 동일 기간의 CSV 내려받기를 제공한다. 실제 기기의 대표 읽기 수업에도 첫 제출 기준 집계기를 적용했다. 현재 실제 대표 수업에는 선택형 답과 네 항목 채점값이 없으므로 이를 임의 생성하지 않는다. 기존 응답·도움·검토 기록은 보존한다.

검증은 최초 응답 보존, 중복 제외, 기간 경계, 가중 합산, 도움·재노출 제외, 미평가와 0점 구분, 공개 전 채점 제외, CSV 행 일치 등을 포함한다. 브라우저에서 일부 항목만 채점했을 때 저장 차단, 전체 채점 후 평균 갱신과 학부모 반영, 반별 합산, 기간 변경, 32개 활동 원장과 CSV 내려받기, 모바일 가로 넘침 여부를 확인했다.
