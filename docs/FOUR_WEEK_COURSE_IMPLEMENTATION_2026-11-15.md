## 사용 흐름

교사는 `#/teacher/classes`에서 배치된 학생을 선택하고 **4주 계획 검토하기**를 누른다. 학습 수업 3개, 새 글 확인 자료 8개, 정답·근거·설명 준거를 확인하고 승인 의견을 작성하면 계획이 시작된다. 기존 첫 수업과 제출 이력을 보존하고 추가 수업 2개만 배정한다. 이미 시작한 학생도 같은 방식으로 연결할 수 있다.

학생은 `#/student/classes`에서 **오늘 이어 할 학습**과 8회 계획을 확인한다. 진행 중인 확인, 이전 코스에서 도래한 유지 확인, 남은 학습 수업, 독립 확인, 새 상황 적용 순으로 다음 행동을 제시한다. 제출한 설명은 교사가 검토한다. 이후 다음 단계의 자료를 교사가 승인하면 새 4주 계획과 수업이 배정된다.

## 계획과 단계

| 주 | 회차 | 기본 활동 |
| --- | --- | --- |
| 1 | 1~2 | 배치된 첫 수업과 추가 학습 |
| 2 | 3~4 | 새 글 독립 확인 2개, 세 번째 학습 |
| 3 | 5~6 | 새 글 독립 확인 2개와 1개 |
| 4 | 7~8 | 새 상황 적용, 유지 확인·다음 계획 검토 |

권장일은 시작일부터 0·3·7·10·14·17·21·24일이다. 학습일을 강제로 잠그지 않고 결석 후 미완료 활동을 이어 간다. 유지 확인은 실제 전이 수행 성공 뒤 7일 경과가 우선이므로 4주 이후로 밀릴 수 있다. 수업 제출 기한은 42일을 확보하고 기존 첫 수업도 교사의 계획 승인 시 연장한다.

코스는 **뜻 익히기 → 단서 짚기 → 관계 엮기 → 의미 풀기 → 근거 따지기 → 새롭게 엮기**다. 진단으로 배치된 코스에서 시작하고, 성취 확인을 거쳐 다음 코스로 이동한다. 마지막 코스 뒤에는 준비된 과정 완료를 안내한다. 학년 승급이나 전국 수준으로 환산하지 않는다.

학년별로 코스당 기존 창작 수업 3개를 연결했다. 별도 창작 확인 자료는 코스당 8개, 서로 다른 자료 계열 총 48개다. 각 자료는 선택·근거 선택·자기 설명을 요구하는 짧은 수행 묶음이다. 초3·4가 같은 확인 자료를 공유하며 학년별 수업 자료는 다르다. 이 자료와 판정 기준은 교사 검토·학생 파일럿 대상이다.

## 성취와 이동 규칙

- 첫 두 학습을 제출해야 독립 확인이 열린다. 연습의 정답·수업 제출 자체는 성취 증거에 넣지 않는다.
- 최근 28일의 독립 확인 5회 중 4회 이상 성공, 마지막 확인 성공, 서로 다른 미노출 계열 5개, 한국 시간 기준 수업일 2일 이상을 요구한다.
- 성공은 선택 정답·필요 근거의 정확한 선택·교사의 설명 준거 충족을 모두 만족해야 한다. 선택 답이 틀렸으면 교사가 설명을 성공으로 표시해도 성공 횟수로 계산하지 않는다.
- 세 학습을 모두 제출하고 독립 확인을 충족해야 새 상황 적용이 열린다. 새 상황 적용도 별도 미노출 계열과 같은 채점·검토 조건을 요구한다.
- 검토 대기 답안이 있으면 이동을 보류한다. 이동 시점에도 서버가 성취 근거와 계획 버전을 다시 확인한다.
- 다음 코스의 자료·준거를 교사가 검토하고 승인해야 이동한다. 자동 추천은 교사의 배정 판단으로 이어진다.
- 새 상황 적용 성공 후 7일이 지나면 이전 코스에서도 유지 확인을 할 수 있다. 유지 실패는 해당 기능 재확인 신호로 남기고 현재 코스를 초기화하지 않는다.

## 보충과 예외

교사는 추가 지도가 필요한 확인 기록에서 **보충 수업 배정**을 누를 수 있다. 해당 코스의 승인된 세 번째 수업을 도움글 수준으로 새로 배정하고, 같은 실패 기록의 중복 요청은 같은 보충 배정을 유지한다. 학생은 새 배정으로 다시 연습하고 이후 미노출 확인 자료를 사용한다. 이전 코스의 유지 실패도 같은 방식으로 보충한다.

이미 열었던 자료 계열은 학생의 전체 코스 이력에서 다시 독립 자료로 사용하지 않는다. 미완료 응시는 같은 답안으로 재개한다. 독립 확인 5개, 전이 1개, 유지 1개와 재확인 예비 1개를 구분한다. 예비 자료를 이미 사용했거나 재확인이 많이 필요해 새 자료가 부족하면 교사에게 추가 공급을 요청하도록 안내하고 이동을 확정하지 않는다.

같은 날 독립 확인 5개를 모두 풀어도 수업일 요건을 충족하지 않는다. 다음 날 전에는 예비 자료를 소모하지 않도록 막는다. 독립 확인을 충족한 뒤에는 같은 종류를 더 열지 않고 전이로 안내한다.

## 저장·권한·화면

`learning_courses`에 학생·기관별 현재 계획, 이전 계획, 자료 노출, 확인 초안·최초 제출, 검토 수정 이력, 배정·이동 결정, 정책 버전 `g34-course-1`을 저장한다. 승인한 수업·평가 묶음의 해시와 평가 본문 스냅샷을 고정한다. 다음 단계 이동의 중복 요청은 추가 계획이나 수업을 만들지 않는다.

확인 답안은 서버 revision으로 동시 수정을 제어하고 제출 후 원응답을 보존한다. 학생에게 미사용 평가 은행과 정답·채점 근거를 전송하지 않는다. 담당 반 교사만 계획 승인과 설명 검토를 할 수 있다. 다른 학생과 보호자는 원응답·계획 관리 API에 접근할 수 없다. 보호자에게 공개하는 기존 수업 기록은 기존 공개 절차를 따른다.

학생 화면에는 오늘의 행동, 4주 계획, 확인 상태, 보충 수업, 이전 코스 기록을 표시한다. 교사 화면에는 전체 답안·근거·설명 검토, 계획 승인, 보충 배정, 다음 단계 검토를 표시한다.
