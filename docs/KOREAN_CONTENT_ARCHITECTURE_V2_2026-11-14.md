상태: 조사에 근거한 제품 설계안. 단계의 명칭·배치·물량은 편집 제안이며 공인 능력 등급이나 현재 승인 보유량이 아니다.

**초1~6 각각에 충분한 깊이를 가진 국어 학습 은행을 만든다.** 학년별 주제 몇 개를 추가하는 방식에서, 학년별 세부 수행과 그 수행의 여러 수준·소재·유형·독립 확인을 채우는 방식으로 제작 기준을 바꾼다. 학생은 필요한 경로를 배우고, 콘텐츠 은행은 다른 경로와 새 자료 확인을 계속 공급한다.

국어 수행을 나타내는6단계는 **뜻 익히기 → 단서 짚기 → 관계 엮기 → 의미 풀기 → 근거 따지기 → 새롭게 엮기**를 제안한다. [조사 기록](../research/KOREAN_LITERACY_PROGRESSION_RESEARCH_2026-11-14.md)의 PIRLS·OECD·IES와 국내 교육과정을 설계 근거로 삼되, 이6단계 자체는 제품에서 검토할 편집 체계다.

이번 계획은 기존 [콘텐츠 제작 계획](CONTENT_PRODUCTION_PLAN_2026-11-14.md)의 공급 규모와 학년 내 단계 구성을 확장한다. 기존 [집필 규칙](CONTENT_AUTHORING_RULES.md)의 사실·근거·검수·노출·버전 원칙은 유지한다.

## 2 국어 수행에 맞춘 여섯 단계

| 단계 | 공통 역할 | 읽기에서의 예 | 쓰기에서의 예 | 완성 판단의 중심 |
| --- | --- | --- | --- | --- |
| S1 뜻 익히기 | 기능·낱말·방법을 알고 예와 비예를 구별 | 원인과 결과의 뜻을 짧은 예로 구별 | 독자·목적·문장 구성 요소를 예와 비교 | 무엇을 살필지 설명 가능 |
| S2 단서 짚기 | 명시된 핵심 정보를 정확히 선택·사용 | 필요한 문장과 조건을 짚음 | 필요한 정보와 표현을 골라 정확한 문장 작성 | 정답과 실제 근거가 일치 |
| S3 관계 엮기 | 여러 정보를 정해진 관계로 연결 | 문단·순서·인과·비교·지시 대상을 연결 | 문장과 문단을 목적에 맞게 조직 | 연결 관계를 보존 |
| S4 의미 풀기 | 드러나지 않은 관계나 표현 효과를 근거로 해석 | 생략된 이유·인물 변화·함축을 설명 | 독자의 이해를 예상해 설명·근거·표현 보완 | 해석과 근거의 연결이 분명 |
| S5 근거 따지기 | 해석·자료·표현의 적절성을 검토·수정 | 반례·범위·출처·관점·해석 가능성을 점검 | 잘못된 정보·논리·조직을 찾아 고치고 이유 설명 | 수정 또는 판단 기준을 제시 |
| S6 새롭게 엮기 | 새 소재·형식·상황에서 통합적으로 수행 | 새 글과 자료를 종합해 목적에 맞게 판단 | 자료를 종합해 새 독자에게 글·발표를 구성 | 처음 보는 조건에서도 독립적으로 적용 |

S1이 항상 낮은 정답률 과제보다 쉽다는 뜻은 아니다. 단계는 수업의 역할과 요구를 조직한다. 실제 과제 난도는 지문·과제·학생 경험에 따라 관찰한다. 모든 기능에 동일한 발문을 씌우지 않는다. 예를 들어 낱말 기능의S5는 뜻풀이가 문맥에 맞는지 검토하는 활동이고, S6는 새 문맥에서 뜻을 구별해 사용하는 활동이다.

초1의S6도 초1에게 적절한 낱말과 경험 안에서 새 자료 두 개를 연결하는 수준으로 만든다. 추상적인 전문 지식이나 상위 학년의 장문을 통째로 가져와 단계가 높다고 표시하지 않는다.

### 영역별로 학생에게 보여 줄 단계 이름

공통 여섯 단계는 제작 원장의 기준으로 사용하고, 학생 화면에서는 배우는 영역의 실제 행동이 드러나게 이름을 구체화한다. 수학 교재의 등급 이름을 바꾸어 붙이는 방식으로 설계하지 않는다. 아래 이름은 편집 제안이며 기존 데이터의 단계 ID를 변경하지 않는다.

| 영역 | S1 | S2 | S3 | S4 | S5 | S6 |
| --- | --- | --- | --- | --- | --- | --- |
| 낱말·문장 | 쓰임 익히기 | 문맥 살피기 | 문장 관계 잇기 | 표현 차이 풀기 | 어울림 따지기 | 새 문맥에 쓰기 |
| 정보 읽기 | 읽는 방법 익히기 | 핵심 정보 짚기 | 내용 관계 엮기 | 숨은 뜻 풀기 | 설명과 근거 따지기 | 여러 글 종합하기 |
| 문학 읽기 | 작품 속 말 익히기 | 장면과 인물 살피기 | 사건과 마음 잇기 | 표현과 의미 풀기 | 해석의 근거 따지기 | 작품을 새롭게 엮기 |
| 매체와 자료 | 표현 방식 알기 | 자료 속 정보 짚기 | 글과 자료 연결하기 | 의도와 관점 풀기 | 자료의 신뢰성 따지기 | 목적에 맞게 재구성하기 |
| 쓰기 | 쓰는 방법 익히기 | 필요한 내용 고르기 | 흐름 있게 조직하기 | 독자를 생각해 표현하기 | 살펴보고 고쳐 쓰기 | 새 상황에 맞게 쓰기 |
| 듣기·말하기 | 듣고 말할 방법 익히기 | 핵심 내용 짚기 | 말의 흐름 이어 가기 | 뜻과 입장 헤아리기 | 근거와 반응 살피기 | 대화하며 생각 조정하기 |

영역별 이름만 달라지고 과제가 같아지는 것을 막기 위해 집필 때는 해당 미세 수행의 구체적인 행동까지 적는다. 예를 들어 ‘인물의 마음’은 마음말 알기 → 행동 단서 찾기 → 사건에 따른 마음 변화 잇기 → 말과 속마음의 차이 해석하기 → 서로 다른 해석을 근거로 비교하기 → 새 장면에서 인물의 말과 행동을 구성하고 설명하기로 구체화할 수 있다. 마지막 과제를 창작의 재미만으로 채점하지 않고 원래 작품의 인물·사건과 연결한 이유를 확인한다.

### 같은 국어 기능 안에서도 깊이와 과제 부담을 따로 설계

학습 단계는 국어의 수행을 표현하고, 같은 단계 안의 부담은 단서·조건·지원으로 따로 조절한다. 예를 들어 초4 접속 표현은 **이어 주는 말 짚기 → 내용의 관계 잇기 → 연결에 담긴 뜻 풀기 → 관계가 맞는지 따지기**로 구체화한다. 단순히 접속어를 찾는 활동, 목적에 맞게 원인·대조·덧붙임을 연결하는 활동, ‘그다음’을 ‘그래서’로 바꿀 때 더해진 인과 판단을 설명하는 활동, 실제 기록에 맞게 연결을 고치는 활동은 서로 다른 수행이다. 이 네 활동을 네 개의 공인 난도 등급으로 부르지 않는다. 같은 활동에서도 직접 드러난 한 관계에서 여러 문단의 경쟁 조건으로 부담을 달리할 수 있다.

이 단계표만으로 학년 내 수준 편성을 완료하지 않는다. 같은 ‘단서 짚기’에서도 핵심 정보가 한 문장에 직접 나오는 과제와, 비슷한 정보 사이에서 여러 문단에 떨어진 조건을 찾아야 하는 과제는 부담이 다르다. 따라서 기능별 자료마다 단서의 거리·경쟁 정보·조건·지원 유무를 기록하고, 학년 안에서 실제 학생 수행을 확인하며 배치한다.

예를 들어 초4 ‘조건을 보존해 요약하기’는 한 문단에서 대상과 조건 하나를 남기는 자료, 여러 문단에서 대상·기간·예외를 함께 보존하는 자료, 안내문과 변경 공지를 대조해 현재 유효한 조건만 남기는 자료를 각각 공급한다. 이 차이는 지문을 길게 만드는 것과 별개로 설계한다. ‘요약은 쉬운 영역, 비판은 어려운 영역’처럼 영역 자체를 난도 등급으로 사용하지 않는다.

초1~6에60개씩 총360개 미세 수행을 우선 편성한다. 같은 이름의 기능도 학년별 수행 조건을 다르게 쓴다. 기존132개 큰 목표와의 연결을 보존하고, 일부 큰 목표를 여러 수행으로 나눴다는 사실을 기록한다. 기존 목표와 맞지 않는 문학·매체·듣기 말하기 수행은 억지로 설명문 목표에 넣지 않고 별도 정식 목표 검토 대상으로 둔다.

듣기·말하기와 소리 내어 읽기는 실제 음성 자료·응답·교사 관찰을 포함해야 한다. 텍스트 문제를 만들었다는 이유로 이 수행의 공급을 완료 처리하지 않는다. 현재 앱에 없는 녹음·재생·관찰 기능과 연결할 개발 항목도 따로 만든다.

## 4 학년별 안에서 요구를 높이는 방식

| 학년 | 기준 소재와 언어 | 같은 학년 안에서 관계를 복잡하게 하는 방법 | 새롭게 엮기 예 |
| --- | --- | --- | --- |
| 초1 | 생활어, 짧은 문장, 눈에 보이는 대상과 행동 | 특징2개 대조, 두 행동 순서, 단순한 조건 변화 | 안내 두 장을 보고 알맞은 물건과 자리를 설명 |
| 초2 | 짧은 문단, 생활 안내, 가까운 이유와 결과 | 두 조건, 서로 다른 문장의 정보, 간단한 예외 | 다른 상황의 규칙에 행동을 적용하고 이유 한두 문장 |
| 초3 | 문단 중심 생각, 기본 교과어, 간단한 표 | 중심·세부 위계, 문단 간 관계, 자료와 본문 결합 | 서로 다른 형식의 자료를 간추려 새 독자에게 안내 |
| 초4 | 여러 문단, 관점·이유, 자료 간 대응 | 생략 관계, 조건·예외, 출처·범위 대조 | 안내와 관찰 기록의 차이를 찾아 설명을 수정 |
| 초5 | 정의·원리·추상어를 필요한 설명과 함께 제공 | 경쟁 근거, 다중 조건, 관점과 자료의 한계 | 상충하는 자료를 정리해 조건부 제안 |
| 초6 | 복합 구조와 여러 자료, 독자·매체 고려 | 근거 우선순위, 반례·불확실성, 해석 조정 | 자료를 종합하고 반론·한계를 반영한 글이나 발표 |

표의 기준은 편집 배치 제안이다. 동일 학년 전체를 같은 속도에 고정하지 않는다. 어휘는 익숙하지만 문단 관계가 어려운 학생처럼 기능별 수행 차이를 기록한다. 초4의 특정 기능을 더 배우는 학생을 전체 국어 능력의 하위 학년으로 표시하지 않는다.

## 5 지문 난도와 문항 난도를 설계하는 명세

지문은 기존 readingPolicy의 학년별 길이를 참고하되 길이만으로 등급을 결정하지 않는다. 정보 읽기 장문·짧은 언어 자료·시·이야기·생활 자료는 각각 별도 분량과 구조 기준을 둔다. 높은 단계에서도 근거가 부족하거나 문장이 부자연스러우면 반려한다.

| 지문 명세 | 의뢰서에 적을 값 |
| --- | --- |
| 어휘 | 핵심어·낯선 말·추상어·다의어와 제공 풀이 |
| 문장 | 문장 길이, 생략, 수식 범위, 지시·접속 부담 |
| 구조 | 문단 수, 설명 구조, 전환, 서술 순서, 관점 수 |
| 정보 | 명제 수, 표·그림 정보량, 목적과 무관한 정보 |
| 지식 | 본문이 제공할 배경, 선수 지식, 새 개념 수 |
| 문학 표현 | 화자·시점, 함축·비유, 시간 변화, 해석 단서 |
| 복합 자료 | 자료 수, 형식, 관계, 출처·작성 시점·범위 |

| 문항 명세 | 요구를 높이는 방식 |
| --- | --- |
| 단서의 수와 거리 | 한 문장 → 두 문장 → 떨어진 문단과 자료 |
| 명시성 | 그대로 제시 → 바꾸어 표현 → 생략된 연결 복원 |
| 조건과 예외 | 단일 조건 → 조건 결합 → 예외·충돌의 우선순위 |
| 경쟁 정보 | 무관한 정보 → 비슷한 대상 → 일부만 맞는 근거 |
| 근거 판단 | 근거 선택 → 관계 설명 → 범위 검토·반례 대조 |
| 표현 | 고르기 → 짧은 설명 → 조직한 글 → 수정과 정당화 |
| 전이 | 같은 소재 → 새 소재 → 새 형식 → 새 목적과 독자 |

항목을 임의의 가중치로 더해 공인 난도 점수를 만들지 않는다. 각 지문·문항에 실제 값을 기록해 같은 기능의 상대적 배치를 검토한다. 선지 수, 낯선 단어, 과도한 시간 압박을 높이는 것만으로 단계를 올리지 않는다.

## 6 같은 목표의 여섯 단계 예시

예시는 초4 편집 수준의 ‘원인과 결과의 연결을 읽고 설명하기’다. 정식 승인 문항이 아닌 설계 예시이며, 각 단계의 실제 납품에는 별도 본문·근거·해설·루브릭이 필요하다.

| 단계 | 자료 설계 | 학생 과제 | 확인할 수행 |
| --- | --- | --- | --- |
| 뜻 익히기 | 원인과 결과의 뜻, 맞는 연결과 거꾸로 된 예 | 두 사건의 앞뒤와 이유를 구별 | 용어만 외우지 않고 관계 구별 |
| 단서 짚기 | 바람이 불어 창가의 안내 쪽지가 떨어졌다는 명시문 | 떨어진 이유를 본문 구절로 확인 | 직접 근거 사용 |
| 관계 엮기 | 쪽지가 떨어짐 → 안내를 못 봄 → 다른 줄에 섬을 문단에 나누어 제시 | 중간 사건을 포함해 연결도 완성 | 관계 사슬 보존 |
| 의미 풀기 | 바뀐 번호표, 예전 안내판, 망설이는 학생을 서로 다른 문단에 제시 | 망설인 이유를 필요한 단서로 추론 | 생략 관계 복원 |
| 근거 따지기 | 안내 위치와 글씨 크기를 동시에 바꾼 뒤 문의가 줄었다는 기록 | 위치만이 원인이라는 해석의 한계 설명 | 다르게 한 조건과 원인 단정 구별 |
| 새롭게 엮기 | 독립 집필한 도서실 기록과 동아리 안내 수정본 | 혼란 원인 후보와 더 확인할 정보를 나누고 새 안내 작성 | 여러 자료의 관계와 불확실성을 표현에 반영 |

같은 지문에 질문만 여섯 개 바꾸어 전체 코스가 완성됐다고 세지 않는다. 수업 중 한 지문을 여러 과제에 재사용할 수는 있으나, 독립 확인과 새로운 소재의 전이는 별도 계열의 자료로 공급한다.

쓰기의6단계도 해당 기능에 맞춰 구현한다. ‘독자에게 필요한 설명 쓰기’라면 독자·목적 구별 → 필요한 정보 선택 → 개요 구성 → 생략 정보 보완 → 독자 관점에서 수정 → 새 독자·매체에 맞게 재작성으로 구체화한다. 낱말 과제에는 같은 쓰기 길이를 강요하지 않는다.

## 7 대규모 공급 물량

최초 장기 공급 목표는 학년별60개 미세 수행마다20개 자료 묶음을 두는 것이다. 다음 수치는 제작 예산이며 실제 검토에서 부적합한 조합은 합치거나 대체하고 총량을 다시 계산한다. 공인 기준이60개 또는20개를 요구한다는 뜻은 아니다.

| 단계 | 수행당 자료 묶음 | 묶음당 문항·과제 | 수행당 문항 합계 |
| --- | ---: | ---: | ---: |
| 뜻 익히기 | 2 | 3 | 6 |
| 단서 짚기 | 4 | 4 | 16 |
| 관계 엮기 | 6 | 4 | 24 |
| 의미 풀기 | 4 | 4 | 16 |
| 근거 따지기 | 3 | 5 | 15 |
| 새롭게 엮기 | 1 | 6 | 6 |
| 합계 | **20** | — | **83** |

| 범위 | 미세 수행 | 단계 설계 칸 | 자료 묶음 | 문항·과제 |
| --- | ---: | ---: | ---: | ---: |
| 학년별 | 60 | 360 | 1,200 | 4,980 |
| 초1~6 전체 | **360** | **2,160** | **7,200** | **29,880** |

자료 묶음은 낱말·문장 카드, 연결된 글, 시·이야기, 도표, 두 편 이상의 글, 쓰기 상황 자료 등이다. 7,200묶음을 모두 장문 지문7,200편이라고 표현하지 않는다. 승인 때 실제 신규 본문·독립 계열·변형·문항·자산 수를 별도 집계한다. 시범 대본과 힌트는 새 문항 수에 더하지 않는다. 쓰기의 계획·초고·수정고는 하나의 쓰기 과제 이력이다.

수행당20묶음의 사용 목적 예산은 수업·연습14, 독립 확인3, 전이 확인2, 지연 확인1이다. 전 학년 기준 각각5,040·1,080·720·360묶음이다. 확인 자료의 원문·해설을 학생에게 사전 노출하지 않는다. 정식 시험12종과224문항은 별도 출제·검수하며 이 은행 수량에 중복 추가하지 않는다.

다양성은 각 수행의 적합한 문학·정보·생활·자료 형식과 소재로 확보한다. 모든 수행을 모든 교과와 장르에 무리하게 곱하지 않는다. 동일 문장에 이름과 수만 바꾼 자료, 단순 분량 확장, 같은 글의 문항 추가는 새로운 독립 자료로 세지 않는다.

## 8 학생 한 명의 실제 경로

은행 전체는 공급량이다. 초기 운영 예시는 연36주·주2회·회당2~3묶음으로 학생당144~216묶음이다. 수업 시간·글 길이·쓰기 비중을 관찰해 조정한다. 학생이 학년별1,200묶음을 모두 끝내야 진급하는 구조로 만들지 않는다.

진단은 영역별 대표 수행과 최근 실제 답안을 확인하는 데 사용한다. 한 번의 총점으로 학생 전체를 S2나S5로 고정하지 않는다. 예를 들어 낱말은 S4, 요약의 조건 보존은 S2 연습이 필요할 수 있다.

진행 결정에는 첫 응답, 근거 설명, 도움, 새 글 노출, 복습 여부, 교사 검토를 함께 본다. 다음 단계 진입은 서로 다른 미노출 자료에서 필요한 준거를 확인하는 방식으로 파일럿한다. 정확한 문항 수와 정답률 기준은 파일럿 전에 교사가 정하고 검증한다. 클릭 수나 읽은 시간만으로 통과시키지 않는다.

상위 단계에서 어려움을 보이면 필요한 선수 수행과 지원을 제공하고 다시 확인한다. 이미 확인된 다른 기능까지 일괄 초기화하지 않는다. 지연 확인 시점도 학생의 실제 수업 일정과 노출을 반영한다.

## 9 문제와 지문의 품질 기준

### 집필 전

집필 의뢰서에 학년·미세 수행·단계·지문 명세·과제 명세·사용 목적·예상 오해·필요 자산·채점 준거를 고정한다. 상위 단계라는 이름만 주어 AI가 임의로 길이와 어휘를 늘리게 하지 않는다. 실제 성취기준과 목표 연결은 원문 위치로 확인한다.

### 집필 후

1. **정답 검토:** 정답을 제외한 자료와 문항을 먼저 풀고, 별도 요청에서 집필 정답과 비교한다. 선택형의 유일성·서술형의 허용 답·문학 해석의 근거 범위를 검토한다.
2. **목표 검토:** 요청한 수행과 실제 해결 행동이 맞는지 확인한다. 추론이라고 붙였지만 답을 그대로 베끼는 문항은 재분류하거나 수정한다.
3. **단계 검토:** 인접 단계 과제를 나란히 보고 어떤 조건이 달라졌는지 설명할 수 있어야 한다. 단계만 다르고 실제 요구가 같은 경우 수정한다.
4. **본문 검토:** 사실·출처·사용 근거·개념 정확성·문장 자연스러움·내용 전개·장르 적합성을 확인한다. 자동 반복으로 길이를 맞추지 않는다.
5. **선지 검토:** 부분만 맞는 이유와 틀린 조건을 명시한다. 정답 길이·어조·문법이 힌트가 되지 않는지 확인한다. 우스운 오답으로 수를 채우지 않는다.
6. **루브릭 검토:** 실제 완전 답·부분 답·잘못된 답의 차이를 기준별로 적는다. 모든 문항에 같은 ‘근거가 적절한가’만 붙이지 않는다.
7. **다양성 검토:** 같은 기능의 소재·구조·정답 위치·자료 형식·오답 유도 방식이 반복되지 않는지 본다.
8. **노출과 화면 검토:** 풀이의 선공개, 다른 문항의 답 누설, 표·그림 가독성, 터치·키보드·음성 지원을 확인한다.

AI 재검토는 교사 승인과 구분한다. 첫 공급 묶음은 전량 내용 검토한다. 실제 학생 파일럿에서는 어떤 집필 난도가 뒤집혔는지, 어느 단어·발문이 불필요한 부담을 주었는지 수집한다. 큰 표본의 난도 보정 전에는 집필 단계와 관찰한 정답률을 동일시하지 않는다.

정답 변경·근거 부족·자료 누락·목표 불일치·성취기준 오연결은 게시 차단이다. 반려는 지문과 연관 문항·해설·시범·루브릭을 함께 수정하고 재검사한다.
