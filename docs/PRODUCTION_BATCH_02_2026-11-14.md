2026년 11월 14일. 모의고사와 같은 계정·세션으로 실제 읽기 수업의 콘텐츠 검토·배정·수행·제출·교사 피드백·보호자 공개를 연결했다. 전체 운영 전환 목표는 계속 진행 중이다.

## 이용 흐름

운영 서버를 실행한 뒤 첫 화면에서 학생·교사·학부모 공간을 선택하면 실제 계정 로그인으로 연결된다. 로그인 후 공통 헤더의 읽기 수업 메뉴와 모의고사 메뉴를 오갈 수 있다.

- 교사 `#/teacher/classes`: 학년과 지문 선택 → 전체 본문·문항·해설 검토 → 검토 의견과 시범 수업 승인 → 학생·글 수준·제출 기간을 선택해 배정.
- 학생 `#/student/classes`: 배정 수업 → 기존 사고 시범·근거 표시·설명 활동 → 내 말로 설명하기 → 저장·제출.
- 교사: 학생의 최초·수정 응답, 근거 원문, 도움 사용, 생각 표시, 글 수정 이력 확인 → 활동별 판단과 종합 의견 → 보호자에게 공개.
- 학부모 `#/parent/classes`: 연결 자녀의 공개된 수업 기록만 확인. 교사 수정본은 재공개 전까지 이전 공개본을 유지한다. 공개 회수 시 서버 조회를 차단한다.

원장과 콘텐츠 관리실의 기존 첫 화면은 아직 체험 화면이다. 실제 운영 기능과 화면의 이관을 계속 진행한다.

## 저장과 판단

배정·학생 수행·보호자 공개본·콘텐츠 승인에 각각 독립된 SQLite 행을 사용한다. 기존 모의고사 계정과 DB를 공유하며 요청 하나의 트랜잭션에 계정 확인·변경·감사 기록을 묶는다. 전체 계정·기관 DB의 PostgreSQL 이관은 아직 완료되지 않았다.

수업을 배정할 때 콘텐츠 전체와 승인 기록·해시를 고정한다. 콘텐츠 파일이 개정되어도 이미 배정된 수업의 본문과 문항이 바뀌지 않는다. 승인되지 않은 지문은 배정할 수 없다. 이번 승인 기능은 교사가 검토하고 선택하는 시범 수업 승인이다. 실제 독립 교사 검수나 학생 난도 보정이 자동으로 완료되는 기능이 아니다.

저장 요청에는 수행 버전과 중복 방지 ID가 있다. 서버는 선택 답과 필요한 근거를 다시 확인하고, 최초 응답·수정 이력과 도움 사용을 보존한다. 클라이언트가 보내는 정오답·교사 검토 결과를 신뢰하지 않는다. 쓰기와 서술 내용의 적절성은 교사 검토로 남긴다. 같은 글의 수행을 새 글 전이 성공으로 집계하지 않는다.

브라우저 초안은 사용자·수행별로 격리한다. 저장 중 추가 입력은 다음 요청에 남기고, 통신 실패 시 같은 요청 ID로 재시도한다. 다른 화면의 버전과 충돌하면 초안을 별도로 보관하고 서버 기록을 다시 불러올 수 있다. 마감 후 입력도 보관하며 교사가 기한을 연장할 수 있다. 제출 후 학생이 공식 기록을 수정하는 요청은 차단한다.

## 검증

최종 `npm run build`가 통과했다. 화면·학습 검사 75개와 서버·통신 검사 12개, 합계 87개가 통과했고, 정식 시험의 비공개 자료가 운영 번들에 포함되지 않는 검사도 통과했다.

서버·통신 검사에는 다음을 포함한다.

- 교사 승인 전 배정 차단, 배정한 학생만 시작, 중복 시작 시 같은 수행 반환.
- 다른 학생 기록과 공개 전 보호자 접근 차단.
- 서버 채점, 최초 응답 변경 거절, 중복 저장 처리, 오래된 버전 거절, 미완료 제출 차단.
- 모든 활동 검토 후 공개, 보호자 공개본 고정, 수정 의견 비공개 유지, 공개 회수.
- 마감 후 제출 차단과 교사 기한 연장, 세션 만료 후 재로그인.
- SQLite 서비스를 종료하고 다시 열었을 때 배정·승인·학생 초안·수행 버전 보존.

기존 432개 수준별 읽기 화면과 활동 검사도 회귀 검사에 포함한다. 실서버 확인에는 별도 `qa-learning-2026-11-14.sqlite`를 사용했다. 5개 활동 제출·5개 활동 교사 검토·공개 전 보호자 차단·지도 의견 일치·배정 콘텐츠 해시 일치를 확인했다. 모든 검증 계정·답안·시범 승인·검토 의견은 기능 연결 시험용이며 실제 학생 평가나 교사 콘텐츠 검수 결과가 아니다.

증거는 서버 확인 결과 (`output/learning-http-evidence-2026-11-14.json`, 로컬 보관·공개 제외), 전체 빌드 로그 (`output/learning-build-2026-11-14.log`, 로컬 보관·공개 제외)에 남긴다.

학생부터 보호자까지의 최종 브라우저 조작·태블릿 화면·오프라인 복구 확인은 아직 남아 있다. 이번 턴에서는 브라우저 제어 도구 변경 후 필요한 브라우저 스킬 파일이 설치 경로에 없어 자동 UI 조작을 재개하지 못했다. HTTP 통합 검사와 렌더 검사로 브라우저 조작 검증을 완료했다고 처리하지 않는다.
