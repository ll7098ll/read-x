## 반영한 화면과 동작

| 영역 | 구현 |
| --- | --- |
| 소개 | 본문의 조건 강조와 선생님의 생각을 세 단계로 넘겨 보는 시범 |
| 학생 홈 | 오늘의 학습·읽기 연습·모의고사·내 성장 네 메뉴, 학년 선택, 대표 읽기 수업, 최근 교사 질문 |
| 읽기 | 본문과 생각 시범 동기화, 앞서 살핀 표시 유지/숨기기, 세부 학습 과정 펼쳐보기 |
| 어노테이션 | 직접 선택한 범위·시작/끝 어절 조절, 대상·근거·연결·조건·질문, 같은 문장 안의 두 구절 연결 |
| 생각 수정 | 표시 편집·삭제·마지막 작업 되돌리기, 수정 전 이유 보관, 처음 생각과 비교 |
| 설명 작성 | 표시한 구절과 이유를 설명으로 가져오기, 근거 선택 재사용, 응답·수정본 보존 |
| 교사 | 직접 작성된 두 읽기 방식의 응답 목록, 검토 대기, 원문·표시·설명·수정 비교, 수행 확인과 피드백 |
| 학부모 | 실제 연습의 근거·설명·교사 피드백을 먼저 제공, 가상 학급 리포트는 별도 펼쳐보기 |
| 원장 | 실제 기기 연습의 검토 현황에서 교사 공간으로 이동 |
| 콘텐츠 관리 | 대표 사고구술 대본의 초안 편집·기기 연습에 반영·학생 시범 미리보기·기본 대본 복원 |

대표 사고 과정 수업과 전 학년 교과 읽기는 기존 흐름을 유지하면서 같은 표시 편집기를 사용한다. 같은 본문을 연습한 기록과 새로운 글에서의 독립 확인은 기존처럼 구별한다.

## 기록 보존

새 표시는 지문 버전·문장 ID·정확한 시작/끝 위치·인용·앞뒤 문맥을 보관한다. 반복되는 같은 문구의 두 번째 위치도 구별한다. 이전 형식의 모호한 인용은 임의의 위치에 강조하지 않는다.

제출된 교과 읽기는 당시 본문·질문·표시를 복제해 보관한다. 다시 연습을 시작해도 보관한 시도의 응답과 교사 피드백을 기록 화면에서 볼 수 있다. 수정하거나 되돌린 현재 표시가 과거 제출본을 덮어쓰지 않는다.

기존 저장 키와 학습·모의시험 기록을 유지한다. 새 시범 편집은 별도 `readx_thinking_script_v1`에 저장한다. 서버 전송과 다른 기기 동기화는 아직 연결하지 않았다.

## 검증

- TypeScript 검사와 자동 검사 70개 통과, Vite 프로덕션 번들 생성 성공.
- 새 검사 6개: 반복 구절, 같은 문장 연결, 원문 버전과 범위 검증, 수정·삭제 되돌리기, UTF-16 경계와 조건 표시, 재연습 후 본문·질문 스냅샷 보존.
- 브라우저에서 초5 대표 수업의 시범→구절 범위 선택→이유 작성→생각 수정→설명에 가져오기→제출을 확인.
- 교사 검토와 피드백이 학생의 다음 질문과 학부모 기록에 반영되는 것을 확인.
- 초2 교과 읽기의 표시→설명·근거 재사용→제출→교사 검토→학부모 기록 연결을 확인.
- 모바일 390px에서 가로 넘침 없음, 기존 응답과 교사 피드백 복원 확인.
- 사고구술 편집 미리보기와 Escape 닫기, 미리보기 본문 대비 보완 확인. 검증 탭의 실행 오류 로그 없음.

자동 검사는 내용의 교육적 타당성이나 학습 효과를 인증하지 않는다. 실제 학생을 대상으로 한 조작·이해 부담 관찰은 후속 검증이다.

## 남은 운영 기반과 확장

기관 계정과 권한, 실제 학생별 배정, 서버 제출·동기화·보호자 연결은 후속 운영 기반이다. 현재 화면의 역할 전환은 기기 내 체험용이다. 정식 주간·월간 발행, 자동 전달, 전체 목표의 사고구술 저작·승인, 음성 사고구술·녹음은 전체 계획의 후속 범위로 남는다.

콘텐츠 편집실은 대표 수업의 시범 문장만 편집한다. 전체 수업 묶음의 지문·앵커·도움·독립 확인을 수정하고 승인하는 관리 시스템이 완성된 것은 아니다. 검수 전 시범을 반영하는 것은 기기 내 연습에 한정한다.
