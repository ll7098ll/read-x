기존 React/Vite 프로젝트의 첫 화면, 학생 체험 홈, 로그인, 계정 학습 현황과 공통 스타일을 개선했다. 기존 로고를 유지하고, 종이의 질감과 책에서 자라는 정원을 모티프로 독자적인 시각 방향을 적용했다.

## 시각 방향

- 따뜻한 아이보리 배경, 짙은 초록색 글자와 버튼, 세이지·살구·버터색 보조 면.
- 직접 생성한 종이 조형 일러스트 3종: 책 속 정원, 온실, 생각을 잇는 다리.
- 이미지와 여백이 중심이 되는 첫 화면, 구별하기 쉬운 역할별 입구, 학년별 수업 카드.
- 기존 ReadX 로고 및 읽기·평가·권한·저장 로직은 유지.

참고: [러니 공식 사이트](https://learney.school/). 역할별 진입과 이미지 중심 설명 방식을 참고 대상으로 삼았으며, 일러스트·문구·색상 구성은 새로 제작했다. 러니의 이미지·마스코트·소스는 사용하지 않았다. 브라우저 화면 확인은 사용자의 Esc 입력으로 중단되어 이후 컴퓨터 조작은 진행하지 않았다.

## 사용성 변경

- 첫 화면: 학습 시작, 수업 둘러보기, 학생·교사·학부모 입구를 명확히 구분.
- 학년별 수업: 초1–6학년 선택과 실제 수업 3개씩 연결. 체험 기록과 계정 학습의 차이를 안내.
- 생각 시범: 기존 상호작용을 유지하고 독립된 넓은 영역에 배치.
- 학생 홈: 이어 읽기/오늘 읽기를 최우선으로 배치. 실제 기기 기록의 수업·생각·낱말 수 표시. 추가 읽기 안내는 접고 펼칠 수 있음.
- 로그인: 일러스트와 입력 영역을 분리하되 기존 초기 설정·복구·개인정보 안내를 보존.
- 학습 현황: 공통 팔레트, 헤더 이미지, 지표 카드의 색상과 여백 통일.
- 작은 화면: 역할 카드는 세로로, 학년 필터는 3열로, 학생 메뉴는 2열로 재배치. 가로 스크롤 없이 읽을 수 있도록 반응형 규칙 작성.
- 키보드 초점, 버튼 상태, 이미지 대체 텍스트, 줄어든 동작 설정 대응.

## 파일과 에셋

- 스타일: `webapp/src/reading-garden.css`
- 첫 화면: `webapp/src/components/layout/MainLandingPage.tsx`
- 학생 홈: `webapp/src/components/student/StudentJourneyHub.tsx`
- 로그인: `webapp/src/components/exam/AccountForms.tsx`
- 계정 현황: `webapp/src/components/common/OverviewDashboard.tsx`
- 로컬 이미지: `webapp/public/brand/reading-garden/{hero,nature,ideas}.webp`
- 생성 원본과 정확한 생성 프롬프트: `output/reading-garden/` 및 `asset-manifest.json`

내장 `image_gen` 도구로 생성했다. 원본 PNG를 보관하고 같은 이미지의 WebP 인코딩을 웹에 사용한다. 최종 이미지 3개의 합계는 563,352바이트이며 외부 이미지 서버에 의존하지 않는다. 첫 이미지에는 크기를 지정해 레이아웃 이동을 줄이고, 아래 수업 이미지는 지연 로드한다.

## 검증

- TypeScript와 Vite 운영 빌드 성공.
- 기존 화면·학습 테스트 79개 통과.
- 첫 화면 서버 렌더링, 내부 섹션 링크, 6개 학년 18개 수업 연결, 로그인/초기 설정 폼 검증 통과.
- WebP 파일 무결성 및 운영 번들의 비공개 시험 해설 제외 확인.
- 자동 외부 리소스 검사 통과.
- 서버 통합 테스트는 제한 환경의 로컬 연결 `EACCES`를 확인한 뒤 허용된 환경에서 재실행하여 32개 모두 통과. 결과는 `output/reading-garden/server-tests.log`에 기록.
- 브라우저 시각·클릭 검증은 Esc로 중단되어 미완료. 반응형 규칙은 구현했으나 실제 모바일 브라우저의 렌더링은 별도 확인이 필요하다.

로컬에서 `webapp` 폴더의 `npm run dev`로 확인할 수 있다. 이 변경은 프로젝트 파일에 반영했으며 외부 배포는 수행하지 않았다.
