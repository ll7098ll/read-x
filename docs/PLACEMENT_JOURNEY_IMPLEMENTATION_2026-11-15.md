> 후속 구현: 첫 수업 이후의 4주 계획, 성취 확인과 다음 단계 이동은 [4주 학습 구현 기록](FOUR_WEEK_COURSE_IMPLEMENTATION_2026-11-15.md)에 연결했다. 아래의 ‘현재 범위’는 최초 구현 시점의 기록이다.

2026-11-15. 전 과정 설계의 첫 수업 연결 범위를 구현했다. 진단은 교사 검토용 창작 시범 자료이며 실제 학생 파일럿으로 보정한 능력 척도가 아니다.

## 이용 순서

1. 운영 서버에서 기존 계정으로 `#/student/classes`에 로그인한다.
2. 초3·초4를 선택하고 조작 연습을 마친 뒤 시작 진단을 진행한다.
3. 공통 12문항의 답을 저장하고 추가 진단으로 이동한다. 공통 수행에 따라 지원형 또는 확장형 8문항과 자기 설명 2과제가 열린다. 저장된 응답은 재접속·서버 재시작 후에도 복원된다.
4. 제출하면 어휘·문장, 정보 확인, 관계 연결 수행과 시작 코스가 추천된다. 학생은 교사의 확인을 기다린다.
5. 교사는 `#/teacher/classes`에서 학생을 선택해 응답·근거·자기 설명을 검토한다. 설명 두 과제의 판단을 기록하고 코스·글 수준을 확인한다.
6. 해당 코스에 연결된 첫 수업의 본문·시범·문항을 검토하고 배치 이유와 첫 2회 확인 사항을 작성한다. 시범 승인을 확인하고 배정한다.
7. 학생은 배치 결과를 갱신하고 ‘첫 수업 시작·이어 하기’로 들어간다. 기존 읽기 수업의 사고 시범·근거 선택·자기 설명·저장·제출·교사 검토 기능을 사용한다.

## 구현 내용

- 진단 응시·분기·응답·추천·교사 결정·첫 수업 배정 ID는 기존 SQLite DB의 `learning_placements`에 학생·기관별로 저장한다.
- 선택형 정답은 서버에서 채점하며 학생에게 제공하는 시험지·프론트 번들에는 정답 키를 포함하지 않는다. 단원·문항은 버전 `g34-pilot-1`을 기록한다.
- 추천은 각 표집 기능의 정답 비율과 선수 기능 우선순위를 사용하는 초기 규칙이다. 어휘가 충분하고 관계 연결에서 어려움을 보인 경우 관계 코스를 추천한다. 쓰기·문학·유창성 전체 능력으로 환산하지 않는다.
- 각 코스는 학년별 기존 읽기 수업 한 개에 연결한다. 연결은 `courseLessons`에서 관리하고 서버가 코스와 수업의 일치를 확인한다. 교사는 코스를 변경할 수 있으며 이유와 원추천을 보존한다.
- 수업의 기존 정확한 콘텐츠 해시 승인과 담당 반 권한을 그대로 적용한다. 중복 승인 요청은 같은 수업 배정을 반환한다. 다른 학생·연결 보호자는 진단 원응답을 조회할 수 없다.
- 진단 제출 후 원응답을 보존한다. 진단 중 수정 요청은 revision으로 충돌을 확인하고, 같은 답 재전송은 중복 집계하지 않는다.

## 검증

- `node --test server/placement-service.test.mjs server/learning-service.test.mjs server/organization.test.mjs server/overview-service.test.mjs`: 17개 통과. 초3·4 분기, 재시작 복원, 누락·권한·동시 수정 거절, 교사 콘텐츠 승인, 중복 배정 방지, 첫 수업 저장·제출, 반 권한·기존 리포트 회귀를 포함한다.
- TypeScript 검사, Vite 배포 번들 생성, 비공개 시험 자료 번들 검사, 외부 리소스 검사 통과.
- `scripts/verify_placement_browser.py`: 격리된 가상 계정 미리보기 서버에서 조작 연습, 응답 저장·새로고침, 추가 진단, 교사 배치, 모바일 첫 수업까지 통과했다. 브라우저 오류 0건. 결과와 화면 4개는 `output/placement-journey`에 기록했다.
- 전체 재검사에서 프론트엔드 검사와 서버 검사 54개가 통과했다. 최초 전체 실행에서 관찰한 MFA 테스트 실패는 단독 재검사와 전체 재검사에서 모두 통과했다.

## 현재 범위

이번 연결은 첫 수업까지다. 배치는 잠정 상태로 기록하며 첫 2회 적합성 판정, 4주 자동 계획, 코스 내 다음 단원 추천, 미노출 자료 전이·유지 확인, 자동 단계 이동은 후속 범위다. 기존 수업의 해설·연습 수행은 새 글 독립 성취로 승격하지 않는다.

학년별 진단은 공통 자료를 공유하며 초4 일부 본문을 확장한다. 학년별 난도와 배치 기준은 실제 파일럿에서 검토해야 한다. 시작 진단은 한 학생당 한 응시를 유지하며 재진단 대체형은 아직 제공하지 않는다.

기본 앱은 실제 계정 서버 모드다. `VITE_EXAM_MODE=demo`의 브라우저 전용 모의고사 체험에는 이 기능이 연결되지 않는다. 개발은 `npm run dev`, 배포용 서버는 빌드 후 `npm run serve:exam`을 사용한다.
