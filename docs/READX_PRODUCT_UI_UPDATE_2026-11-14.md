> 작성 당시의 설계·조사·구현 기록입니다. 현재 기능과 운영 상태는 최신 현황을 우선합니다. [문서 목차](README.md) · [최신 현황](PROJECT_STATUS.md)


학생 학습, 교사·학부모 대시보드, 모의고사, 리포트와 관리 화면에 편집형 디자인을 적용했다. `webapp/src/product-ui.css`를 공통 제품 화면의 최종 스타일로 사용하며 `main.tsx`에서 브랜드 및 레거시 화면 스타일 뒤에 불러온다.

## 주요 변경

- 흰색·딥그린 기반의 공통 헤더, 명확한 현재 메뉴, 작은 모서리, 일관된 버튼·입력창·표·상태 표시.
- 학생 읽기: 기본/큰 글씨, 지문·활동 탭, 간결한 학습 단계, 근거 선택과 설명 작성, 짧은 저장 상태와 펼쳐 보는 안내. 교사 배정 수업과 체험 읽기가 같은 표시 컴포넌트를 쓴다.
- 수업 목록: 제목 검색, 진행할 수업/제출한 수업/검토 대기 필터, 실제 수업 수, 별도로 펼치는 수업 준비 영역. 수업 시작과 목록 복귀 시 화면 상단으로 이동한다.
- 교사 대시보드: 검토할 응답 우선 배치, 최근 기간 선택, 상세 조회 조건, 학생·과제 검색과 상태 필터, 기록 바로가기.
- 학부모 대시보드: 공개된 가장 최근 피드백과 실제 응답 연결. 읽기 리포트는 종합 의견을 먼저 보여 주고 활동별 기록을 펼쳐 본다. 인쇄 시 응답 상세를 펼친 후 원래 열림 상태로 복원한다.
- 체험 교사·학부모 홈의 주 메뉴를 먼저 배치하고 모의고사 연결은 펼치는 보조 영역으로 정리했다.
- 모의고사, 보충 연습, 학습이력, 목표·통계 리포트, 운영 폼과 대화상자도 같은 시각 규칙을 사용한다.

## 검증

- 프런트엔드 80개, 서버 38개 테스트 통과. 전체 실행 기록: `output/editorial-design/product-build.log`.
- TypeScript 및 Vite 운영 빌드, 비공개 시험 콘텐츠 경계, 외부 자동 로딩 리소스 검사 통과. 최종 Vite 로그: `output/editorial-design/product-build-final.log`.
- 실제 API를 사용하는 별도 localhost 검증 서버에서 학생·교사·학부모 로그인과 역할별 화면을 확인했다. 계정과 기록은 전부 합성 자료이며 메모리 DB만 사용했다. 운영 DB는 읽거나 변경하지 않았다.
- 1440px 데스크톱과 390px 모바일에서 가로 문서 넘침 없이 확인했다. 교사 목록 검색, 검토 대기 필터, 수업 준비 패널, 대시보드 과제 검색, 공개 피드백 연결을 확인했다.
- 학생의 시범 → 문제 풀이 → 근거 선택 → 설명 입력 → 응답 확인 → 서버 저장 → 다시 열기 흐름을 검증했다. 큰 글씨의 모바일 본문은 23px로 표시된다.
- 학원 운영 및 모의고사 운영 화면의 모바일 레이아웃을 확인했다. 검증 브라우저 콘솔 오류 없음.
