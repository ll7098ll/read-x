## 적용

- 중심 문구: **읽으라고 하기 전에, 읽는 방법부터.**
- 심벌: 글과 생각이 만나는 X. 잉크·코발트·라임 컬러 및 단색/반전 SVG.
- 워드마크 SVG는 로컬 Pretendard Variable 글리프를 윤곽선으로 변환. 폰트 라이선스 동봉.
- 공통 `ReadXBrand`, 파비콘, 문서 제목·메타 설명, 기존 사용 화면의 구 브랜드명 갱신.
- 31개 CSS 토큰과 JSON 배포본. `data-brand="read-x-v3"` 범위에서 기존 테마와의 토큰 충돌 방지.
- `#/brand`: CI, 팔레트, 글자·읽기 바탕, 버튼·선택·입력·오류·완료·빈 상태, 도움말, 4단계 수업 흐름, 학생·교사·보호자 화면 예시, 다운로드.
- 첫 화면의 소개와 짧은 시범을 ‘어떻게 읽는지’에 맞게 교체. 시범과 직접 선택을 같은 공유 컴포넌트로 제공.
- 공통 도움말의 Escape 닫기와 시작 버튼으로 초점 복귀 보완.
- 기존 CI·컴포넌트 마스터 진입점 갱신. 원문은 `docs/archive/*_PRE_V3.md`로 보존.

## 확인한 동작

- 시범 → 직접 해 보기 → 결과 문장 선택 시 위치 안내 → 원인 문장 선택 시 이유 피드백.
- 힌트 펼치기/접기, 선택 초기화.
- 빈 응답의 오류 문구·초점 이동, 문장 작성 후 작성 확인. 정답·숙련으로 자동 판정하지 않음.
- 도움말 열기, Escape 닫기, 시작 버튼으로 키보드 초점 복귀.
- 학생·교사·보호자 화면 예시 전환. 교사 표는 실제 데이터와 구별해 표시.
- 학년군·야간 바탕·28px 확대. 선택값과 표시 크기 일치.
- 색상 복사 성공 안내.
- 데스크톱 1440px, 태블릿 768px, 모바일 390px에서 킷 가로 넘침 없음.
- 모바일 첫 화면 가로 넘침 없음. 모바일 화면 예시의 로고가 숨겨지던 CSS 선택자 수정.
- 검증 시 브라우저 오류 로그 없음.

## 자동 검사

- TypeScript 검사 통과.
- 기존 UI·학습 도메인 테스트 80개 통과.
- 기존 서버·저장·권한 관련 테스트 38개 통과.
- 운영 빌드 및 비공개 시험 자료 번들 제외 검사 통과.
- 공개 체험판 빌드·자동 외부 리소스 검사 통과.
- 주요 색상 8쌍 대비 계산 통과. 본문 13.02:1, 주요 버튼 6.08:1, 보조 설명 5.54:1, 조작 경계 3.55:1.
- 다운로드 8개 HTTP 200 및 올바른 파일 형식 확인.
- ZIP CRC 검증, 원본/ZIP 파일 일치, 16개 파일 수록, 워드마크의 text 노드 없음 확인.

이는 확인한 크기·동작에 대한 검사다. 전체 기존 세부 화면의 접근성 인증이나 학습 효과 검증을 뜻하지 않는다. 역할별 화면 킷은 설계 예시이며, 모든 기존 수업 엔진을 새 단계로 교체한 것은 아니다.
