## 접수와 확인

계정 설정의 권리 요청 화면에서 본인 또는 확인된 법정대리인의 자녀를 선택한다. 학습 이용 동의와 권리 행사 확인을 분리했다. 동의 철회·퇴원 때문에 자녀가 학습하지 못해도 유효한 법정대리인 확인이 있으면 권리 요청을 접수할 수 있다. 유효한 관계가 없거나 계정에 접속할 수 없다면 학원의 외부 접수 절차로 처리한다. 원장은 대면·서면 접수의 문서 번호와 실제 확인 여부를 기록할 수 있다. 신분증·주민등록번호·가족관계 원본 파일을 앱에 업로드하지 않는다.

계정 사용자는 본인의 요청만 보며, 원장만 기관 전체 요청을 검토한다. 일반 교사는 자신의 개인정보 권리를 행사할 수 있지만 다른 학생·보호자의 요청을 열거나 처리할 수 없다. 기관·역할을 본문에 지정해 접근 범위를 넓히지 못한다. 요청 목록은 50건씩 번호 기준으로 이전 항목을 조회한다. 접수·확인·결과·이의 제기·취소 이력을 남기며, 변경 버전과 요청 식별자로 충돌·중복 재전송을 처리한다.

새 접수와 처리·사본 조회/다운로드에 현재 비밀번호를 다시 확인한다. MFA를 등록한 계정은 새 인증앱 코드도 요구한다. 기본 서버의 교사·원장은 기존 MFA 필수 경계 안에 있다. 초기 비밀번호 변경이 필요한 계정은 먼저 본인 비밀번호로 바꿔야 권리 요청 내용에 접근한다. 실패 누적·인증 제한은 기존 추가 인증 체계에 저장한다.

본인·대리인 확인은 자동 신원 인증이나 법률 적합성 판정이 아니다. 실제 확인 방법·참조 문서·담당자·시각을 기록한다. 기존 관계가 해제되거나 만료되면 종전 승인만으로 계정 다운로드를 계속할 수 없다. 별도 대면·서면 확인으로 학원이 직접 전달하는 경우에는 `offlineOnly`로 구분해 원장만 사본 파일을 받을 수 있다. 이 절차가 일반 보호자 연결이나 학습 접근을 복원하지 않는다. 실제 외부 전달과 수령 확인 절차는 운영자가 수행해야 한다.

## 열람 사본 검토·제공

계정 정보, 읽기 수행, 평가 응답, 동의·확인 이력, 출결·상담, 시작 진단과 학습 코스에서 요청 대상의 자료를 구성한다. 시험 문항·정답표·코스의 비공개 확인 자료와 인증 비밀·타인의 계정 메타데이터를 원본 DB 전체 덤프 방식으로 제공하지 않는다. 자유 서술·메모에 제3자 정보가 포함될 수 있으므로 원장의 실제 검토가 필요하다.

원장은 요청 범위 안에서 사본을 미리 보고, 필요한 문자열을 고정된 제외 표시로 바꿀 수 있다. 일부 범위를 빼거나 문구를 제외하면 검토 문서 참조와 결과·이유를 기록한다. 제외 기능은 실제 존재하는 허용된 문자열만 대상으로 하며 식별자·객체 전체·프로토타입 경로를 바꿀 수 없다. 제공할 사본의 원본 해시가 미리보기 때와 다르면 저장을 거부하고 최신 자료를 다시 검토한다.

검토 후 준비한 사본은 이후 학습·상담 수정과 분리한 사본으로 고정한다. 기본 제공 유효기간은 내부 기준 7일이며, 이후 다운로드는 거부한다. 사본을 다시 확인하거나 이의를 접수하면 이전 사본의 제공을 중지한다. 다운로드 시에도 현재 계정·관계·비밀번호·MFA를 확인한다. 링크 토큰을 URL에 넣거나 인증 없이 파일을 공개하지 않는다. 원장 다운로드는 권리 요청 목적과 문서 참조를 접속기록에 남기고, 요청자 다운로드도 본인/보호자 접근으로 기록한다.

앱에서 다루는 한 사본은 5MB, 한 번에 제외할 문자열은 200개로 제한한다. 대규모 자료는 범위 분리·추가 접수 또는 운영자의 별도 검토·전달이 필요하다. 이 내부 파일 한도를 법적 권리 범위의 제한으로 적용하면 안 된다. 사본 준비나 원장 다운로드를 실제 외부 전달·수령 확인 또는 개인정보 파기 완료로 해석하지 않는다.

## 실제 정정과 아직 남은 실행

현재 계정 표시 이름 정정은 원장이 검토한 요청 값만 실제 계정에 반영한다. 현재 이름·계정 버전이 확인 때와 다르면 거절하며, 반영 시 대상의 기존 세션과 기기 초안 키를 회수한다. 현재 화면의 이름을 고치는 작업이고 과거 동의·제출 당시의 역사적 사실을 몰래 다시 쓰지 않는다. 다른 항목의 정정은 별도 실제 처리와 검증이 필요하다.

삭제·처리정지 접수는 실제 파기·학습 차단 완료 상태가 아니다. 검토·이의 제기·연기/거절 사유 기록은 가능하지만 보존 근거·제한 범위·실행·백업 영향을 확인하지 않은 요청을 완료 처리하는 API는 허용하지 않는다. `action_required`를 유지해 실제 조치가 남았음을 표시한다. 이 요청 화면의 취소는 해당 요청 접수만 취소하며 학습 동의·계정 활성 상태를 바꾸지 않는다. 연기·거절의 법적 정당성과 안내·이의 절차는 실제 운영 검토 대상이다.

## 암호화·저장·기록

요청 내용·확인 참조·검토 결과·이력은 `privacy_requests`의 암호화된 본문으로 저장한다. 사본은 별도 `privacy_request_bundles` 표에 저장해 목록 조회가 큰 사본 본문을 읽고 복호화하지 않게 했다. AES-256-GCM의 임의 nonce와 기관·요청 ID, 사본 버전을 결합한다. 일반 색인의 대상·요청자·상태·버전 등은 복호화한 본문과 일치를 검사한다. 사본은 별도 버전과 본문 해시도 검사한다. 행 이동·색인/암호문 변경·잘못된 키에 대해 자료를 평문으로 대체하지 않고 실패한다.

운영 모드는 독립적인 `READX_DATA_KEYS`가 필요하다. 형식은 `{activeId,keys}`이며 실제 32바이트 Base64 키를 코드·문서·공개 사이트에 저장하지 않는다. MFA·감사 검증 키와 분리해 보관한다. 이전 키를 유지하는 교체 읽기를 지원하지만 일괄 재암호화·키 보관소·복구 훈련은 아직 완료되지 않았다. 비운영의 `.data-keys.json`은 개발 편의용이고 Windows ACL 보호를 보증하지 않는다. 키 파일과 DB·환경 파일은 Git·Sites 동기화 대상에서 제외한다.

초기 개발 형식에서 요청 본문 안에 암호화되어 있던 승인 사본은 별도 암호화 표로 이관하며, 제공된 사본의 내용·해시를 바꾸지 않는다. 만료·취소·이의 제기 시 접근 차단 및 활성 사본 정리는 물리적 장치·WAL·백업의 완전 파기 검증과 다르다. 후속 보존/파기·복구 절차가 필요하다.

접수·확인·다운로드·정정·이의 제기는 기존 접속기록 경계 안에 있다. 감사 기록에는 요청·사본 원문과 비밀번호를 복사하지 않는다. 접속기록 저장이 실패하면 요청·사본 저장과 계정 정정을 함께 취소한다. 요청 식별자 재전송은 이미 승인한 같은 작업을 반복하지 않으며 같은 식별자로 내용을 바꾸면 거절한다.

## 검증과 운영 전환 상태

실제 HTTP와 임시 SQLite의 가상 계정으로 암호화·서명 경계, 현재 비밀번호·MFA, 원장·기관·보호자 범위, 동의 철회와 확인 해제, 고정 사본·일부 제외·동시 변경·재시작·만료, 실제 이름 정정·세션 회수, 재전송·이의 제기·페이지 이동, 키 유실·색인 변경·감사 장애, 별도 전달·사본 이관을 검사한다. 운영 원본 전체 빌드에서 UI·도메인 80개와 서버·운영 96개, 합계 176개 검사가 통과했다. 비공개 평가 자료의 운영 번들 비포함과 외부 자동 리소스 검사도 통과했다. 증거는 `output/rights-final-build-2026-11-17.log`이다. 공개 사본의 후속 검증·배포 결과는 아래 기록에 추가한다. 실제 단말·브라우저·법률 전문가·학원 현장 검증을 수행한 것으로 보지 않는다.

접수 시 7일의 내부 처리 목표를 표시한다. 법정 기한을 판정하거나 자동 연장하는 기능이 아니며 권리 유형·보완 요청·예외·통지를 실제 운영 기준과 법률 검토로 정해야 한다. [개인정보 보호법 제38조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0038&lsiSeq=283839&urlMode=lsScJoRltInfoR), [정정·삭제 조문](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335317), [시행령의 본인·대리인 확인](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=289537)을 설계 근거로 확인했다. 자동 계정 인증만으로 법정대리인 여부나 법률 검토가 끝난 것으로 간주하지 않는다.

전체 목표는 계속 진행 중이다. 실제 삭제·처리정지 실행, 자료별 보유기간·보존 예외, 백업 복원 후 재파기, 계정 외부 접수 운영, 권리 안내·계약·국내 서버·키 운영·현장 검증이 남아 있다. `RIGHTS-01`, `RETENTION-01`을 포함한 운영 준비 23개 통제는 검토 대기 상태를 유지한다. 공개 Sites는 실제 학원 DB와 연결하지 않는 가상 자료 체험판이다.
