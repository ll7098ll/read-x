2026년 11월 14일. 운영 모의고사 경로를 브라우저 체험 엔진에서 계정 기반 HTTP API로 전환했다. 교사 배정, 학생 제출, 교사 검토·결과 공개, 연결 보호자 리포트를 같은 SQLite 원장으로 연결한다.

## 구현

- 요청 검증의 미정의 `fail` 오류를 수정했다. 잘못된 Origin, 요청 형식, JSON, 크기에 대해 403·415·400·413을 반환한다.
- 기본 `examApi`는 쿠키 세션을 포함한 동일 출처 HTTP 요청을 사용한다. 네트워크 실패·시간 초과·JSON이 아닌 응답을 오류로 표시하며, 로컬 성공으로 대체하지 않는다.
- 첫 교사 계정과 반 생성, 로그인·로그아웃, 학생 및 연결 보호자 등록 폼을 추가했다. 초기 설정은 서버 컴퓨터에서만 가능하고 기본 계정·공통 비밀번호는 없다.
- 시험 배정·이어하기·제출·교사 공개·지도 의견·보호자 공개와 회수를 기존 서버 기능에 연결했다. 새 세션의 실제 사용자에 맞춰 화면 역할을 갱신한다.
- 운영 학생 화면의 저장 상태와 결과 공개 안내를 서버 동작에 맞췄다. 계정 없는 새 응시 버튼은 체험 빌드에서만 제공한다.
- 체험 모드는 `VITE_EXAM_MODE=demo`를 빌드 시 명시한 경우에만 활성화된다. 운영 빌드에서 체험 엔진·정식 시험 채점 원본 모듈을 참조하면 빌드가 실패한다. 최종 HTML에서도 비공개 해설과 체험 저장 키의 비노출을 검사한다.

## 실행

`webapp`에서 다음 명령을 실행한다.

```powershell
npm run build
npm run serve:exam
```

주소는 `http://127.0.0.1:5186/#/exams`다. 교사는 초기 계정 생성 후 학생·보호자 메뉴에서 계정을 발급하고 시험을 배정한다. 학생과 보호자는 같은 주소에 자신의 계정으로 로그인한다. 학생 제출 후 교사가 회차 결과를 공개하고, 지도 의견을 작성해 보호자에게 공개한다. 보호자는 연결 자녀의 공개된 리포트만 조회한다.

개발 서버는 `npm run dev`다. `READX_EXAM_PORT`, `READX_EXAM_HOST`, `READX_EXAM_DB`로 서버 주소와 저장 파일을 지정한다. HTTPS 운영에서는 `READX_COOKIE_SECURE=1`을 적용한다. 기본 서버의 접속 범위는 해당 컴퓨터다. 외부 접속을 위한 HTTPS·호스팅은 별도 운영 준비 단계다.

운영 DB 기본 위치는 `webapp/.exam-data/readx.sqlite`다. 이번 실제 HTTP 검증에는 별도 `qa-production-2026-11-14.sqlite`를 사용했다. 검증용 계정과 학생은 모두 가상 자료이며 기본 운영 DB와 분리되어 있다.

## 검증 증거

최종 `npm run build` 통과. 화면·학습 검사 74개와 서버·통신 검사 8개, 합계 82개가 통과했고 운영 HTML의 비공개 시험 해설·체험 엔진 비노출 검사도 통과했다.

- 화면·학습 로직 검사에 운영 계정 폼 검사를 추가했다.
- 서버·통신 검사에는 기존 권한·마감·중복 저장·공개·후속 지도·재시작 보존 검사에 더해 잘못된 HTTP 요청, 쿠키 포함 요청, 통신 실패, 시간 초과, 실제 HTTP 어댑터의 계정별 전체 이용 흐름을 포함한다.
- 브라우저에서 초기 교사 계정 생성과 학생·보호자 등록·연결을 확인했다.
- 실제 실행 서버에서 교사 배정 → 학생 로그인·답안 저장·제출 → 공개 전 보호자 차단 → 교사 결과·의견 공개 → 학생·교사·보호자 리포트 일치를 확인했다. 검증 결과는 1/24 정답, 4.2점이다. 서버 콘텐츠 원본 경로는 404였다.
- 실행 증거: 실제 HTTP 확인 (`output/production-http-evidence-2026-11-14.json`, 로컬 보관·공개 제외), 전체 빌드 로그 (`output/production-build-2026-11-14.log`, 로컬 보관·공개 제외).

브라우저에서 계정 등록을 확인한 뒤 도구 환경이 갱신되었다. 이후 배정·제출·공개 확인은 실제 서버 HTTP 요청과 자동 통합 검사로 수행했다. 학생 응시부터 보호자 리포트까지의 최종 브라우저 조작 검증은 다음 검증 항목으로 남아 있다.
