## 이용 순서

학생은 `#/student/classes`에서 재학 학년을 선택하고 조작 연습 후 시작 진단을 진행한다. 교사는 `#/teacher/classes`에서 응답과 자기 설명을 검토하고 학년별 첫 수업을 승인한다. 이어 4주 계획을 검토해 시작하면 학생의 ‘오늘 이어 할 학습’으로 수업·새 글 확인이 연결된다. 교사가 실제 근거와 설명을 확인한 후 다음 단계의 수업을 승인한다.

## 학년별 편성

초1~2는 선택지 3개, 초3~6은 4개를 사용한다. 예상 응시 시간은 초1~2 15~20분, 초3~6 25~35분의 편성 가설이다. 공통 응답에서 어려움이 나타나면 지원형, 여유가 있으면 확장형으로 분기한다. 저장한 답은 이어서 응시할 수 있다.

초1~4는 어휘·문장, 정보 확인, 관계 연결을 중심으로 표집한다. 초5~6은 추론·해석, 근거 평가, 자료 통합을 함께 표집하며 이 결과에 따라 상위 코스부터 시작하는 추천도 제공한다. 작은 문항 표본으로 국어 전체 능력이나 전국 수준을 산출하지 않는다. 추천은 교사가 실제 설명을 보고 조정한다.

초4 진단은 단순 길이 추가 외에 공휴일 예외, 방문 횟수와 사람 수 구별, 동시 변경과 참여자 차이 등 과제 조건도 조정했다. 초3~4의 일부 진단 자료는 같은 원천의 편집 변형이며 독립 자료로 중복 집계하지 않는다.

## 학년별 코스와 성취 자료

각 학년에 **뜻 익히기 → 단서 짚기 → 관계 엮기 → 의미 풀기 → 근거 따지기 → 새롭게 엮기**를 둔다. 같은 코스 이름이어도 자료의 언어와 요구는 학년에 따라 다르다. 초1 새롭게 엮기는 짧은 안내 두 개를 함께 사용하는 활동이며, 초6은 조건·예외·불확실성을 함께 적용한다. 학년 간 공통 능력 척도로 환산하지 않는다.

- 학년 6개 × 코스 6개 = 36개 학년별 코스.
- 코스당 해당 학년의 학습 수업 3개, 전체 연결 108개. 기존 개정 지문과 사고 시범·문항을 사용한다.
- 코스당 독립 확인 5개, 전이 1개, 유지 1개, 재확인 예비 1개. 학년별 48개, 전체 288개 학년판.
- 학년판은 노출 관리상 48개 계열로 보수적으로 묶는다. 학년만 바꾸거나 문장을 다시 편집한 자료를 새 독립 자료로 인정하지 않는다. 288개를 서로 독립인 원천 288개라고 주장하지 않는다.

성취 자료는 생활 상황과 창작 안내·관찰 기록으로 구성한다. 초1~2는 짧은 사건·규칙·마음, 초5~6은 단독 효과와 동시 변화, 표본과 전체, 시간과 능력 지표, 예외의 범위, 출처와 허락 등 학년 내 요구를 높인다. 사실 지식보다 본문을 근거로 답할 수 있도록 작성했다. 이 편성·난도는 교사 검토 및 학생 파일럿에서 보정할 대상이다.

## 저학년 설명과 실제 읽기 관찰

학생은 진단의 자기 설명과 성취 확인에서 **말로 설명하고 선생님이 기록해요**를 선택할 수 있다. 이 경우 글을 길게 입력하지 않고 설명 요청과 선택한 근거를 제출한다. 교사는 실제 발화를 받아 적고 도움 조건을 기록한다.

| 관찰 조건 | 기록·성취 처리 |
| --- | --- |
| 학생이 직접 읽고 설명하고 교사는 받아 적기만 함 | 다른 채점 준거와 함께 독립 성공 근거가 될 수 있음 |
| 힌트나 질문 도움 | 도움받은 수행으로 보존, 독립 성공으로 계산하지 않음 |
| 지문을 대신 읽어 줌 | 읽기 독립 수행과 구분, 독립 성공으로 계산하지 않음 |

실제 구두 관찰을 남기기 전에는 교사가 성공으로만 표시해 성취를 확정할 수 없다. 학생의 최초 제출은 그대로 보존하고 교사의 관찰 기록을 별도로 남긴다. 이미 제공한 힌트·대독 이력은 이후 검토를 수정해도 독립 수행으로 낮춰 바꿀 수 없다. 새로운 독립 수행은 다른 미노출 자료에서 확인한다.

초1~2 배치 승인에는 ‘실제 읽는 모습을 관찰함’ 또는 ‘첫 수업에서 추가 관찰 필요’ 상태와 관찰·계획 메모를 요구한다. 이해 선택형의 정답만으로 해독과 유창성을 확인했다고 표시하지 않는다. 녹음·자동 음성 채점 기능이 추가된 것은 아니다.

학습 수업에서는 짧은 낱말이나 문장으로 답할 수 있음을 안내하고 최종 정리 입력창의 부담을 줄였다. 연습의 도움 여부·서버 제출·교사 공개 절차는 기존 읽기 수업과 동일하다.

## 4주 계획과 단계 이동

코스별 8회 계획, 최근 28일의 서로 다른 새 글 5회 중 4회 성공, 마지막 성공, 2개 이상 수업일, 별도 전이, 교사 설명 검토, 7일 이후 유지 확인을 유지한다. 각 학년이 해당 학년의 자료에서 이 조건을 확인한다.

배치된 첫 수업을 재사용하고 추가 수업을 배정한다. 전이까지 충족하면 교사가 다음 코스 자료를 검토해 이동한다. 이전 코스의 유지 실패는 현재 코스를 초기화하지 않고 해당 기능 보충으로 연결한다. 같은 날 확인을 반복하거나 이미 노출된 자료를 바꾸어 푸는 것으로 단계를 올리지 않는다. 새 자료가 소진되면 추가 공급을 요청하고 이동 판정을 보류한다.

학년을 자동 진급시키거나 재학 학년을 바꾸는 기능은 포함하지 않는다. 한 학생의 최초 배치 응시는 계속 같은 응시를 유지한다. 학년 변경·재진단은 별도 대체 자료와 노출 정책을 갖춘 후속 운영 범위다.

## 기록 보존과 구현 파일

새 진단은 `g16-placement-2` 버전과 전체 문항 스냅샷을 서버에 보존한다. 분기 후에도 같은 버전의 문항을 사용한다. 기존 `g34-pilot-1` 응시는 기존 출제 함수를 유지하므로 진행 중인 답이 다른 문제에 연결되지 않는다. 학생 응답에서 비공개 스냅샷과 정답·채점 키를 제거한다.

새 코스 정책은 `g16-course-2`다. 이미 승인된 계획의 `checkBank`와 평가 본문, 제출·검토 이력은 그대로 사용한다. 기존 계획을 새 자료로 자동 교체하지 않는다. 다음 코스를 새로 승인할 때 현재 학년의 새 편성을 사용한다.

주요 경로:

- `webapp/shared/learning-config.mjs`: 학년 프로필, 코스·학습 수업 연결. 공개 메타데이터만 포함.
- `webapp/server/diagnostic-forms.mjs`: 학년별 시작·분기 진단.
- `webapp/server/grade-checks.mjs`, `grade-upper-checks.mjs`: 학년별 성취 확인 판본.
- `placement-service.mjs`, `course-service.mjs`: 스냅샷·권한·구두 관찰·성취 판정.
- `PlacementJourney.tsx`, `CourseJourney.tsx`: 전 학년 학생·교사 화면.

## 검증
