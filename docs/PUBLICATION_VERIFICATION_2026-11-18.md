첫 빌드 시도에서는 샌드박스가 로컬 HTTP 연결을 `EACCES`로 차단했다. 해당 실행을 중단하고 로컬 연결이 허용된 환경에서 같은 소스의 전체 빌드를 다시 실행해 통과했다. 실패를 성공으로 재분류하지 않았다.

기존 프로젝트의 실행 중인 esbuild 파일 때문에 직접 `npm ci`가 실패했으므로, 별도 공개 사본에서 잠금 설치를 검증했다. 기존 프로젝트 의존성은 `npm install --ignore-scripts --no-audit --no-fund`로 복구했고 manifest/lockfile이 검증 사본과 같은 것을 확인했다.

검사 범위는 자동 구조·기능·전달·경계 검사다. 실제 브라우저 조작·기기·인쇄·현장 수업·침투 검사·운영 증거 승인·교육 효과 검증은 이번에 수행하지 않았다. 패턴 검사가 모든 형태의 비밀이나 외부 자료의 권리를 증명하지 않는다.

원시 작업 로그는 로컬 검증 폴더에 보관하며 공개에 포함하지 않는다. GitHub Actions 실행 결과는 저장소의 Actions 탭에서 별도로 확인한다. 기존 Sites는 재배포하지 않았다.

공개 준비 중 완료된 문학 10차 자료를 추가 반영했다. 작성 중인 운영 자동화 모듈은 로컬에 보존하고 공개 커밋에서 제외한다. 최종 공개 커밋의 사본으로 전체 검사를 다시 확인한다.
