2026-10-14 사용자 방향 반영. 첫 구매자는 학원·공부방이다.

제품의 중심은 세부 문해력 목표에 따른 정밀한 진단·처방이며, 학생이 읽기 사고 과정을 따라 배우는 수업이다. 방대한 교과 지문은 이 수업을 다양한 맥락에서 반복하고 전이하는 기반이다.

2차 확장에서 초3~6 수학·사회·과학 지문 24편과 진단 문항 108개, 개별 사고 시범을 추가했다. 누적 본문은 144편(신규 초안 48편·기존 96편)이며 판매용 승인은 아직 0편이다. [2차 집필·검토 기록](CONTENT_EXPANSION_BATCH_02_2026-10-14.md)에 수업 묶음과 기록 화면, 검증 범위를 정리했다.

## 세 가지 축

| 축 | 묻는 질문 | 관리 단위 |
| --- | --- | --- |
| 문해력 세부목표 | 무엇을 어떤 조건에서 수행해야 하는가 | 목표 ID, 수행 준거, 선수목표, 증거와 판정 규칙 |
| 사고 과정 | 어디를 보고 무엇을 연결해 어떤 판단을 했는가 | 단서 포착·관계 연결·판단·자기 표현, 도움 수준, 응답 원문 |
| 교과 개념과 지문 | 어떤 소재와 글을 통해 연습하는가 | 개념 ID, 성취기준·고시 버전, 지문 ID·버전, 난도·구조·검수 |

기존 `G5-EXP-V1-1` 같은 코드는 목표/수업 틀의 기존 식별자로 보존한다. 지문은 별도 `passageId`를 갖는다. 한 목표에 여러 지문을 연결하고, 한 지문에도 검수된 여러 목표를 연결할 수 있다. 새로운 소재를 추가할 때 목표 ID를 새 지문 ID처럼 늘리지 않는다.

## 학생이 따라가는 사고 과정

1. **생각 시범:** 교사가 실제 본문을 짚으며 ‘이 부분을 보는 이유, 이 단서가 뜻하는 것, 두 내용을 연결하는 이유’를 말한다.
2. **함께 연습:** 학생이 단서를 선택하고 연결을 완성한다. 막힌 단계에만 필요한 도움을 준다.
3. **도움 줄이기:** 같은 기능을 요구하는 다른 부분에서 스스로 근거와 판단을 만든다.
4. **새 글에서 확인:** 해설을 보지 않은 새 지문에 같은 기능을 적용한다.
5. **자기 표현:** 판단의 근거와 관계를 말이나 글로 설명하고, 피드백을 받아 고친다.

설명 탭을 열었다는 사실이나 읽기 시간만으로 사고 과정을 이해했다고 판정하지 않는다. 목표별로 필요한 단계를 선택한다. 모든 목표에 동일한 화면 순서를 강요하지 않는다.

현재의 `prototype_step1_2`는 활동 안내문이다. 교사의 완성된 사고구술 대본과 동등하지 않다. 다음 콘텐츠 편집에서는 **시범 대본, 시범이 짚는 본문 범위, 예상 오해, 단계별 힌트, 학생 수행, 독립 확인 지문, 쓰기 준거**를 따로 작성한다.

## 정밀 진단과 처방의 단위

문항 정오답과 사고 과정의 관찰을 연결하되, 관찰하지 않은 원인을 확정하지 않는다. 예를 들어 답을 틀렸다는 이유만으로 ‘인과 추론 결손’으로 판단하지 않는다. 관련 문장을 찾았는지, 원인과 결과를 구별했는지, 연결어를 이해했는지 추가 관찰한다.

| 관찰 | 다음 지도 후보 | 확인할 것 |
| --- | --- | --- |
| 관련 구절을 찾는 데 도움 필요 | 대상·특징 및 단서 선택 연습 | 낱말 이해와 정보 위치 탐색을 구별 |
| 구절은 찾지만 관계 연결에 도움 필요 | 두 명제 연결, 지시 대상·인과 방향 비교 | 필요한 선수 기능과 연결 근거 |
| 연습 글에서는 성공, 새 소재에서는 어려움 | 같은 목표의 다른 교과 지문 제공 | 읽기 기능과 배경지식·어휘 부담을 분리 |
| 힌트 뒤에만 성공 | 해당 단계의 시범·공동 수행 후 도움 축소 | 독립 수행과 동일 점수로 합치지 않음 |
| 답·근거는 적절하나 설명이 미완성 | 관계를 문장으로 만드는 표현 지도 | 내용 이해와 쓰기 표현을 구별 |

이 표는 지도 설계 원칙이며 검증된 자동 판정 규칙이 아니다. 실제 엔진에는 목표별 채점 준거, 최소 관찰 수, 상충 증거 처리, 추천 이유, 교사 변경, 규칙 버전과 재검사 조건이 필요하다.

`ProcessObservation`에는 학생·세부목표·지문 버전·활동·사고 단계·도움 수준·연습/독립확인/전이확인·지문 노출 여부·수행 결과·근거·시각을 남긴다. `summarizeProcessEvidence`는 단계별 관찰을 요약하는 기반 함수이며, 인증된 능력 지수나 자동 처방 엔진이 아니다. 아직 학생 화면의 모든 행동과 서버 기록에 연결하지 않았다.

## 2022 개정 교육과정 전 교과 지문 은행

장기 범위는 초1~6의 국어·수학·사회·도덕·과학·실과·체육·음악·미술·영어와 저학년 통합교과에서 확인한 개념이다. 영어 교과에서 가져오는 소재를 국어 읽기 지문으로 활용하는 것과 영어 읽기 평가를 혼동하지 않는다. 개념이 국어 설명문에 적합하지 않으면 억지로 동일 형식에 넣지 않고 자료 읽기·절차·비교 등 적절한 표현을 정한다.

공식 원천은 [교육부 2022-33호 총론·각론 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)와 [국가교육위원회의 2026-1호 일부개정 고시](https://www.ne.go.kr/new/user/bbs/BD_selectBbs.do?q_bbsDocNo=20260121102419070&q_bbsSn=1016)를 시작점으로 삼는다. 일부개정이 있으므로 ‘2022’라는 이름만 저장하지 않고 고시·별책·원문 위치·적용 시점까지 추적한다. 후속 집필 작업에서 별책 5~15를 확보하고 초등 성취기준 611개를 추출했다. 사회·음악 일부개정 대조 및 수식 객체의 원문 교정은 남아 있다. 학기 지도 96개 묶음, 개념·기능 후보 826개, 새 지문 24편의 현황과 한계는 [교과 개념 원장과 1차 집필 기록](CURRICULUM_CONTENT_INVENTORY_2026-10-14.md)에 정리했다.

### 원천에서 게시까지

1. 공식 원문 확보와 버전 고정 → 교과·학년군·영역·성취기준·내용 요소 추출.
2. 교과 개념을 독립 식별자로 정리하고 원문 위치·유사 개념·선수 개념 연결.
3. 개념과 문해력 목표를 연결할 수업 설계표 작성. 목표를 수행할 수 있는 글 구조 선택.
4. 지문 초안 작성. 사실 근거, 설명 관계, 어휘, 문장·문단 난도, 배경지식 부담 기록.
5. 시범 대본·활동·오답 이유·단계별 도움·자기 설명 과제 작성.
6. 사실·교육과정·학년 적합성·정답 근거·권리·중복·화면 검수.
7. 승인된 버전만 게시. 수정 시 이전 응시가 참조한 버전 보존.

교과서 문장을 대량 복제하지 않는다. 교육과정 개념을 원천으로 자체 지문을 작성하고 사실 근거와 사용 권리를 확인한다. 자동 생성은 초안 상태로 끝나며 게시 승인을 대신하지 않는다.

### 양을 늘리는 방식

한 개념에 관찰·정의·비교·인과·분류·문제해결 등 적합한 글 구조와 여러 생활 소재를 배치한다. 여기에 입문·기본·도전 수준과 시범·연습·독립확인·전이확인 용도를 구분한다. 모든 조합을 기계적으로 곱해서 숫자를 채우지 않는다.

수천 편 규모를 장기 제작 목표로 두되, 공식 개념 목록과 편집 처리량을 확인한 뒤 수량을 확정한다. 예를 들어 검수된 개념 500개에 서로 다른 지문 4편을 만들면 2,000편이지만 **500개와 2,000편은 산술 예시이며 현재 보유량이나 확정된 교육과정 개념 수가 아니다.**

관리 화면은 전체 파일 개수보다 ‘교과·학년군·개념·목표별 승인 지문 수, 훈련용/평가용 분리, 미충족 영역, 내용 유사도, 검수 대기’를 보여준다. 동일 지문 제목만 바꾼 자료는 새로운 지문으로 세지 않는다.

## 이번 구현과 다음 실행

이번에는 기존 설명문에서 **96개 개념 후보·96개 목표·96개 지문**을 분리한 초기 색인과 자료 구조를 만들었다. 개념·지문의 검수 상태는 모두 `needs_review`이며 공식 성취기준 매핑 배열은 비어 있다. 기존 학년·단원 표시는 원본의 주장으로 보존하며 검증된 교육과정 매핑으로 승격하지 않는다. 학습 화면은 여전히 기존 수업별 대표 지문을 사용하고, 대규모 지문 선택·게시 시스템은 후속 개발이다.

다음 콘텐츠 작업은 **공식 개념 원장과 커버리지 표 → 대표 세부목표의 사고구술·진단 준거 → 서로 다른 소재의 훈련·전이 지문 묶음 → 교사 검토** 순서로 진행한다. 모든 교과의 목록화는 병행하되 실제 상품에 공개할 지문은 수업 검증을 통과한 묶음부터 늘린다.
