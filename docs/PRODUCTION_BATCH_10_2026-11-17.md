## 실제 적용과 확인

원장은 확인된 처리정지 요청에서 현재 영향 계정·진행 기록·종료할 다른 로그인을 미리 확인한다. 현재 비밀번호와 등록된 경우 새 MFA 코드, 검토 문서 번호, 실제 확인과 요청자 안내를 다시 입력해야 적용한다. 미리보기 뒤 요청·대상 버전·진행 기록·로그인이 바뀌면 서버가 거절한다. 같은 요청 식별자의 재전송은 중복 적용하지 않는다.

학생·보호자·교사 계정을 대상으로 한다. 보호자의 정지는 확인된 연결 자녀의 일반 이용도 제한하므로 영향 목록을 검토해야 한다. 이 종속 목록은 적용 시 보관하여 단순 연결 해제·관계 만료로 학생 이용 제한이 풀리지 않는다. 다른 보호자의 정당한 별도 이용 근거가 있으면 운영자가 범위를 검토하고 명시적으로 해제해야 한다. 자동 부분 해제는 구현하지 않았다. 서로 다른 정지가 겹치면 마지막 유효 정지를 해제할 때까지 제한을 유지한다. 마지막 운영자는 다른 운영자에게 권한을 인계하기 전 정지할 수 없고, 정지된 운영자가 본인 권한으로 정지를 풀 수 없다.

일반 API는 제한 계정의 읽기·변경을 423으로 거절한다. 다른 이용자의 정상 홈·대시보드·집계·CSV·인쇄 준비에는 대상 학습 자료를 포함하지 않는다. 원장 명단에는 권리 처리를 위한 최소 이름·역할·반·제한 여부만 남긴다. 일반 교사의 이전 반 기록 접근도 변경 차단 대상이다. 본인 권리 행사, 현재 비밀번호 변경·MFA와 필요한 보안·권리 업무는 별도로 유지한다. 보존 근거의 적법성은 문서 번호 입력만으로 자동 판정하지 않는다. 자유 서술의 모든 이름이나 이미 반출된 자료를 자동 탐지·회수하는 기능은 아니다.

적용·해제 시 영향 계정의 기기 초안 키를 회수하고, 대상·관련 보호자·담당 교사·운영자의 다른 세션을 종료한다. 실제 화면은 서버 응답과 세션 확인 때 일반 기록을 닫고 제한 안내와 권리 요청 화면으로 이동한다. 오프라인 상태의 기존 화면, 이미 본 기록·스크린샷·내려받은 파일을 원격으로 지우는 기능은 아니다. 실제 단말 동작은 아직 확인하지 않았다.

## 진행 기록과 공개본

진행 중 시험의 남은 응시 시간을 정지 상태에 저장하며, 서버 재시작 뒤에도 자동 시간 종료 제출을 하지 않는다. 마지막 정지 근거를 해제하면 보관한 남은 시간으로 이어서 응시한다. 읽기는 정지 전 제출 가능했던 진행 기록의 남은 제출 시간을 보관한다. 이미 기한이 지난 기록은 정지만으로 소급해 유효해지지 않는다. 수업 마감 연장이 겹치거나 해제 뒤 다시 연장하면 더 늦은 유효 기한을 반영한다. 아직 시작하지 않은 배정의 기한은 개별적으로 연장하지 않는다.

보호자에게 공개한 시험·읽기 결과는 정지 때 회수한다. 읽기 공개 사본은 별도 보존하며 일반 제공만 차단한다. 해제로 이전 공개본을 자동 복원하지 않는다. 교사의 현재 권한·동의·학생 상태와 결과 재검토 후 명시적으로 다시 공개해야 한다. 학생·보호자의 읽기 상세 응답은 해당 학생의 배정 식별자만 포함하도록 함께 보완했다. 과거 사본을 조회할 때도 다른 학생의 식별자를 노출하지 않는다.

## 저장과 실패 경계

처리정지 근거·이력은 계정 운영 원장, 요청·검토 내용은 기존 암호화한 권리 요청 원장에 저장한다. 정지 상태 자체를 모든 서버 개인정보의 암호화 완료로 해석하면 안 된다. 세션·초안 키 회수, 시간 보존, 공개 회수, 요청 상태와 접속기록을 같은 SQLite 트랜잭션에서 반영한다. 감사 기록 저장 장애 시 모두 취소한다. 외부 문서 원본을 업로드하거나 신분증 번호를 수집하지 않는다.

해제는 기존 정지 ID가 일치하는 요청에서 현재 본인·대리인 확인과 해제 의사 문서·보존 검토 참조를 확인한다. 요청 취소나 이의 제기로 적용된 정지를 몰래 없애지 않는다. 이의 제기 후에는 재확인이 필요하다. 원장 계정·법정대리인 확인·현재 비밀번호·MFA를 클라이언트에만 의존하지 않는다.
