## 1. 디자인 방향

“따뜻하게 읽고, 선명하게 생각하다.”

기존 CI의 네이비, 블루, 시안, 에메랄드, 골드를 계승하면서 화면의 정보 밀도와 장식을 낮췄다. 따뜻한 종이색과 명조 본문, 정돈된 고딕 UI, 절제된 선 아이콘을 함께 사용한다. 브랜드 소개에는 넉넉한 여백을, 읽기 화면에는 본문과 사고 활동의 관계를, 관리 화면에는 검색과 검토의 순서를 우선한다.

원본 SVG를 개선해도 좋다는 사용자 요청에 따라 Rx-5의 R/X 결합과 골드 +를 유지하면서 심벌을 재설계했다. 기존 CI 문서는 이력으로 보존하고 이 문서가 이번 구현의 변경 기준을 설명한다.

## 2. 로고 원본과 규칙

- 컬러 SVG: [readx-symbol.svg](../webapp/public/brand/readx-symbol.svg)
- 단색 SVG: [readx-symbol-mono.svg](../webapp/public/brand/readx-symbol-mono.svg)
- 앱 컴포넌트: [ReadXBrand.tsx](../webapp/src/components/brand/ReadXBrand.tsx)
- 화면 하단 ‘ReadX 디자인 가이드’에서 시각 규칙 확인과 SVG 다운로드 가능.
- 전체 표기는 ReadX-Ray Pro, 작은 화면의 제품 내 표기는 ReadX.
- 64 × 64 viewBox, 모서리 17, 주획 5.5, 교차 분리획 9, 골드 + 획 3.
- 기존 외곽의 시안 테두리와 원형 배지를 덜어내고 심벌 안쪽 여백을 확장.
- 교차부의 네이비 간격으로 시안과 에메랄드 획을 분리. 흑백에서도 읽히도록 단색 버전 제공.
- 기본 표시 40px, 모바일 30~33px. 일반 사용에서는 24px 이상 권장. 파비콘은 별도 소형 사용.
- 여유 공간은 심벌 너비의 1/4 이상 권장. 회전, 비율 왜곡, 임의 그림자·그라데이션 금지.
- 화면 헤더, 푸터, 브랜드 가이드, 상담 보고서 예시, 파비콘에 반영.

## 4. 서체·레이아웃

- UI: Pretendard, 시스템 한글 고딕 폴백.
- 읽기 본문·일부 편집형 제목: MaruBuri, 명조 폴백.
- 본문 크기 작게/보통/크게와 종이/세피아/야간 모드 제공.
- 지문에는 넉넉한 행간과 한글 어절 줄바꿈 적용.
- 데스크톱에서 본문과 활동을 나란히 배치. 900px 이하에서 본문/활동 전환.
- 모바일 전환 시 두 패널을 유지하고 표시만 바꿔 작성 중 응답 소실 방지.
- 1100 / 900 / 600px 구간에서 메뉴·카드·본문 폭 조정.
- 포커스 링, 본문 건너뛰기 링크, 버튼 이름과 선택 상태, 모션 축소 환경 대응.
- 새 공통 모달은 native dialog로 초점 제한, Escape 닫기, 원래 버튼으로 초점 복귀를 사용.

## 5. 화면별 적용 내용

| 화면 | 새 구성 | 실제 연결한 동작 |
|---|---|---|
| 브랜드 홈 | 편집형 소개, 읽기의 4단계, 역할별 진입 | 학생·교사·학부모·콘텐츠 관리 이동 |
| 학생 배움터 | 다음 수업, 이어 읽기, 기록, 단어장 | 수업 열기, 자료 검색, 글 다시 보기, 낱말 저장·제거 |
| 읽기 스튜디오 | 종이형 본문, 근거 찾기 기본 활동, 분리된 도구 | 문단 근거 담기, 수업별 메모, 읽기 설정, 답안·탭·스크롤 복구 |
| 교사 수업실 | 오늘 수업, 수업 자료, 검토 노트, 반 명단 | 학년·검색 필터, 학생 화면 미리보기, 기기 내 체험 과제 추가, 검토 메모 |
| 학부모 공간 | 현재 연습, 직접 쓴 문장, 대화 질문 | 기기 내 응답 확인, 질문 전환, 인쇄 |
| 콘텐츠 관리실 | 공통 브랜드 헤더·제목, 자료 요약, 편집과 검토 | 기존 검색·편집·검증·파일 내보내기 유지 |
| 공통 | 역할 헤더, 푸터, 디자인 가이드, 체험 안내 | 홈·목록 복귀, 브라우저 경로 복구, SVG 다운로드 |

수업별 메모는 기존 학년 공통 예시 메모와 분리했다. 저장 실패 시 입력을 메모리에 유지하고 읽기 화면에 안내한다. 근거 문단을 선택했다는 사실만으로 정답·숙련을 판정하지 않는다.

## 6. 적용 범위와 후속 개발

이번 변경은 브랜드와 주요 역할 화면의 UI/UX, 그리고 브라우저 기기에 저장되는 연습 기능이다. 실제 계정, 권한, 학생별 서버 저장, 정식 과제 제출·회수, 실시간 반 관리, 교사 승인, 검증된 진단·성장 리포트는 후속 개발이 필요하다.

기존 세부 활동·게임·초기 확인·시험·운영 예시는 유지했다. 공통 화면 틀과 스타일을 적용했으나 이들 내부의 모든 활동 UI를 새 컴포넌트로 재작성한 것은 아니다. 전체 개선 계획의 기능이 모두 구현됐다고 해석하지 않는다.

기존 콘텐츠의 교육과정 대응·출처·난도 검수는 UI 개편과 별도이며, 공식 교육과정 전체 수록이나 검증 완료로 표시하지 않는다.

후속 순서:
1. 학생별 계정·권한·서버 저장·복구.
2. 교사 배정 → 학생 제출 → 검토·재작성으로 이어지는 실제 수업 흐름.
3. 목표별 여러 지문과 도움 사용·전이 학습을 연결하는 기록 모델.
4. 공통 활동 컴포넌트 정비와 기존 선택형 활동의 키보드 접근성 보완.
5. 교사·학생 사용성 관찰 및 실제 저학년 읽기 부담 검증.

## 7. 검증

2026-10-14 로컬 Chromium 환경에서 확인:
- 데스크톱 메인·학생·읽기·관리자 및 브랜드 가이드 시각 검토.
- 390 × 844 모바일 메인·읽기 전환·단어장 검토.
- 768 × 1024 태블릿 교사·학부모 화면 검토.
- 문단 근거 선택 → 세피아 모드 → 새로고침 뒤 선택과 설정 복구.
- 모바일 본문/활동 전환 뒤 기존 서술 초안 유지.
- 본문 낱말 저장 → 학생 단어장에 ‘용해도’ 추가 확인.
- 교사 검색 결과 없음 → 검색 조건 변경 → 체험 과제 추가 성공 안내.
- 학부모 화면에서 기기에 작성된 문장 확인.
- 관리자 ‘개나리’ 검색, 브랜드 가이드 열기, Escape 닫기.
- 브라우저 콘솔의 오류·경고 없음(검증 시점).
- 자동 테스트 12개 통과: 기존 10개와 수업별 이어하기 복구·저장 실패 회복 2개.
- 기존 96개 수업 × 5개 활동 렌더 및 공통기초 36개 렌더 검증 포함.
- TypeScript 검사 및 production build 통과.

음성 기능은 지원 여부·오류 안내를 구현했으나 이 환경에서 실제 한국어 재생 음질은 확인하지 않았다. 인쇄 스타일은 추가했으며 실제 프린터 출력은 수행하지 않았다. 전체 접근성 적합성 인증이나 실제 학습 효과 검증을 의미하지 않는다.
