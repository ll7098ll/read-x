학생 홈에서 초5·6 미니 모의고사를 시작하고, 제출 성적·학습이력·목표별 증거·보충학습·새 글 확인으로 이어지는 개인 연습 흐름을 구현했다. [개발 계획](./ELEMENTARY_MOCK_EXAM_AND_DASHBOARD_PLAN_2026-10-15.md)의 첫 개발 묶음에 해당한다.

## 이용 방법

`webapp`에서 `npm run dev`로 실행한다. 학생 배움터의 **미니 모의고사**, **성적 분석**, **나의 목표**, **학습이력** 메뉴를 사용하거나 `#/student/assessment`로 들어간다. 학년 선택에서 초5·6의 기록을 구분한다. 진행 중인 시험은 안내 화면과 학습이력에서 이어서 열 수 있다.

시험지의 모든 문항은 본문 근거와 다섯 선지의 이유를 갖는다. 초6 새 글 확인에는 색인·복합 관람 조건·분류 우선순위·백업 순서·자발적 응답 표본·참여 집단 변화 등 초5와 다른 글을 제공한다. 사례의 조사 수치와 작동 모형은 명시적으로 가상 자료로 작성했다.

## 성적과 목표의 계산

시험의 모든 문항을 분모에 넣고 미응답을 0점으로 처리한다. 11/12 정답은 91.7점, 1/12 정답은 8.3점이다. 정답과 해설은 제출 후 화면에서 연다. 시험지 전체를 시도 시작 때 복제하므로 이후 콘텐츠 변경이 이미 시작한 시험의 채점에 영향을 주지 않는다.

처음 시작한 글 계열에서의 첫 시험과 처음 보는 새 글 확인을 목표 근거로 사용한다. 같은 시험 재응시와 도움받은 보충학습은 최초 성적을 덮어쓰거나 새 독립 수행 증거를 늘리지 않는다. 답·근거 제출이 끝나지 않은 새 글은 성공 건수에 들어가지 않는다.

개인 연습 기준은 최근 28일의 글 계열 3개 이상·세션 2회 이상·확인 5건 이상이며, 최근 5건 중 4건 이상과 마지막 확인이 성공해야 한다. 새 글 두 계열에서 답과 근거까지 성공하면 전이 상태로 표시한다. 과거의 기준 충족은 보존하며 새 실패나 오랜 미확인에는 재확인 상태를 표시한다. 이 판정은 명시한 선택형 과제의 연습 지표다. 서술·쓰기 능력과 공인 문해력 수준은 별도 검토가 필요하다.

## 저장과 운영 경계

새 기록은 `readx_student_assessment_v1`에 저장하며 기존 학습 로그를 추정 이관하지 않는다. 화면 집계는 같은 응시·보충학습·확인 기록에서 만든다. 날짜 경계와 표시는 한국 시간으로 계산한다.

이번 구현은 **로그인과 서버 동기화가 없는 브라우저별 개인 연습판**이다. 브라우저 저장소나 기기 시각의 조작을 막는 공식 시험 환경이 아니며 정답 키도 클라이언트 콘텐츠에 포함된다. 전국 참여자 비교·기관별 권한·보호자 연동·서버 채점은 후속 운영 기반 단계다. 현재 콘텐츠 상태는 시범이며 교사 검수를 거쳐 정식 출제 승인해야 한다.

## 검증

`npm run build`가 TypeScript 검사, 자동 검사 56개, Vite 패키징까지 통과했다. 이 중 새 모의고사 관련 검사는 12개다. 새 검사는 시험지·근거 무결성, 점수와 미응답, 최초 선택과 마감, 시험지 고정, 재응시 제외, 목표 판정·유지, 실제 저장과 복구, 중복 활동 방지, 대체 근거, 해설 비노출, 빈 화면, 저장 실패를 확인한다.

브라우저에서는 다음 흐름을 직접 확인했다.

- 초5 12문항 제출 → 11/12·91.7점 → 실제 오답 보충학습 → 새 글 두 편의 답·근거 확인 → 목표 기준 충족 1/3개.
- 이 과정의 응시·보충학습·새 글 확인 두 건이 학습이력 4건과 달력에 일치함.
- 새로고침 후 답·남은 시간·지문 위치가 유지됨.
- 초6 1문항 정답·11문항 미응답 제출 → 8.3점. 초5의 91.7점과 목표 기록이 유지됨.
- 휴대전화 390픽셀 화면에서 대시보드와 지문/문제 전환을 확인하고 페이지 가로 넘침이 없음을 확인함.
- 브라우저 콘솔 오류 없음.

기존 교과 자료실 검사의 고정 문항 수는 편집 콘텐츠 확장과 맞지 않아, 원천 기준본과 현재 편집본의 실제 문항 수를 대조하도록 수정했다. 학년·교과·활동 필터는 별도 입력 사례로 검증한다.
