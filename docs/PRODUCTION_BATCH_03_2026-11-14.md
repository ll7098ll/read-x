## 실제 이용

첫 화면에서 학원 원장의 운영실을 선택하거나 로그인 후 공통 헤더의 학원 운영·반 운영·계정 설정으로 진입한다. 주소는 운영자·교사 `#/teacher/manage`, 학생 `#/student/account`, 보호자 `#/parent/account`다.

처음 생성한 교사 계정은 해당 학원의 운영 권한을 갖는다. 기존 DB는 기관별 최초 교사 계정에 운영 권한을 연결하고 기존 반과 학생 관계를 이관한다. 운영 권한은 교사 계정에 별도 저장하며, 담당 반 권한과 구분한다. 주소나 요청 본문에 역할을 넣어 운영 권한을 얻을 수 없다.

- 원장: 학원 이름, 반 생성·이름 변경·운영 종료, 교사 계정과 담당 반·운영 권한, 학생 이름·반 이동·재원/휴원/퇴원·이용 종료일·활성 상태, 보호자 연결을 관리한다.
- 교사: 담당 반의 원생·수업·평가·출석·상담만 다룬다. 원장이 여러 반을 관리할 수 있고, 교사는 복수의 담당 반을 가질 수 있다.
- 학생과 보호자: 자신의 현재 비밀번호로 새 비밀번호를 설정할 수 있다. 변경 후 다른 기존 세션과 복구 코드는 폐기한다.
- 운영자: 본인 확인과 발급 사유를 남기고 15분 유효 일회용 복구 코드를 발급한다. 로그인 화면의 비밀번호를 잊었어요에서 아이디·코드·새 비밀번호를 입력한다. 코드는 한 번만 사용되며 DB에는 코드 해시를 저장한다.

마지막 활성 운영자 계정의 권한 해제·비활성화는 차단한다. 학생의 반 이동·휴원·퇴원은 수업·평가 기록을 삭제하지 않는다. 계정 상태·권한·보호자 연결을 변경하면 해당 계정의 기존 로그인은 해제된다. 휴원·퇴원·비활성·이용 종료 학생은 접속과 새 배정이 차단된다. 과거 공개 결과에 대한 보호자 권한은 실제 연결 여부로 판단한다.

## 반 이동과 과거 기록

시험·읽기 수업을 배정할 당시의 반 ID를 고정한다. 학생이 다른 반으로 이동해도 과거 기록은 원래 반의 담당 교사와 학생 본인·허용된 보호자가 확인한다. 새 반 교사가 이전 반 권한 없이 과거 기록을 열 수는 없다. 원장은 기관 전체 기록을 확인한다. 과거 학생 이름 표시를 위해 필요한 정보만 이전 담당 교사에게 제공하고, 새 반·활성 상태 등 현재의 상세 정보를 전달하지 않는다.

반을 종료하기 전에 재원 학생을 이동하거나 상태를 변경해야 한다. 출석·상담은 버전 검사를 적용해 동시 수정 덮어쓰기를 막고, 변경 사유와 실행자·시각을 기록한다. 상담 메모는 담당 교사와 운영자만 확인한다.

기존 수업·평가 계정은 같은 ID와 기록을 유지한다. 읽기 수업 테이블의 내부 저장 키에는 기관 ID를 포함하도록 이관했다. 같은 지문을 서로 다른 기관에서 승인해도 승인 기록이 덮어써지지 않는다. 기존 배정의 반 연결은 서버 시작 시 이관해 이후 반 변경으로 과거 배정의 반이 바뀌지 않게 했다.

## 원장 계정 복구

원장도 비밀번호를 잊었다면 서버 파일에 접근할 수 있는 운영 담당자가 기존 DB를 지정해 다음 명령을 실행한다.

```powershell
cd webapp
node server/recover-owner.mjs --username 기존원장아이디
```

별도 DB는 `--db 실제DB경로`로 지정한다. 이 명령은 기존의 활성 원장 계정에 대해서만 일회용 복구 코드를 발급한다. 새 계정 생성이나 운영 권한 부여는 수행하지 않는다. 출력 코드는 본인 확인을 마친 해당 계정의 소유자에게만 전달한다. 화면 코드 발급·사용·로컬 발급 이력은 서버 감사 기록으로 남긴다.

## 검증

최종 `npm run build` 통과. 화면·학습 검사 75개, 서버·통신·기관 운영 검사 17개, 합계 92개 통과. 운영 번들에 정식 시험의 비공개 해설과 체험 엔진이 포함되지 않는 검사도 통과했다.

추가 검사는 담당 반별 학생·평가·수업 접근, 다른 반 학생 등록·배정 차단, 반 이동 후 과거 기록 보존, 일회용 복구의 사용·만료·재사용 차단, 기존 세션 폐기, 비밀번호 변경, 보호자 연결 해제 후 공개 결과 접근 차단, 휴원 접속 차단, 마지막 운영자 보호, 출석·상담 권한과 동시 수정, 기관별 승인 격리, 서버 파일을 이용한 원장 복구를 포함한다.

실행 서버의 별도 `qa-organization-2026-11-14.sqlite`에서 학원·반·원생·출석·상담과 학생 제출·교사 공개·보호자 4.2점 리포트 연결을 확인했다. 모든 계정과 기록은 가상의 검증 자료다. 증거는 실제 HTTP 확인 (`output/organization-http-evidence-2026-11-14.json`, 로컬 보관·공개 제외), 전체 빌드 로그 (`output/organization-build-2026-11-14.log`, 로컬 보관·공개 제외)에 보관한다.

별도 Chrome 탭으로 최종 화면 조작을 검증하려 했으나 사용자가 Escape 키로 컴퓨터 제어를 중단했다. 이후 UI 입력은 수행하지 않았다. 기관 운영·읽기 수업·평가의 전체 브라우저 조작과 태블릿 검증은 미완료 상태다.
