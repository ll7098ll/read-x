## 콘텐츠

초기 132슬롯, 개정 읽기 144지문, 학습 코스와 국어 확장 원고는 서로 다른 자산이다. 합산하여 독립 검증 문항 수로 소개하지 않는다. 144지문은 432개 수준별 변형·720개 기본 연습 문항을 포함한다. 최신 집필 수량과 앱 연결·교사 승인·학생 보정 상태는 [콘텐츠 안내](CONTENT.md)를 따른다.

## 현재 경계

- 정적 가상 체험판 기록과 서버 계정 기반 학습 기록은 분리된다.
- 초기 Firebase/Firestore 파일은 스키마·내보내기 참고 자산이다. 기본 계정 서버는 SQLite이며 Firebase SDK 연동은 구현되지 않았다.
- Kiwi WASM, 완전한 오프라인 PWA, 결제·문자 실연동, 외부 AI 채점은 현재 구현으로 보장하지 않는다.
- 정답·채점 코드도 공개된 개발용 예제다. 비공개 평가에는 신규 문항과 비공개 공급 경로가 필요하다.
- 운영 준비 23개 통제는 미완료다. `check:readiness` 실패는 현재 기대 상태다.
- 실제 단말·현장·침투 검사와 교육 효과 검증은 자동 테스트로 대체하지 않는다.

검사 결과는 [변경 기록](../CHANGELOG.md)에 남긴다. 기존 공개 사이트 버전과 GitHub 소스 버전을 같은 번호로 취급하지 않는다.

## 이번 공개의 고정 범위

문학 확장 10차까지의 완료 원고를 포함한다(국어 V2 342자료·1,478문항·72기능). 같은 폴더의 다른 채팅에서 작성 중인 `webapp/server/operations*.mjs` 운영 자동화 모듈·검사는 이번 공개 커밋에서 제외하고 로컬에 보존한다. 정규 운영 구현 기준은 14차다.
