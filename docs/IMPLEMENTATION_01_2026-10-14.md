## 확인 결과

`webapp`에서 `npm run build`를 실행하면 TypeScript 검사, 자동 테스트, 배포용 번들 생성이 순서대로 수행된다.

- 최종 빌드 성공. 자동 테스트 10개 모두 통과.
- 설명문 96개 × 5개 활동 = 480회와 공통기초 36개를 서버 렌더링하여 데이터에 따른 렌더 오류를 검사했다. 모든 화면의 브라우저 클릭 검사를 대신하는 결과는 아니다.
- 원본 보존·변환 재실행 일치, 잘못된 ID·학년·편집본 거절, 정답과 근거 참조, 체험 기록 격리, 초안 재수화, 여러 지문 조회, 사고 과정 관찰 구분을 검사했다.
- 브라우저에서 과제의 실제 지문 연결, 답과 근거 연결 화면, 쓰기 진입과 새로고침 후 초안 복구, 공통기초 정답 피드백, 관리자 콘텐츠 현황을 확인했다. 검증 탭에서 확인한 콘솔 오류는 없었다.
- `git diff --check` 통과. 수정 전 상태를 로컬 Git 커밋으로 남겼다.

## 현재의 한계

- 실제 계정·학원별 권한·서버 저장·교사 제출·배정 완료·학부모 공유는 연결하지 않았다. 현재의 과제와 초안은 기기 체험용이다.
- 점수와 성장 그래프에 남아 있는 예시 값은 진단 결과가 아니다. CAT 화면도 진단 시뮬레이션이다.
- 관찰 요약 함수는 목표별 숙달 판정이나 자동 처방 엔진이 아니다. 학생 활동 전체와 서버 기록에도 아직 연결하지 않았다.
- 기존 활동 안내를 보여주는 단계다. 본문을 짚는 교사의 사고구술 시범, 단계별 힌트, 독립 수행 확인, 목표별 채점 준거를 새로 편집해야 한다.
- 기존 자료에서 만든 96개 개념 후보와 96개 지문은 모두 검수 대기 상태다. 공식 성취기준 매핑은 비어 있으며 전 교과 개념 원장이나 대량 신규 지문은 아직 없다.
- 구조도 참고 자료의 완전한 상호작용 활동 전환, 전체 반응형 UI와 접근성 점검, 콘텐츠 분리 로딩은 남아 있다. 현재 단일 HTML 번들은 약 2.39 MB, gzip 약 548 KB다.

## 다음 개발 순서

1. **개념 원장:** 공식 교육과정의 교과·학년군·성취기준·내용 요소를 원문 위치와 고시 버전으로 기록하고 전체 범위의 누락을 표시한다.
2. **대표 목표의 수업 완성:** 목표별 수행 준거, 사고구술 시범, 예상 오해, 단계별 도움, 훈련용과 새로운 전이 확인용 지문을 한 묶음으로 만든다.
3. **실제 기록과 교사 처방 연결:** 계정과 학원 권한, 활동 원문·근거·도움 기록, 교사의 검토와 배정을 연결한다. 관찰이 부족하면 추가 확인이 필요하다고 표시한다.
4. **수업 검증 후 확장:** 교사와 학생의 사용성을 확인한 묶음을 기준으로 편집·검수·게시 과정을 만들고 지문 수를 늘린다. UI와 브랜드도 이 수업 흐름을 중심으로 다듬는다.

대량 지문은 같은 기능을 서로 다른 글에서도 수행하게 만드는 자산으로 축적한다. 진단 정확도는 파일 개수보다 목표에 맞는 관찰과 독립 수행 증거를 통해 검증한다.
