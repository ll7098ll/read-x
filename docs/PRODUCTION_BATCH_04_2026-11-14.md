## 공통 홈과 리포트

역할별 `#/student/home`, `#/teacher/home`, `#/parent/home`와 공통 `#/home`에서 로그인한 계정의 실제 범위를 조회한다. 첫 화면의 학생·교사·학부모 버튼은 공통 홈으로 연결한다. 헤더에서 학습 현황·읽기 수업·모의고사·학원/반 운영·계정 설정으로 이동한다.

리포트는 서버 원장의 배정·학생별 수행·제출·검토·공개본·평가·보충 기록에서 산출한다. 조회 기간은 한국 시간의 배정일 기준이며 해당 과제의 현재 처리 결과를 보여 준다. 날짜·학생·담당 반 필터를 적용한다. 주차별 결과는 같은 난도의 반복 측정이나 공인 능력 지수로 표시하지 않는다.

- 과제 배정·제출·공개, 미제출 기한 경과와 교사 검토 대기.
- 읽기 첫 선택 답과 필요한 근거, 첫 응답 시 도움 질문 사용, 수정 응답 수.
- 교사가 확인한 설명·근거. 미검토 응답은 분모에서 제외하고 실제 0점과 관찰 없음을 구분.
- 조회 권한이 있는 평가 정답/전체 문항. 학생 공개·보호자 공개 전 성적 제외.
- 배정 주차별·학생별·읽기 행동별·수업 목표별 관찰과 실제 응답·교사 의견 예시.
- 보충 확인 활동과 새 글에서 선택 답·교사 근거 검토를 함께 확인한 수행. 재노출 글은 새 글 성공으로 중복 집계하지 않음.

부모 리포트는 공개 스냅샷만 사용한다. 교사의 비공개 수정은 재공개 전 반영하지 않고 공개 회수 후에는 결과를 제외한다. 미공개 응답은 점수 0으로 취급하지 않는다. CSV는 서버에서 같은 조회 결과로 생성하고, 스프레드시트 수식으로 실행될 수 있는 입력을 이스케이프한다. 인쇄/PDF 버튼과 수업·평가의 개별 기록 주소도 연결했다.

늦게 전송된 수정 이력의 최종 도움 수준이 첫 응답에 소급 적용되는 경우를 보완했다. 완료된 보충 활동은 기존에도 원본을 유지했지만, 변경한 답을 다시 보내도 성공 응답을 반환했다. 이제 같은 답의 재전송은 허용하고 완료 답·복습 내용을 변경하려는 요청은 409로 명시적으로 거절한다.

## 법률 개인정보 보안 운영 기준 추가

확정된 전제는 직접 운영하는 학원, 교사 등록 후 보호자 동의·연결, 국내 운영 예정이다. 결제·문자 도입을 검토하며 업체·사업자 명의·서버·책임자 등은 아직 미정이다. [개인정보 법률 보안 운영 계획](PRIVACY_SECURITY_OPERATIONS_PLAN_2026-11-14.md)과 [23개 필수 통제](PRODUCTION_READINESS_2026-11-14.json)에 전체 완료 조건을 기록했다.

`check:readiness`는 필수 통제를 삭제하거나 증거·배포 파일이 달라진 상태를 준비 완료로 처리하지 않는다. `start:production`은 증거와 HTTPS 운영 주소·Secure 쿠키·운영 DB 분리 설정이 미완료이면 시작을 거부한다. 기존 `serve:exam`은 기능 검증용 명령이다. 이 도구가 법률·보안 전문가와 운영 책임자의 실제 검토를 대신하는 것은 아니다.

첫 화면의 자동 외부 글꼴 CDN 두 곳을 제거하고 로컬 글꼴로 대체했다. 읽어주기는 브라우저가 로컬 음성으로 보고한 한국어 음성이 없으면 외부 기본 음성으로 대체하지 않는다. 실제 기기의 전체 네트워크와 운영체제 통신을 검증한 결과는 아니다. 운영 빌드 HTML/CSS의 자동 외부 리소스 참조 검사도 추가했다.

의존성 감사에서 중간 위험도 2건을 확인하고 호환 범위에서 수정했다. Vite는 6.4.6으로 갱신되었다. 수정 후 감사 보고 취약점 수는 0이며, 이 수치로 전체 앱·운영 환경의 안전성을 판정하지 않는다. CycloneDX 구성요소 목록도 생성했다.
