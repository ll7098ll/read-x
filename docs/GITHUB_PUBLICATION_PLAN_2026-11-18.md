## 문서 운영

현재 설명은 [현황](PROJECT_STATUS.md), 실행은 [개발 환경](DEVELOPMENT.md), 배포는 [배포 안내](DEPLOYMENT.md)를 따른다. 날짜별 기획·작업 문서는 당시 범위와 근거를 보존한다. 과거 실패나 미완료 항목을 최신 완료 상태로 덮어쓰지 않는다.

중복 루트 문서는 `docs/` 기준 문서로 연결한다. 초기 UI 명세는 v3로 안내한다. 전체 Markdown은 [문서 목차](README.md)에 분류한다. 공개에서 제외한 로컬 로그는 링크 대신 경로 표기로 남긴다.

## 공개 범위

포함: 앱·서버·테스트, 데이터·집필 원고, 연구 요약·출처 목록, 기존 교과서 참조 자산, 교재 HTML·검증 결과·브랜드 전달본.

제외: 의존성·빌드 폴더, 실제 키·환경 파일·DB·백업·복구 원장, `sites/`, 배포 tar/zip, 작업 로그·임시 청크·로컬 감사 캡처, `research/curriculum_2022/sources/` 다운로드 원본. 파일 제외는 로컬 원본 삭제를 뜻하지 않는다.

기존 Git 이력에도 민감 자료가 없는지 확인한다. 민감 자료가 발견되면 해당 이력을 그대로 공개하지 않는다. 외부 자산에 임의로 MIT 등 포괄 라이선스를 부여하지 않는다.
