## 적용 범위

대표 세부목표 `G5-EXP-V1-1`의 **정의·세부 정보 확인 부분**을 실제로 진행할 수 있는 수업으로 개편했다. 학생 배움터와 교사 첫 화면에 진입 카드를 추가했다. 기존의 다른 수업과 사용자 편집본은 유지한다.

진입 주소: `http://127.0.0.1:5173/#/student/studio/G5-EXP-V1-1`

이번 구현은 대표 수업과 기기 내 기록을 검증하는 범위다. 전체 목표의 개편, 정식 교육 콘텐츠 게시, 기관 인증·권한·서버 제출, 학습 효과 검증까지 완료한 것은 아니다.

## 실제 학습 흐름

오늘의 목표 → 생각 시범 → 함께 연습 → 도움 줄이기 → 내 말로 정리 → 혼자 확인 → 새 글에 적용 → 돌아보기.

- **생각 시범:** 질문 확인, 정의 연결, 원문과 자기 설명 비교의 세 장면. 각 장면이 실제 본문 문장과 연결된다.
- **함께 연습:** 용매의 정의를 찾고 설명과 근거 선택 이유를 직접 작성한다.
- **도움 줄이기:** 별도 증발 지문에서 같은 읽기 기능을 사용한다. 필요한 질문만 펼칠 수 있다.
- **내 말로 정리:** 앞서 고른 근거와 설명을 옆에서 확인하며 글을 쓴다. 첫 문장과 수정본을 각각 보관한다.
- **혼자 확인:** 도서관 지문에서 청구기호의 정의를 설명한다.
- **새 글에 적용:** 생산·소비 지문에서 유통의 정의를 구별한다.
- **돌아보기:** 활동별 응답·근거·도움·교사 검토 상태·쓰기 수정본을 확인하고 다음에 사용할 읽기 방법을 적는다.

준비된 학생은 목표 화면에서 혼자 확인부터 시작할 수 있다. 완료 여부를 능력 점수로 바꾸지 않는다. 같은 수업을 다시 시작해도 이전 시도와 지문 노출 이력을 보존한다.

## 읽기와 자기 표현의 연결

본문 문장을 누르거나 키보드로 선택하면 ‘글에서 고른 근거’에 연결된다. 각 활동의 근거, 자기 설명, 선택 이유가 ‘내 생각의 흔적’에 모이고 쓰기 화면에서도 이어진다. 근거를 누르면 원문 위치를 다시 볼 수 있다.

문장을 수정해도 이전 확인 응답은 덮어쓰지 않는다. 확인 시점의 지문 ID·버전과 인용 문장도 보관한다. 현재 작성 중인 내용과 이전에 확인한 응답을 구별하며, 근거가 바뀌면 저장한 설명을 다시 점검하도록 안내한다.

## 도움과 확인 기록

도움은 단계별로 최대 세 질문까지 펼칠 수 있다. 한 번 펼친 도움 수준은 뒤로 이동하거나 다시 열어도 낮아지지 않는다. 독립·전이 과제에서 도움을 사용하면 지원을 받은 수행으로 남긴다.

근거 위치에 대한 즉시 안내와 서술형 설명의 평가는 구별한다. 적절한 근거를 골랐어도 설명·선택 이유는 자동으로 성공 판정하지 않으며 교사 검토 전으로 기록한다. 피드백 이후의 수정 응답과 이전에 열어본 지문의 재시도는 새 글의 첫 독립 응답으로 집계하지 않는다.

관찰 자료는 `ProcessObservation`으로 변환할 수 있도록 목표, 시도, 활동, 지문 버전, 도움 수준, 연습·독립·전이 목적, 노출 조건, 응답과 근거를 포함한다. 화면의 집계는 활동별 최근 응답 기준이고, 과거 응답은 별도로 열람할 수 있다.

## 역할별 화면

| 역할 | 반영한 내용 |
| --- | --- |
| 학생 | 목표부터 돌아보기까지의 수업, 도움 요청, 원문 복귀, 자동 저장, 다시 연습, 작성 기록 |
| 교사 | 검토 대기 응답 수, 근거·설명·선택 이유·도움 이력 확인, 이번 응답의 수행 판정과 검토 메모 |
| 학부모 | 동일한 체험 응답과 검토 상태, 실제 작성한 문장, 아이에게 물어볼 대화 질문 |
| 콘텐츠 관리자 | 대표 수업의 지문·시범·활동·도움 구성과 정식 게시 전 검토 상태 |

검토와 메모는 같은 기기의 체험 저장소에 반영한다. 다른 학생·기관·교사에게 전송하거나 정식 과제를 제출하는 기능은 포함하지 않는다.

## 디자인과 접근 방식

기존 ReadX 심벌과 CI를 사용한다. 종이색 읽기 영역, 옅은 시안의 선생님 시범, 에메랄드 계열의 자기 표현, 골드 근거 강조를 구별했다. 단계, 작성 주체, 선택 상태에는 문구와 아이콘도 함께 표시한다.

넓은 화면에서는 본문과 활동을 나란히 둔다. 모바일에서는 질문을 보며 본문과 활동을 전환하고, 근거를 다시 보러 가도 입력이 유지된다. 읽기 글자 크기와 종이·따뜻한 배경·어두운 배경을 제공한다. 응답을 확인한 뒤에는 다음 학습 행동을 주 버튼으로 보여 준다.

## 검증

`npm run build` 완료: TypeScript, 자동 검사 19개, Vite 프로덕션 빌드 통과. 단일 HTML 산출물은 약 2.46 MB, gzip 약 573 KB다.

새 자동 검사에서는 다음을 확인했다.

- 시범과 과제의 근거가 해당 지문에 존재하는지, 구절 ID가 고유한지.
- 도움을 받은 응답이 독립 수행으로 바뀌지 않는지.
- 서술형 설명이 교사 검토 없이 자동 성공이 되지 않는지.
- 피드백 뒤 수정·재시도를 새로운 글의 확인으로 집계하지 않는지.
- 다른 글의 근거, 빈 응답, 중복 제출을 거절하는지.
- 새로고침에 해당하는 재수화 뒤 단계·도움·노출·수정본·검토 메모가 복원되는지.
- 8개 학습 과정과 학생·교사·학부모 기록 화면이 저장된 응답으로 렌더되는지.

기존 96개 수업의 480개 활동과 36개 기초 수업 렌더 검사도 통과했다.

브라우저에서는 목표부터 회고까지 직접 진행했다. 근거 선택, 도움 사용, 새로고침 복원, 초고·수정본 저장, 모바일 원문 복귀, 독립·전이 응답, 교사 검토 저장, 학부모 화면 반영을 확인했다. 1440px과 모바일 390px 설정에서 가로 넘침이 없었고, 확인 시점의 브라우저 오류 로그는 없었다.

동작 검사용 응답은 `localhost`에 작성해 사용자가 열어 둔 `127.0.0.1`의 학습 기록과 분리했다. 검사 탭을 닫고 임시 화면 크기 설정을 복원했다.

## 다음 확장 조건

새 지문 네 편과 시범·도움은 자체 작성한 체험 초안이다. 정식 게시 전 교육·사실·학년 적합성 검토가 필요하다. 이번 수업을 기존 목표 전체의 성취 증거로 사용하지 않는다.

학생·교사 사용 관찰을 거쳐 사실 확인 수업의 지시량과 도움 수준을 조정한 뒤 추론·평가 목표로 확장한다. 각 목표에 맞는 사고 활동과 판정 준거를 별도로 작성하고, 기관 운영 단계에서 인증·권한·서버 저장·제출을 연결한다.
