## 0. 기존 프로토타입(`.docx` / `.json`) 편집 체제 진단 및 핵심 개선 과제

현재 생성된 `문해력_교과서_이야기_꼴뚜기.docx`(B5 판형, `182.88 × 256.54mm`, 상하좌우 여백 `20.32mm`, 총 97개 표)를 역분석한 결과, 다음 **4가지 구조적 한계**가 확인되었습니다.

1. **공간적 분리(Split-Attention)와 스캐폴딩 중복**:
   - 본문 우측 날개(`Nx2` 표)에 이미 `scaffold_text`가 존재함에도, 본문 표가 끝난 하단에 별도의 `1x1` **[💬 사고구술 코너 (I Do)]** 박스가 중복 배치되어 시선이 분산됨.
   - 본문 텍스트 내부에 밑줄·동그라미·문단 번호·스텝 배지 등 **시각적 앵커(Anchor)**가 전혀 없어, 우측 날개 질문이 본문의 어느 문장을 가리키는지 학생이 다시 찾아야 하는 외재적 인지 부하(Extraneous Cognitive Load) 발생.
2. **도해조직자(Graphic Organizer)의 평문 텍스트화**:
   - 3차시(이야기 산), 6차시(심리 추론 프로파일), 12차시(이야기 설계도) 등 구조화 활동이 모두 `1x1` 단일 셀 안에 `• 항목: _______________` 형태의 단순 밑줄 빈칸(`workspace` 문자열)으로만 구현되어 시각적 스캐폴딩 기능 상실.
3. **활동 간 단절(파편화된 I Do → We Do → You Do)**:
   - `[본문 마킹] ➔ [짝 대화] ➔ [기록 노트]`가 별개의 `1x1` 상자로 쪼개져 있어, 본문에서 찾은 단서가 어떻게 도해조직자로 묶이고 최종 요약·추론문으로 이어지는지 **유기적 활동 사슬(Activity Chain)**이 보이지 않음.
4. **전 차시(1~14차시) 획일적 템플릿 적용**:
   - 도입(1차시), 정독(2~10차시), 독립적 읽기(11차시), 쓰기 기획(12차시), 초고·퇴고(13차시)가 모두 동일한 `본문 2열 표 + 하단 1x1 박스 3개` 구조로 찍혀 나옴. 특히 12·13차시(쓰기)에서는 쓰기 안내문이 마치 읽기 지문처럼 `segmented_passages`에 들어가는 기형적 구조 발생.

### 1-2. Mayer의 멀티미디어 학습 인지이론 기반 3대 편집 원칙

잘게 쪼개진 하위목표(Sub-skills)와 사고구술·발문이 초등 6학년 학습자에게 **인지적 과부하(Cognitive Overload)**를 일으키지 않고 한눈에 읽히도록 하는 3대 지면 설계 법칙입니다.

#### ① 공간적 근접성 원리 (Spatial Contiguity Principle) — *"시선 이동 거리 제로(Zero Eye-Jump)"*
* **원리**: 본문 구절과 그 구절을 해설하는 사고구술·어휘 뜻풀이·날개 질문이 물리적으로 가장 가까운 위치(동일 수평선상)에 배치될 때 작업 기억(Working Memory) 소모가 최소화됩니다.
* **지면 구현 규칙**:
  - **행(Row) 단위 1:1 수평 정렬**: 기존처럼 본문 전체가 끝난 뒤에 사고구술 박스를 두는 방식을 폐기하고, 본문을 의미 단락(2~3문단) 단위의 테이블 행(`<tr>`)으로 분할하여 **좌측 셀(본문 특정 구절)**과 **우측 셀(해당 구절의 사고구술/날개 질문)**이 정확히 같은 수평 높이에 시작하도록 고정합니다.
  - **인라인 앵커-날개 번호 매칭**: 본문 내 타깃 문장에 원문자 배지(`➊`, `➋` 또는 `[단서 ①]`)와 색깔 하이라이트를 부여하고, 우측 날개 박스 상단에 동일한 배지(`[단서 ①] 🔍 사실 확인`)를 달아 시선이 1cm 이내에 즉각 연결되게 합니다.

#### ② 신호 주기 원리 (Signaling Principle) — *"시각적 위계와 색상 코딩을 통한 주의 집중"*
* **원리**: 핵심 정보의 조직 구조와 수행할 행동(Action)을 색상, 아이콘, 타이포그래피 대비로 신호화(Signaling)하면 학습자가 무엇에 주목해야 할지 즉시 파악합니다.
* **지면 구현 규칙**:
  - **3색 시맨틱 마킹 시스템(Semantic Color Coding)**: 장르를 불문하고 학생이 손으로 긋거나 눈으로 따라가는 요소를 3가지 색(파랑 `#2980B9` / 초록 `#27AE60` / 빨강·주황 `#E67E22`·`#C0392B`)으로 표준화합니다. (예: 이야기 — 파랑=인물, 초록=배경, 빨강=사건 / 논설문 — 빨강 이중선=주장, 파랑 실선=근거, 초록 점선=근거자료)
  - **발문 주체 및 단계 신호화**:
    - `🗯️ [선생님의 생각 시범 | I Do]`: 연한 웜그레이/테마 틴트 배경 + 좌측 굵은 테마색 보더(3pt) + 구어체 따옴표 텍스트 (읽고 관찰하는 영역)
    - `✏️ [함께 단서 찾기 | We Do]` / `✍️ [스스로 정리하기 | You Do]`: 흰색 입력 배경(`#FFFFFF`) + 점선/실선 테두리 + 연필 아이콘 + 기입용 밑줄/빈칸 (직접 연필로 쓰는 영역)
    - **시각적 불변 법칙**: *"색 배경 박스는 눈으로 읽는 가이드이고, 흰색 바탕 박스는 연필로 글씨를 쓰는 공간이다"*라는 시각 신호를 전 페이지에 일관되게 적용합니다.

#### ③ 분절화 원리 (Segmenting Principle) — *"인지적 호흡에 맞춘 세그먼트와 마이크로 스텝"*
* **원리**: 1,200~1,800자의 긴 본문과 복합적인 사고 과제를 연속된 덩어리로 제시하지 않고, 학습자가 소화할 수 있는 의미 단위(Chunk)와 단계별 하위 목표(Micro-steps)로 쪼개어 인지적 멈춤(Pause & Process)을 유도합니다.
* **지면 구현 규칙**:
  - **본문 3~4 세그먼트 분절 및 미세 여백(8pt)**: 한 차시 본문(약 1,200~1,500자)을 사건 전환이나 문단 역할에 따라 **3~4개의 세그먼트(각 300~450자)**로 분할하고, 세그먼트 사이에 얇은 점선 구분선(`1pt dashed #D5D8DC`)을 넣어 호흡을 조절합니다.
  - **복합 질문의 단일 행동 분절**: *"인물의 행동을 찾고 그 속마음을 추론하여 문장으로 쓰세요"*처럼 3가지 인지 작용이 섞인 질문을 금지하고, 반드시 **`[Step 1 찾고 표시하기]` ➔ `[Step 2 단서와 내 경험 묶기]` ➔ `[Step 3 한 문장으로 쓰기]`**의 3단계 마이크로 박스로 분절합니다.

## 2. 핵심 시각적 스캐폴딩 구성요소(Editorial Components) 상세 규격

### 2-1. 본문 어노테이션(Annotation) 시스템 및 우측 날개 매핑 규격

교과서 지면 위에서 학생의 연필 움직임을 유도하고, 교사의 시범(I Do)과 학생의 연습(We Do)을 본문에 직접 각인시키는 표준 기호 체계입니다.

#### (1) 본문 상단 고정형 「오늘의 읽기 기호 (Annotation Legend) 바」
매 읽기 차시 본문 시작 바로 위에 가로 막대(높이 `9mm`, 배경 `#F8F9FA`, 테두리 `0.75pt solid #BDC3C7`)로 배치하여, 해당 차시에서 본문에 직접 표시해야 할 기호를 안내합니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ✏️ 오늘의 읽기 기호 │ 🔵 동그라미: 등장인물  │ 🟩 네모: 시간·공간 배경  │ 〰️ 빨간 밑줄: 중심 사건 │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### (2) 장르·목표별 6대 표준 어노테이션 기호 규격 (`.docx` & HTML 호환)

| 기호 명칭 | 시각적 표현 (인쇄/교과서 표기) | `.docx` / HTML 구현 방식 | 주요 적용 학습 목표 (`goals_by_genre.json` 매핑) |
| :--- | :--- | :--- | :--- |
| **① 문단 번호** | `➊` `➋` `➌` `➍` `➎` (테마색 원문자) | 문단 첫 글자 앞 `9pt` 테마색 볼드 원문자 | 전체 차시 공통: 문단 중심문장 찾기, 발문 위치 지시(`"➌문단에서..."`) |
| **② 타깃 구절 앵커** | `①` `②` `③` (위첨자 배지) + **색깔 밑줄/음영** | 텍스트 Run에 `Underline` + `Highlight/Shading` 적용 | 날개 질문 및 사고구술(`💬①`, `🔍②`)과 본문 구절의 1:1 직결 |
| **③ 요소 구분 마킹** | `[인물: 길이찬]` (동그라미/태그)<br>`【배경: 급식실】` (네모 테두리) | Run 테두리(`w:bdr`) 또는 유니코드 괄호 + 배경 틴트 | • 이야기: 인물(파랑 `○`), 배경(초록 `□`), 사건(빨강 밑줄)<br>• 수필: 경험(파랑), 사실(초록), 생각·감상(빨강)<br>• 설명문: 대상(`□`), 특징(밑줄) / 중심문장(굵은 밑줄), 세부문장(점선 밑줄)<br>• 논설문: 문제상황(물결선), 주장(이중 밑줄 `═`), 근거(실선 `─`) |
| **④ 관계 연결 화살표** | `그것` ──(지시)──▶ `앞 문장의 꼴뚜기`<br>`원관념(풀꽃)` ⟷ `보조관념(친구)` | 본문 내 `[지시어: 그것 ➔ '꼴뚜기']` 인라인 표기 + 날개 미니 매핑 박스 | • 공통: 지시어(`이, 그, 저, 그것`)가 가리키는 내용 연결<br>• 공통: 주어(`══`)와 서술어(`══`) 호응 연결<br>• 시: 비유 표현의 원관념과 보조관념 연결 |
| **⑤ 시범 마킹 vs 학생 마킹** | • **I Do 구간**: 교과서에 미리 색깔 밑줄·메모가 인쇄됨<br>• **We Do/You Do 구간**: `[          ]` 빈칸 태그 또는 회색 점선 밑줄(`┈┈┈`)로 학생이 직접 덧칠하게 유도 | 1~2문단은 컬러 밑줄·배지 완성본 출력, 3~4문단은 회색 가이드라인(`#BDC3C7`) 출력 | 점진적 책임 이양(GRR): 교사가 1문단에 마킹한 견본을 보고, 학생이 2~3문단에 똑같이 마킹 수행 |

### 2-2. 유기적 활동 사슬(Activity Chain) 시각화 규격

본문을 읽은 직후 하단(또는 마주보는 우측 페이지)에 펼쳐지는 본 활동 영역은 파편화된 질문 나열을 금지하고, 반드시 **3단계 시각적 파이프라인(`Step 1 ➔ Step 2 ➔ Step 3`)**으로 설계합니다. 학생이 **Step 1에서 쓴 단어를 Step 2의 상자에 넣고, Step 2의 상자를 보고 Step 3의 문장을 완성**하도록 번호와 화살표(`➔`, `▼`)로 강제 연결합니다.

### 2-3. 읽기↔쓰기 전이(Transfer) 레이아웃 규격 (표현 활동 1차시: 기획·조직)

#### (4) `.docx` 및 HTML/PDF 구현 시 필수 테이블(Table) 엔지니어링 규칙
1. **페이지 넘김 시 행 쪼개짐 방지 (`cantSplit`)**: 본문 세그먼트 행(`<tr>`)이나 도해조직자 박스가 페이지 경계에서 어색하게 잘리지 않도록 모든 활동 박스 행에 XML `<w:cantSplit/>` 속성을 부여합니다.
2. **좌우 셀 시각적 분리 (Gutter/Border)**: 2열 본문-날개 테이블에서 외곽 테두리는 제거(`none`)하되, 좌측 본문(70%)과 우측 날개(30%) 사이의 **수직 중앙선(Inside Vertical Border)에만 `0.75pt dashed #BDC3C7` 점선**을 넣고 좌측 셀 우측 패딩을 `10pt(3.5mm)`로 설정하여 본문과 날개가 시각적으로 섞이지 않게 합니다.
3. **도해조직자의 중첩 표(Nested Table) 또는 다열 그리드 구현**: `you_do.workspace`를 단순 문자열로 넣지 않고, JSON 스키마에 `organizer_type` (`"story_mountain"`, `"inference_equation"`, `"three_column"`, `"argument_tree"`, `"transfer_bridge"`, `"revision_manuscript"`)을 정의하여 렌더러가 실제 다열/다행 그래픽 테이블과 화살표 셀(`➔`, `▼`)을 그리도록 구조화합니다.
